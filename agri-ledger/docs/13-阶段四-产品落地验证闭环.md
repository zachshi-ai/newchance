# 13 · 阶段四：产品落地验证闭环

> 本阶段回答：怎么证明这个产品会成（或不成）？用 HDD 把信念变成可证伪假设，用 OHELM 循环推进验证，用 90 天排期对齐农时与执法节奏，并确立第一桶金。

---

## 1. 假设登记册（HDD）

| # | 假设 | 判据（可证伪） | 验证方法 | 状态 |
|---|---|---|---|---|
| H1 | 店主会持续落账（进货/销售动作留存是全产品的地基） | ≥40% 建档门店第 14 天仍有落账记录新增 | 本地事件流（`intake`/`sale` 埋点，设置页可导出）+ 20 家种子门店微信群自愿回传 | ⬜ 待验证 |
| H2 | 迎检打印包会在真实检查中被使用并采信 | ≥50% 活跃门店每月导出 ≥1 次；≥3 家门店反馈"检查时实际出示" | 埋点：`ledger` 事件按 action 分桶（copy/download/print）+ 种子回访 | ⬜ 待验证 |
| H3 | 药害自证单在真实纠纷中被使用 | 种子门店中 ≥2 家在真实纠纷/索赔中出示过自证单 | 埋点：`proof` 事件密度 + 案例回访 | ⬜ 待验证 |
| H4 | 付费意愿存在且锚点在一百元内 | 假门按钮点击率 ≥5%；或 ≥10 家愿付 ¥99/年 | 假门 Pro（多店/月报/自定义抬头，点击后如实告知"功能规划中"）+ 直接报价访谈 | ⬜ 待验证 |
| H5 | 县级批发商愿意联营分销（赊销保全叙事成立） | ≥3 家批发商试点贴牌、合计覆盖 ≥60 家门店 | 县级批发商扫街拜访（一个批发商辐射 10~200 家门店），白标包 ¥1200/年 | ⬜ 待验证 |
| H6 | 过期封存动作被真实执行（劣药红线的日常化） | 过期在库点名的门店中 ≥60% 两周内完成封存 | 埋点：`seal-batch` 事件对 `expiredOnShelf` 曝光的转化 | ⬜ 待验证 |
| H7 | 门店品类结构呈长尾（纯农药店少、混卖店多） | 混卖店（农药+种子/肥料）占比 ≥60% | 埋点：建档商品 kind 分布（若纯农药店超预期，强化农药专有功能优先级） | ⬜ 待验证 |
| H8 | 用户会主动备份/迁移数据 | JSON 导出使用率 ≥10% | 埋点：`export-json` 事件 | ⬜ 待验证 |

**已证伪风险预案**：若 H1 < 20%（落账动作不成立——忙时顾不上 R2 成真），转向"迎检台账包生成器"单点工具（弱化日常落账叙事，强化办证/检查前批量补录场景——同一个 core，换一个入口叙事）；若 H2 < 30%（打印包没人用或没人采信），出证价值主张被证伪，产品失去对执法场景的钩子，止损关停，把禁限用名录体检拆给农资内容号做引流素材另起炉灶。

## 2. OHELM 验证循环

每条假设按 **Objective → Hypothesis → Experiment → Learn → Measure** 循环推进，学习结果写回假设登记册，不做完循环不进入下一轮投入：

| 环节 | 本项目的落地形式 |
|---|---|
| **O** Objective | 90 天内证明"店主愿意把购销账从纸本升级为落账 + 出证"（H1+H2+H3+H6） |
| **H** Hypothesis | 上表 H1-H8，一条一个预期数值 |
| **E** Experiment | ①20 家种子门店（8 纯农药店 + 8 混卖店 + 2 筹备办证户 + 2 被罚过/遇药害的店）微信群陪跑（本地优先工具的天然局限：埋点在端上，靠用户自愿导出 + 周回访，赶集日面对面回收）②假门付费 ③县级批发商扫街 10 家、谈 3 家贴牌试点 |
| **L** Learn | 每两周一次循环复盘：判据达标 → 升级投入；不达标 → 触发对应预案（H1/H2 预案） |
| **M** Measure | 北极星：**周活跃落账门店数（周内至少有 1 条进货或销售落账的门店数）**；护栏指标：迎检包导出率（H2）、落账 14 天留存（H1）、过期封存执行率（H6）、备份导出率（H8） |

**北极星指标说明**：不选下载量（vanity）、不选建档数（无门槛），选"每周至少落一笔账的门店数"——它同时代表门店留存、真实购销行为与台账的持续可证明性，且与门店的合规健康度同向。

## 3. 第一桶金（确立）

三条腿并进，以 ② 县级批发商联营为杠杆主攻：

| 路径 | 定价 | 第一笔钱的现实性 | 90 天目标 |
|---|---|---|---|
| ① 门店 Pro | ¥99/年（多店管理 + 经营月报 + 自定义台账抬头）；单店永久免费 | 假门点击 → 直接报价转化；锚点贴"两瓶高档杀菌剂"的心理账户 | H4 判据：≥10 家付费或假门点击 ≥5% |
| ② **县级批发商联营（主攻）** | ¥1200/年/商（白标 ≤50 家门店，含商家看板：下游门店落账活跃度/效期风险信号） | 一个县级批发商服务 10~200 家门店，客单价是门店的 12 倍且决策人单一（批发商老板）；对商家的账：**农资赊销普遍，下游门店被罚/吊证 = 应收账款坏账，帮门店合规存续 = 保护自家资产负债表** + 白标 = 每周品牌触达 ≫ ¥1200 | 扫街 10 家、签约 3 家 = **首笔现金 ¥3,600**，同时获得 60+ 精准门店分发面 |
| ③ 县域推广员分佣 | 按成交 20% 分佣（农技站离职人员/农资老业务员） | 依赖①②的转化率数据成熟后再开 | 不做承诺，进迭代池 |

**为什么 ② 是主攻**：店主个体付费弱（R1），但县级批发商 B2B 决策快、有独特且深刻的 ROI（**赊销应收账款保全**——这是农资流通区别于其他行业的渠道动机，docs/12 §6.3）、且天然批量触达门店主——**供应链上游即渠道**。第一桶金的本质不是规模，是"有人为价值付了第一笔真钱 + 一条可复制的收款路径"，3 家批发商试点同时验证产品价值（H5）、渠道结构（分发面）与收款能力。

## 6. 诚实条款（本项目的科学底线）

- **不碰追溯平台报送、不做扫码硬件绑定、不做财务进销存**：批次手输照标签抄（这是特性不是缺陷：无报送合规负担、无硬件门槛、离线可用）。追溯赋码与数据报送以监管平台及属地要求为准，本工具只管门店自己的经营底账。
- **内置禁限用名录是常见条目的通识整理，绝非完整名录**：现行禁用农药数十种、限制使用农药 32 种，以农业农村部最新公告为准；匹配采用名称完全一致、不猜模糊词，商品手动标记永远可覆盖；736 号公告条目已单独标注 2026-06-01 生效时点。名录更新滞后风险（R8）显式存在。
- **打印台账不承诺执法采信**：迎检包是门店自查与备查底账（含账实守恒体检），帮助店主"当场拿得出、说得清"；本地记录不具备司法级不可篡改性，不宣称替代法定报送、公证存证或监管平台数据；证据价值在"完整、即时、与实物对得上"。
- **自证单是经营凭据不是法律意见**：按门店台账如实出具（含"未查到"的如实记录），药害责任认定以司法机关与属地规则为准——**法律永远赢**。
- **实名信息最小披露**：限用农药购买人身份证号仅存本机、仅在限用商品台账行出示，非限用商品一律不留不显；数据 100% 本地存储，换机走 JSON 导入导出。
- **所有商业假设未验证**：付费、留存、渠道数字全部是待证伪的信念。我们不把"法定台账义务"当作付费的必然性——纸台账本两块钱一本，记忆和管家婆的空壳也是船。
