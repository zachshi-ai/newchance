# 10 · 阶段一：识别机会与洞察市场

> 本阶段回答：世界的哪个痛点值得做？用第一性原理拆到底，用 JTBD / 船模型 / 非消费者分析还原真实场景，用 PESTEL 扫宏观，用机会缺口矩阵定位空白。

---

## 1. 第一性原理拆解

不问"市面上有什么农资软件"，只保留不可再分的事实：

| # | 不可再分的事实 | 推论 |
|---|---|---|
| F1 | 台账是农药经营的**法定义务**而非经营偏好：《农药管理条例》（2017 修订）第 26 条要求建立采购台账（名称、许可证明文件编号、规格、数量、生产企业、供货人及联系方式、进货日期），第 27 条要求建立销售台账（名称、规格、数量、生产企业、购买人、销售日期），均须**保存 2 年以上**；不执行台账制度的责令改正，拒不改正或情节严重的处 2000 元~2 万元罚款（第 58 条口径，检索摘要留存） | 农资店的台账不是"记不记"的选择题，是"能否持续自证已记"的合规题。**证明成本**（把义务变成拿得出手的凭据）是整个痛点的第一性变量 |
| F2 | 「电子台账」是拿证的前置条件：《农药经营许可管理办法》第 7 条第（四）项，申请农药经营许可须"有可追溯电子信息码扫描识别设备和用于记载农药购进、储存、销售等电子台账的计算机管理系统"——新增门店与到期换证的店主**必须**跨过这道坎 | 合规压力最尖锐的时刻是**办证时点**，而不是日常经营；工具若替店主把"电子台账"这关变得近乎免费，就卡住了刚需的咽喉 |
| F3 | 禁限用红线正在收紧且**时效性极强**：农业农村部第 736 号公告，氧乐果、克百威、灭多威、涕灭威自 2026-06-01 起**全面禁止销售和使用**（制剂 2024-06-01 起已禁止生产）；现行禁用农药数十种、限制使用农药 32 种（定点经营、实名购买、专柜存放） | 2026-06-01 已过——**存量清库与台账核查是当下进行时**；店主演不清"哪个还能卖"，一次误进误卖就是没收+罚款+吊证风险。红线的判断成本必须被打到趋近于零 |
| F4 | 过期农药按**劣质农药**管理：经营劣质农药将被没收并处罚款——效期不是"库存管理问题"而是违法红线；但农资的季节性（春耕/秋播窗口）让"临期先卖"天然反直觉，压货过季是常态 | 效期账 = 资金账 + 合规账的交点：到点自动点名、过期自动踢出卖场，是把"劣药红线"翻译成店主每天看得懂的动作 |
| F5 | 药害纠纷的举证责任现实地压在门店：最高法涉农民事典型案例口径（检索摘要留存），农资经营者不能指明进货来源与产品信息的，对产品质量缺陷致害**先行担责**；销售台账上的批号/追溯码是门店把责任回溯到生产企业的唯一通道 | 卖出那一刻的落账质量，决定药害纠纷发生时门店是"自证清白"还是"背锅垫底"。台账同时是**合规凭据**与**民事证据** |
| F6 | 乡镇门店的现状解法 = **纸台账本 + 记忆 + 检查前突击补填**：店主平均年龄偏大、不会 Excel、进货集中在赶集日与送货上门时段，"先干着回头补"是默认动作；而补填的台账经不起"与进货发票/实物对不上"的追问 | 现状解法的失败不在"不知道要记"，在**记录动作的成本高于记录的价值感知**——动作成本必须打到"顺手"级 |
| F7 | 农资零售是**极端低毛利 + 高频小额**生意：一瓶药赚几块钱，一单 2000 元罚款等于几周白干；店主对"年费软件"的心理账户接近零，对"帮我过关"的心理账户是真金白银 | 定价只能走免费增值；付费叙事必须是"止损与过关"（罚款/吊证/药害赔偿的期望损失），不是"提升经营效率" |
| F8 | 购买人实名（限用农药）、农户姓名电话是个人信息；乡镇网络不稳、店主终端就是手机；农药追溯平台（监管侧）负责二维码赋码与数据报送，门店无力也无须自建"第二套监管系统" | 本地优先（数据不出设备）是隐私与成本双重最优解；工具**不做追溯平台报送、不做扫码硬件绑定**，与监管设施互补不竞争 |

**第一性结论**：农药经营门店的生存确定性 = 「台账义务的可证明性 × 禁限用红线的可判断性 × 效期红线的可执行性 × 药害纠纷的可自证性」，四件事共用**同一本购销流水账**。谁把"进货落一笔、卖出落一笔、检查出一包"的成本打到趋近于零，谁就把 2 年保存期的法定义务，从悬在头上的罚款风险变成门店的信用资产。

## 2. 痛点 - 爽点 - 痒点模型（梁宁）

| 层 | 用户心理 | 购销单对应 |
|---|---|---|
| **痛点**（恐惧/怕） | 怕执法检查拿出台账对不上实物；怕误卖 2026-06-01 起全面禁售的氧乐果/克百威；怕过期货没下架被按劣质农药处罚；怕药害找上门说不清货源；怕办证/换证时"电子台账"这关过不去 | 禁限用名录建档即体检（禁用拒绝建档、限用自动打标）＋效期自动点名＋过期一键封存＋迎检打印包 30 秒出证——罚款风险在爆发前被看见 |
| **爽点**（即时确定性） | 进货扫一眼标签照抄落账 30 秒；卖限用农药实名一填就过；执法进门点两下打印台账；农户索赔当场出凭据 | 进货/销售两步落账（账实自动守恒）＋限用实名强制不漏填＋自证单按人 30 秒捞出批号追溯码 |
| **痒点**（虚拟自我） | "我的小店是持证规范户，台账比连锁店还齐整"；"全村就我家拿得出凭据" | 印着门店名与许可证号的台账与自证单——夫妻店的"规范经营者"身份叙事 |

优先级：痛点 > 爽点 > 痒点。MVP 只做痛点与爽点，痒点靠台账/自证单的品牌落款顺手满足，不做农技问答、不做电商集采、不做赊销记账（见阶段三 ERRC）。

## 3. JTBD（待办任务）

**主任务陈述**：**当**进了一批货、卖出一瓶限用农药、有批次快到期、执法上门检查、农户拿着蔫了的苗上门索赔时，**我要**当场说得清"这是什么、哪来的、卖给了谁、还能不能卖"，**以便**检查不挨罚、纠纷不背锅、过期不压仓、办证能过关。

三维拆解：

| 维度 | Job | 现状方案的失败点 |
|---|---|---|
| 功能性 | 进货落账（批号/追溯码/效期/供货人）；销售落账（购买人/实名/防治对象）；禁限用判断；效期预警与过期下架；台账与凭据产出 | 纸本懒得多写一行、名录靠记忆、效期靠翻箱、台账靠突击 |
| 情感性 | 执法进门不心虚；农户上门不慌；清库处置"心里有数" | "我找找台账本"本身就在制造紧张 |
| 社会性 | 向监管（持证规范户）、向农户（负责任的店）、向批发商（对得起赊账的正规门店）证明"我是认真的" | 没有任何体面的凭据载体 |

**竞品不是某个 SaaS，而是「纸台账本 + 记忆 + 管家婆的空壳 + 什么都不记」**——它们免费且是行业默认动作，这是我们真正的敌人（见阶段二波特五力：替代品威胁）。

## 4. 船模型

> 用户要的从来不是船，是安全过河。这里河对岸 = 检查不罚、药害不背、过期不压、办证能过。

| 元素 | 本场景 | 现状问题 |
|---|---|---|
| 乘客 | 乡镇/县域持证农资门店（1~2 人经营，农药+种子+肥料混卖）；无证想办证的夫妻店 | — |
| 船 A：纸台账本 + 记忆 | 现状默认解，零成本 | 懒得写、字迹乱、与实物对不上、检索靠翻，检查前突击补填经不起核对 |
| 船 B：通用进销存（管家婆、秦丝、智慧记等一众） | 进销存全家桶 | 为商超/批发设计：按年费收钱、要电脑要学习、**没有农药的字段与规则**——效期红线、批号追溯、限用实名、禁限用名录一个都没有；店主买了用两周就闲置 |
| 船 C：农药追溯平台 / 扫码设备 | 监管侧赋码与报送通道 | 服务**监管数据链**，不是门店的经营底账：门店无法用它打印迎检台账、按人出自证单、做效期清库；扫码设备办证时买了，日常"懒得开机" |
| 船 D：微信备忘 + 拍照 + Excel 表侄女帮做 | 部分年轻店主的过渡解 | 无规则（不知哪批过期）、无红线（不知哪个禁了）、出证要现攒 |
| 河 | **购销之间的证明黑箱**：进了什么、卖了给谁、哪批过期、哪个禁售，没有一本随取随用的账 | 四条船共同的黑水区 |

**定位推论**：购销单**不造进销存的船，也不造追溯平台的船**，做挂在所有船上的"门店自己的合规底账"——货从哪个批发商来（赊销还是现款）不重要，重要的是"进了之后、卖出之前"这段黑箱第一次有了规则化的账。与进销存互补（真需要财务进销存的店迟早升级，升级前先用它过关），与追溯平台互补（它管赋码报送，购销单管门店自证），与纸台账正面对抗但迁移成本 ≈ 0（还是一部手机，只是从"翻本子"变成"点打印"）。

## 5. 非消费者分析（Christensen）

| 非消费者类型 | 画像 | 为什么不用现有解 | 对产品的启示 |
|---|---|---|---|
| 纸本老店主 | 50+ 岁，老花，微信只会语音，一部千元机 | 管家婆"是会计用的"；Excel 是天书；扫码设备"懒得开机" | 说人话（"效期"不叫"保质期截止日"）；单屏两步动作；字段照标签抄不要求理解 |
| 种子肥料为主、农药为辅的店 | 农药只占两成营业额，品类少周转慢 | 专门为"几瓶药"上一套系统不值 | 支持农药/种子/肥料三类建档，种子肥料不强制效期但可登记 |
| 无证筹备户 | 正在申请农药经营许可的新店主 | 不知道"电子台账"长什么样，怕办证被驳回 | 店铺档案 + 台账输出就是办证材料里"电子台账管理制度"的活证明 |
| 被 SaaS 年费伤过的老板 | 买过会员没用起来，钱打了水漂 | "再交一次年费不如再买一沓台账本" | 数据 100% 本地 + JSON 导出/导入；单店免费全功能，不交钱也能一直用 |

非消费者共同阻碍排序：**"台账是给检查看的，不是给我用的"（价值错觉）> 怕学不会（能力焦虑）> 怕实名信息惹麻烦（隐私顾虑）**。MVP 依次对应：台账先服务店主自己（效期/红线/自证），检查出证只是顺产的输出；名词全部取自标签原文；实名信息只存本机、非限用商品不留证件号（最小披露，已写入台账导出规则）。

## 6. PESTEL 宏观扫描

| 维度 | 要点 | 对本机会 |
|---|---|---|
| **P** 政治 | 农业农村部持续强监管：2017 条例修订确立经营许可 + 台账制度，限制使用农药定点经营全覆盖；农产品质量安全专项整治（豇豆、韭菜等农残专项）把用药溯源压力传导到零售末端 | 合规是自上而下的硬约束，顺风；专项整治期间执法频次上升，"迎检出证"价值即时兑现 |
| **E** 经济 | 农资零售毛利薄、赊销普遍（春赊秋还）；罚款（2000~2 万）相对单店利润是真金白银的打击；高毒农药退市（736 号公告）迫使存量清库换品类 | 免费是唯一入场券；付费叙事 = 止损（罚款/吊证/药害赔偿期望损失），店主算得清这笔账 |
| **S** 社会 | 农产品质量安全是舆情高敏区（毒韭菜、豇豆农残事件反复上热搜）；粮食安全是国策情绪；农村老龄化使店主与农户都在向"少写字、多拍照"迁移 | 台账/自证单 = 门店的"社会信任基建"；拍照式记录、标签原文式输入贴合用户习惯 |
| **T** 技术 | 农药标签强制印追溯二维码——追溯码就在标签上，手输即可采集；智能手机在乡镇已普及；PWA/打印是系统级能力 | 不依赖扫码硬件也能把追溯码记进台账（办证口径的"电子台账"要件由软件承担）；设备钱省下来 |
| **E** 环境 | 高毒高残留农药持续退市（736 号公告即最新一步），生物农药替代加速；规模化种植服务（飞防、统防统治）分流零售用药 | 品类更替频繁 → "哪个还能卖"的判断成本上升，红线体检的价值随退市节奏**持续增值** |
| **L** 法律 | 条例罚则成文化（台账、劣药、超范围经营各有罚则）；药害民事诉讼中经营者对"指明货源"负有责任（最高法涉农典型案例口径，检索摘要留存）；限制使用农药实名购买有地方规章支撑 | 台账既是行政合规凭据又是民事证据；"双证据"定位让产品价值跨过"迎检"进入"纠纷自证" |

结论：宏观无逆风。P（专项整治 + 台账法定）与 E（罚款/吊证的真实损失）双顺风；S 与 L 把痛点从"检查"放大到"纠纷"；T（标签追溯码普及）让数据采集成本趋近于零；E（农药退市节奏）保证红线内容持续更新——规则已生效、时机正在进行（2026-06-01 禁售刚落地）、轻产品空白仍在。

## 7. 机会缺口矩阵

以"用户重要性 × 市场现有解完整度"定位空白：

```
重要性 高 │ ①通用进销存/收银         ③【空白】门店自己的合规购销台账
          │ （管家婆们红海）           （红线体检/效期清库/限用实名/
          │                            药害自证/迎检出证，无小微级轻产品）
重要性 低 │ ②农资电商/集采平台        ④农技内容与飞防调度
          │ （重供应链重运营）          （服务属性重、难收费）
          └─────────────────────────────
             现有解完整度 高            低
```

- ③的四段拆解交叉验证：纸台账（无规则无红线）、通用进销存（无农药字段与规则）、追溯平台（管报送不管自证）、微信拍照（无结构无检索）——**每一段都有人做，合起来无人做**。
- ①是通用软件的主场，年费数百起且要电脑要学习；③覆盖的是沉默的大多数（乡镇夫妻店与农药为辅的综合店）。
- ②与④偏离主线，无冲突也不碰。
- 政策与产业事实给 ③ 背书：台账制度 + 2 年保存期（条例 26/27 条）、电子台账 = 办证前置条件（办法第 7 条）、736 号公告四种高毒农药 2026-06-01 起全面禁售（存量清库进行时）、过期 = 劣药红线——**规则已生效、痛点有罚额背书、轻产品空白仍在**。

**阶段一结论**：购销单占位 ③——一条被台账法定义务、办证前置条件、736 号公告存量清库与药害举证责任共同供养、被"纸台账 + 通用进销存 + 微信拍照"证明协作真实存在、却被所有重软件忽略的缺口。
