# 购销单 AgriLedger 🌾

> **乡镇农资店的农药购销合规台账：进货卖出顺手落账，禁限用红线当场亮灯，效期临期先知道、过期一键封存，执法检查 30 秒打出台账包，药害索赔按人出凭据。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 一部手机就能用

台账是农药经营的法定义务，不是经营偏好：《农药管理条例》第 26、27 条要求经营者建立采购与销售台账并**保存 2 年以上**，不执行台账制度的责令改正、拒不改正可处罚款；"电子台账"更是农药经营许可的**前置条件**（《农药经营许可管理办法》第 7 条）。2026-06-01 起，氧乐果、克百威、灭多威、涕灭威四种高毒农药全面禁止销售和使用（农业农村部第 736 号公告）——存量清库与台账核查是当下进行时。而乡镇门店的现状是纸台账本 + 记忆 + 检查前突击：禁限用名录靠脑子、效期靠翻箱、药害索赔说不清货源、办证不知道"电子台账"长什么样。购销单把这段黑箱变成白箱：商品建档（禁限用红线当场体检）→ 进货建批（批号/追溯码/效期照标签抄）→ 销售落账（限用强制实名、临期先发）→ 效期红灯与过期一键封存 → 执法/药害/办证三场出证。

## 3 条命令跑起来

```bash
cd agri-ledger
npm start           # 等价于 python3 -m http.server 8085 --directory app
open http://localhost:8085
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程（含过期在库红灯与限用实名演示）。

## 功能

| 模块 | 说明 |
|---|---|
| 🧪 **商品建档 + 红线体检** | 名称与内置禁用名录完全一致 → **拒绝建档无后门**（含 736 号公告 2026-06-01 起全面禁售的氧乐果/克百威/灭多威/涕灭威）；命中限制使用名录或手动勾选 → 自动打「限」标；农药/种子/肥料三类建档，毒性分级照标签抄 |
| 📦 **进货建批（条例第 26 条字段）** | 供货人/批号/追溯码/效期/进价一次落账；农药批次**效期必填**、效期早于进货日拒绝——采购台账的法定字段顺手记全 |
| 🧾 **销售落账（条例第 27 条字段）** | 勾商品 → 填数量 → 落账三步；**临期先发 FIFO、同效期先进先出、跨批自动分配**（卖出的每件可追到批号与追溯码）；带「限」标商品**强制实名**（姓名 + 身份证号缺一拒绝落账）；**库存不足整单拒绝，绝不部分入账**；撤销精确回滚，账实始终一致 |
| ⏰ **效期三态管理** | 临期窗（默认 90 天，可调）点名先卖；过期批次自动踢出卖场；过期在库看板红灯 + **一键封存报损**（过期农药按劣质农药管理，经营即违法——红线变成一个按钮） |
| 🛡️ **药害自证单** | 按购买人姓名一键捞出全部卖单与批次明细（批号/追溯码/效期/登记证号）；未命中也如实出具"未查到"——药害索赔、执法调查当场拿得出证据 |
| 🖨️ **迎检打印包三通道** | 台账文本复制（微信转发）/ 单文件 HTML（店铺档案 + **账实守恒体检** + 采购台账 + 销售台账 + 库存效期盘点，内联样式离线可用）/ 直接打印——30 秒出证，执法者零安装 |
| 🔍 **账本体检三查** | 过期在库 / 限用实名缺漏（补录数据常见）/ 禁用商品档案（只可能来自导入）——迎检前先自扫一遍；进货 = 已售 + 报损 + 库存的守恒体检常亮 |
| ⚙️ **数据自持** | 100% 本地存储（限用实名信息不出设备）；JSON 导出/导入（换机迁移，含结构校验——台账要保存 2 年以上，别只靠一台手机）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
乡镇网络差，PWA 离线可用；出证走微信文本与本地打印，不依赖任何在线服务；限用实名信息不出设备。**不碰追溯平台报送、不做扫码硬件绑定、不做财务进销存**——赋码报送是监管平台的事，这里是门店自己的经营底账与自证凭据。

## 边界与免责

- **不碰追溯平台报送、不绑定扫码硬件、不做财务进销存、不做电商集采**——批次手输照标签抄（这是特性不是缺陷：无报送合规负担、无硬件门槛、离线可用）。追溯赋码与数据报送以监管平台及属地要求为准。
- **内置禁限用名录是常见条目的通识整理，绝非完整名录**：现行禁用农药数十种、限制使用农药 32 种，以农业农村部最新公告为准；匹配采用名称完全一致、不猜模糊词；商品手动标记永远可覆盖；736 号公告条目已标注 2026-06-01 生效时点。**属地规则与最新公告永远赢**。
- **打印台账不承诺执法采信**：迎检包是门店自查与备查底账（含账实守恒体检），本地记录不具备司法级不可篡改性，不替代法定报送、公证存证或监管平台数据。
- **自证单是经营凭据不是法律意见**：按门店台账如实出具（含"未查到"），药害责任认定以司法机关与属地规则为准——**法律永远赢**。
- **限用实名信息最小披露**：仅存本机、仅在限用商品台账行出示，非限用商品一律不留不显。
