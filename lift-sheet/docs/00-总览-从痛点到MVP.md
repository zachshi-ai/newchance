> 一句话：**电梯维保是「周期法定、记录法定、签字法定」的合同履约——做了没记录等于没做，记录没签字等于白做。梯保单把半月/季度/半年/年度四类周期变成一屏自动滚动的红黄绿，把一次保养变成 30 秒落单，把使用单位签字变成流程的最后一环，把「检查来了」变成 30 秒出包。**

## 1. 痛点（真实世界，有据可查）

- **周期是法定的**：TSG T5002-2017《电梯维护保养规则》第六条把维保分为**半月、季度、半年、年度**四类，深层包含浅层；一家管 300 台梯的小微公司每月至少 600 次半月保叠加其他三类——靠 Excel 和记忆排班，漏保是结构性必然。
- **记录与签字是法定的**：第五条(六) 每台电梯建立维保记录、至少保存 4 年；第七条「维保记录**应当经使用单位安全管理人员签字确认**」。纸质单月底补签、代签，在事故调查的对时质询面前一击即穿。
- **罚则是真的**：《特种设备安全法》第八十八条——未按安全技术规范要求进行维保的，与无证维保同罚，处 1 万~10 万元罚款；2024 年「电梯安全筑底行动」典型案例中，头部企业因「维保记录与现场实际不一致」被查处。
- **救援时限是真的**：第五条(四) 24 小时值班电话；困人救援直辖市/设区的市 30 分钟、其他地区一般 1 小时到场——接报到到场没有留痕，超时就说不清。
- **市场是真的**：2024 年底全国电梯 1153.24 万台（市场监管总局通报），维保单位宽区间 1.2 万~1.6 万家，其中大多数是没有 IT 的小微公司。
- 第一性差距：**「做了」与「能证明做了」之间的证明成本，没有任何小微级工具承接**——梯保单把周期变成引擎、把记录变成流程、把签字变成闭环、把证明变成一键出包。

## 2. 方案（机会 → 产品）

**梯保单**：零依赖、本地优先的 PWA。

1. **四周期滚动引擎**：按「该层级或更深层级最后一次完成日 + 周期天数」自动推导每台电梯半月/季度/半年/年度四个到期日；红=逾期、黄=7 日内、绿=正常；无历史按接管日起算——欠账第一天就可见；建议本次类别取「逾期最深层」，一次出工清掉叠层欠账。
2. **30 秒落单（六道门禁）**：项目清单按品种（附件 A~D）与类别叠层并集自动给出；异常项必须写处置说明；不能预录未来；维保人员必须在册；自行检查必须有检查人与审核人；**补录如实打标、不可关闭**。
3. **签字确认链**：确认单三通道（微信文本 / 打印版单文件 HTML 含签字栏 / 直接打印）；使用单位安全管理人员确认后不可覆盖；待签字单持续点名。
4. **救援时钟**：接报 → 到场 → 闭环三时点；30/60 分钟口径参数化；超时如实保留；未闭环永远点名。
5. **周期任务台账**：应急演练按品种半年点名、作业人员证到期、定期检验临期、年度自行检查与检验窗口联动门。
6. **月账**：应收 / 已收 / 欠收 / 落单数 / 签字确认率——欠费月账是催款凭据。
7. **七项体检**：保养逾期、确认缺签、救援超时、检验与自行检查、人员证、演练、欠费（经营项单列）。
8. **迎检打印包**：按使用单位捞出档案 + 维保台账 + 应急记录 + 体检 + 签字栏，单文件 HTML。

## 3. 诚实的现状声明（真实可落地，不空中楼阁）

- **已验证**：全部业务规则在 `tests/core.test.mjs` 中有 33 个单元测试覆盖（周期滚动、叠层覆盖、六道门禁、签字链不可覆盖、救援时钟跨天、演练/证件/检验/自行检查点名、月账派生、七项体检整改回升、出证 XSS 转义、备份往返）；浏览器端到端跑通建档 → 排班 → 落单 → 签字 → 应急 → 体检 → 出证。
- **未验证（诚实标注）**：留存、真实落单覆盖率、签字真实发生率、付费转化、配件商渠道意愿——全部在 docs/13 的 HDD 登记册里配有可证伪判据。
- **边界**：不做物联网、不做政府报送、不做派单大系统、不做多设备实时同步；本工具**不宣称构成 TSG T5002-2017 第十条意义上的法定无纸化维保记录系统**——它是维保单位自持底账与确认单生成器；周期天数与救援时限均为参数化预填，规则原文与属地要求永远赢；打印件不承诺执法采信，事故责任认定以监管与司法机关为准。

## 4. 快速开始

```bash
cd lift-sheet && npm start   # → http://localhost:8092
npm test                     # 33/33 单元测试
```

第一次使用：设置 → 填维保单位与 24h 值班电话、添加维保人员 → 电梯 → 建档（使用单位/设备代码/品种/接管日）→ 排班页看到四周期红黄绿 → 落单 → 台账签字确认 → 迎检包。

## 5. 商业模式与第一桶金（摘要，详见 docs/12、13）

- **双轨收入**：维保公司 Pro ¥99/年（台量无限 + 月账 + 迎检包）；电梯配件经销商白标 ¥1500/年/商，分发其下游 10~100 家维保公司。
- **渠道动机**：配件商靠光幕/门机/钢丝绳/按钮的周周复购活着——下游维保公司被停业 = 客户池流失；帮下游合规存续 = 保护自己的应收与复购。
- **第一桶金路径**：配件商白标 3~5 家（¥4500~7500）+ 直销 80~150 家（¥0.8~1.5 万）；本质是验证「有人愿意为证明成本掏钱」这一行为事实。
- **北极星**：周活跃落单电梯数；护栏：签字率 ≥ 50%、补录率 ≤ 40%。
