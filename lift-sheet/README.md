# 梯保单 LiftSheet

> 小微电梯维保公司的四周期排班、维保记录与签字确认台账 —— 零依赖、本地优先 PWA。
> 机会实验室（`newchance`）第 16 号项目 · 领域：电梯维保服务业 · 市场监管特种设备线。

**做了没记录等于没做，记录没签字等于白做。** TSG T5002-2017 把电梯维保定为半月/季度/半年/年度四类叠层周期，要求每台电梯建立维保记录、保存 4 年、经使用单位安全管理人员签字确认；《特种设备安全法》第八十八条对未按规定维保处 1 万~10 万元罚款。小微维保公司靠 Excel + 纸质单 + 记忆扛这套法定义务——梯保单把它变成一屏红黄绿、30 秒落单、签字闭环与一键出包。

## 快速开始

```bash
npm start   # → http://localhost:8092
npm test    # 33/33 单元测试（node --test，零依赖）
```

## 功能

- **四周期滚动引擎**：按最后完成日 + 周期天数自动推导四类到期；深层保养覆盖浅层欠账；无历史按接管日起算
- **30 秒落单**：项目清单按品种（附件 A~D）与类别叠层给出；异常必须写处置；补录如实打标；自行检查需检查人 + 审核人
- **签字确认链**：确认单三通道（微信文本 / 打印 HTML 含签字栏 / 直接打印）；确认后不可覆盖；待签字持续点名
- **救援时钟**：接报 → 到场 → 闭环；30/60 分钟口径参数化；超时如实保留
- **周期任务**：演练按品种半年点名、人员证到期、定期检验临期、年度自行检查联动门
- **月账**：应收 / 已收 / 欠收 / 签字率——催款凭据
- **七项体检** 与 **迎检打印包**（按使用单位整链）

## 诚实条款

本工具是维保单位的自持底账与确认单生成器，不宣称构成 TSG T5002-2017 第十条意义上的法定无纸化维保记录系统，不替代法定报送；周期天数与救援时限为参数化预填，规则原文与属地要求永远赢；打印件不承诺执法采信，事故责任认定以监管与司法机关为准；商业假设全部「待验证」并配有可证伪判据（docs/13）。
