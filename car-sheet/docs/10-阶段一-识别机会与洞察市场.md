# 10 · 阶段一：识别机会与洞察市场

> 本阶段回答：世界的哪个痛点值得做？用第一性原理拆到底，用 JTBD / 船模型 / 非消费者分析还原真实场景，用 PESTEL 扫宏观，用机会缺口矩阵定位空白。

---

## 1. 第一性原理拆解

不问"市面上有什么二手车 SaaS"，只保留不可再分的事实：

| # | 不可再分的事实 | 推论 |
|---|---|---|
| F1 | 如实告知是卖方的**法定义务**而非道德选项：《二手车流通管理办法》（2005 年商务部等四部门令第 2 号，2017-09 修订）第十四条要求卖方向买方提供车辆的使用、修理、事故、检验以及是否办理抵押登记、交纳税费、报废期等**真实情况和信息**；隐瞒或欺诈叠加《消费者权益保护法》第五十五条 = **退一赔三**（本仓库已对照 moj.gov.cn 原文核验） | 车商的生存问题不是"车况好不好"，是"**能否证明自己如实告知过**"。证明成本（把口头承诺变成拿得出手的书面记录）是整个痛点的第一性变量 |
| F2 | 司法实践把查明义务压给专业经营者：通识口径下，车商作为专业经营者负有主动查明车况的义务，**"不知情"抗辩不成立**；2023 年以来调表车、事故车退一赔三判例持续出现（公开报道口径），赔偿 = 3 倍车价 + 退车 + 维权成本——一台 10 万元的车，尾部风险 40 万起 | 风险与利润严重错配：一台车的毛利几千元，一次败诉赔掉几年的利润。**收车那一刻"已知什么、未查什么"的记录质量，决定纠纷发生时车商是自证清白还是背锅垫底** |
| F3 | 2022 年起新政把车商推向企业化留痕：商务部等 17 部门《关于搞活汽车流通 扩大汽车消费的若干措施》（商消费发〔2022〕92 号）推动二手车经销企业化（减征增值税、反向开票、取消限迁）——从"背户黄牛"到"备案经销主体"的行业迁移正在进行时 | 合规主体 = 留痕主体：个人倒卖可以不负经营者责任，**企业化经销必须留下经营者级别的告知证据**。行业形态变化把"披露留痕"从可选项变成身份的一部分 |
| F4 | 市场量级真实：2024 年全国二手车交易 **1961.42 万辆**、2025 年首破 2000 万辆（中国汽车流通协会口径）；车商数量通识口径 20 万+（含 1~30 台在库的小微车商），物理上聚集在 600+ 二手车交易市场 | 沉默的大多数是小微车商：没有 DMS、没有库管系统，一个人一台手机完成收车到交车全流程 |
| F5 | 库存即资金：收车价几万到几十万，在库每一天都在烧钱（资金利息 + 场地 + 贬值 + 行情下行）。小微车商对"哪台车压了多久、压了多少"只有**感觉**，没有数字 | 库存账 = 资金账：把"感觉压了很久"变成"总成本 × 在库天数"的可比数字，清库决策才有依据。台账同时是**合规底账**与**经营仪表盘** |
| F6 | 小微车商的现状解法 = **记忆 + 微信口头 + 手机备忘录 + 纸质收据**：收车信息不落档、整备成本散在微信转账记录、披露靠口头"你放心"、卖完毛利全凭印象；检查或纠纷时翻不出任何东西 | 现状解法的失败不在"不懂法"，在**记录的成本高于记录的价值感知**——直到判例把记录的价值标价成 40 万。动作成本必须打到"顺手"级，价值叙事必须贴着"止损" |
| F7 | 买家端信任是成交的转化瓶颈：二手车口碑是柠檬市场重灾区，买家默认防着调表/事故/水泡；车商越坦荡越难成交，越遮掩越容易踩雷 | 一张有"未核查"栏的披露单反而制造差异化：**敢写"未核查"的车商，等于当着买家把牌翻开**——披露单同时是自证凭据与成交话术 |
| F8 | 收车价、毛利、买家信息是商业机密；车商的经营终端就是手机微信；出险/维保查询平台是既定的数据通道 | 本地优先（数据不出设备）是机密与成本双重最优解；工具**不做估价、不做查询、不碰支付、不碰过户**——与查询平台、车务服务商互补不竞争 |

**第一性结论**：二手车商的生存确定性 = 「已知车况的书面留痕度 × 交车环节的可证明性 × 库存资金的可视度」，三件事共用**同一本车档**。谁把"收车落一笔档、交车出一张披露单"的成本打到趋近于零，谁就把退一赔三的尾部风险，变成小微车商用得起的自证资产。

## 2. 痛点 - 爽点 - 痒点模型（梁宁）

| 层 | 用户心理 | 车况单对应 |
|---|---|---|
| **痛点**（恐惧/怕） | 怕买家回头说"你没告诉我这是事故车"，法院判退一赔三；怕"我不知道"成为败诉理由；怕行情下行时说不清哪台车该割肉；怕整备花了多少算不清，卖完发现白忙 | 九项披露建档即亮「未核查」灯（不装懂）；售出前门诊点名；库存黄线红线 + 资金占用排行；毛利永远由流水现算——尾部风险在爆发前被看见 |
| **爽点**（即时确定性） | 收车 30 秒建档，查完一项销一项；买家微信问车况，复制披露单 10 秒回复；交车打印一张带签字栏的披露单各留一份；月底毛利自动汇总 | 建档即体检 + 披露单三通道（微信文本 / 打印 HTML / 直接打印）+ 月度经营账 |
| **痒点**（虚拟自我） | "我的小车库比大车行还规范"；"我敢把每一项都写清楚，包括没查到的" | 印着车行名称与签字栏的披露单——小微车商的"坦荡专业"身份叙事 |

优先级：痛点 > 爽点 > 痒点。MVP 只做痛点与爽点，痒点靠披露单的品牌落款顺手满足，不做估价、不做获客、不做金融对接（见阶段三 ERRC）。

## 3. JTBD（待办任务）

**主任务陈述**：**当**收进一台车、买家微信问"有没有事故"、交车签合同、过完户要算这笔赚了多少、月底盘点哪台车压太久时，**我要**说得出"这车我知道什么、没查什么、告诉了买家什么、花了多少、压了多少"，**以便**卖得安心（不怕赔三）、赚得明白（毛利清楚）、资金转得快（超期先清）。

| 维度 | Job | 现状方案的失败点 |
|---|---|---|
| 功能性 | 收车落档（九项三态）；整备成本逐笔记；披露单产出；售出毛利结算；库存超期点名 | 记忆不聚合、备忘录无预警、披露单成本高、毛利全凭印象 |
| 情感性 | 买家来问时不心虚、不含糊；纠纷谈判不蒸腾成对抗 | "你放心没问题"本身就在积累风险；一旦被诉，翻不出任何书面痕迹 |
| 社会性 | 向买家（明白消费）、向市场管理方（规范商户）、向同行（专业口碑）证明"我是认真做车的" | 没有任何体面的告知载体 |

**竞品不是别的 SaaS，而是「记忆 + 微信口头 + 备忘录 + 什么都不记」**——它们免费且是行业默认动作，这是我们真正的敌人（见阶段二波特五力：替代品威胁）。

## 4. 船模型

> 用户要的从来不是船，是安全过河。这里河对岸 = 卖得安心、赚得明白、资金转得快。

| 元素 | 本场景 | 现状问题 |
|---|---|---|
| 乘客 | 1~30 台在库的小微二手车商（市场驻户 / 临街车行 / 赶集式车贩） | — |
| 船 A：记忆 + 微信口头 + 备忘录 | 现状默认解，零成本 | 车况靠脑子、承诺靠口头、成本靠翻转账——出事时一片空白；库存压钱全靠感觉 |
| 船 B：车行 DMS / 收银 SaaS | 中大车行的全家桶（收银、库存、客户管理） | 为"30 台以上 + 多员工"设计：按年费收钱、重实施、要培训；小微要的是"把车况说明白、把毛利算清楚"，不是一套门店系统 |
| 船 C：出险/维保查询平台（车300、查博士等） | 查记录的数据工具 | 按次收费查**别人的记录**，查完就完了——不帮你把"我查过什么、告知了什么"留下来；查询是原料，留痕才是资产 |
| 船 D：纸质买卖合同模板 | 成交时才补的文书 | 合同里一句"车况以实车为准"保护不了卖方；没有逐项告知与签字确认链，"口头告知"在法庭上等于没说 |
| 河 | **已知车况与对外披露之间的证据黑箱 + 库存资金黑箱**：说没说过说不清，压了多少钱算不出 | 四条船共同的黑水区 |

**定位推论**：车况单**不造 SaaS 的船，也不造查询平台的船**，做挂在所有船上的"披露底账 + 资金仪表盘"——车况信息从哪来（查询平台、第三方检测、卖家口述）不重要，重要的是"收车之后我知道了什么"第一次有了可交付给买家的书面形态。与查询平台互补（它产原料，车况单管留痕与交付），与 DMS 互补（轻车商用不上 DMS），与口头承诺正面对抗但迁移成本 ≈ 0（还是微信，只是从"你放心"变成"发披露单"）。

## 5. 非消费者分析（Christensen）

| 非消费者类型 | 画像 | 为什么不用现有解 | 对产品的启示 |
|---|---|---|---|
| 夫妻老婆店 | 2~5 台车，一张桌子一个院 | "披露是大车行的事"；DMS 是连锁用的 | 免费开始；5 台内全功能；名词全部说人话（"披露"不叫"告知义务履行"） |
| 赶集式车贩 | 无固定铺面，手机就是全部家当 | 用不上门店系统；怕留痕迹反而留不住生意 | 手机 PWA 离线可用；披露单走微信文本，买家零安装 |
| 大车行的库管 | 公司有 DMS，但库管自己还在 Excel 记整备 | DMS 管钱不管车况留痕 | 单车档案可以平行存在：库管先把车况账记起来 |
| 新能源/营运退役车商 | 网约车退役、电车电池衰减，披露项更复杂 | 现有模板不管营运历史与电池 | 九项披露含营运历史，异常备注自由文本兜底 |

非消费者共同阻碍排序：**觉得"披露是自曝"（叙事风险）> 觉得"建档是文书"（动作成本）> 觉得"小买卖没人告"（风险错觉）**。MVP 依次对应：披露单文案以"坦荡专业"为基调（未核查也是如实，反而制造差异化）、建档 30 秒、看板用判例口径把尾部风险标价。

## 6. PESTEL 宏观扫描

| 维度 | 要点 | 对本机会 |
|---|---|---|
| **P** 政治 | 2022 商务部等 17 部门新政推动经销企业化（备案、反向开票、增值税减征、取消限迁）；消法 55 条退一赔三持续适用 | 合规主体扩张 = 留痕主体扩张，顺风；企业化进程把披露证据变成身份的一部分 |
| **E** 经济 | 汽车以旧换新政策放大置换车源；新车价格战挤压二手车价差，行业利润率收窄 | 利润越薄，"止损逻辑"（避赔三、快周转）越比"增长逻辑"值钱；置换车源增加 = 建档需求增加 |
| **S** 社会 | 二手车是柠檬市场口碑重灾区；买家维权意识与检测普及度上升；车商群体年轻化（90 后车商用工具、发抖音） | 信任稀缺 = 披露单是成交资产；年轻车商对轻工具零教育成本 |
| **T** 技术 | 出险/维保查询平台成熟（按次付费）；微信是车商-买家沟通的绝对通道；PWA/打印是系统级能力 | 查询平台是披露单的**原料管道**（互补）；微信文本通道恰好补位交付 |
| **E** 环境 | 新能源置换潮带来营运退役车源，电池健康度、营运历史等披露维度更复杂 | 披露复杂度上升 = 留痕价值上升（MVP 以自由备注兜底，结构化电池披露进迭代池） |
| **L** 法律 | 判例口径持续强化卖方举证：隐瞒事故/调表的退一赔三判决常态化；《二手车交易规范》要求签订规范合同并附车况信息 | 车况披露单 + 买方签字 = **举证资产**——记录的完整、即时、规范直接服务诉讼与调解 |

结论：宏观无逆风。P（企业化新政）与 L（判例潮）双顺风，S（柠檬市场信任赤字）让披露从成本变资产；E（利润收窄）约束定价但不约束机会成立；T（查询平台存在）被"互补定位"结构性化解——做平台不做的事（留痕与交付），不做平台做的事（数据查询）。

## 7. 机会缺口矩阵

以"用户重要性 × 市场现有解完整度"定位空白：

```
重要性 高 │ ①估价/出险维保查询          ③【空白】车况披露底账 + 库存资金账
          │ （车300/查博士等，按次查询）  （收车建档/未核查门诊/披露单三通道/
          │                              毛利现算/库存黄线红线，无小微级轻产品）
重要性 低 │ ②车行 DMS/收银全家桶        ④车商金融/集采/获客代运营
          │ （中大车行，重实施）          （重资金或重人力）
          └─────────────────────────────
             现有解完整度 高            低
```

- ③的四段拆解交叉验证：记忆口头（无留痕）、查询平台（产原料不留痕）、DMS（管钱不管披露）、合同模板（成交才补、无签字链）——**每一段都有人做，合起来无人做**。
- ①是查询平台的主场，按次收费模式成熟；③覆盖的是沉默的大多数（1~30 台小微车商）。
- ②与④偏离主线，无冲突也不碰。
- 政策与产业事实给 ③ 背书：第十四条告知义务生效多年、退一赔三判例常态化、2022 新政把车商推入企业化留痕时代、2024 年 1961 万辆的交易量证明协作密度——**规则已生效、痛点有量级、轻产品空白仍在**。

**阶段一结论**：车况单占位 ③——一条被如实告知义务、退一赔三判例潮与经销企业化新政共同供养、被"记忆 + 口头 + 备忘录"证明协作真实存在、却被查询平台与 DMS 同时忽略的缺口。
