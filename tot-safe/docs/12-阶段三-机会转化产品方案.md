# 12 · 阶段三：机会转化产品方案

## 1. 商业画布（九格）

| 格 | 内容 |
|---|---|

| 客户细分 | 1~10 班小微民营托育机构（主）；幼儿园托班/单位办托（次）；托育协会/妇幼保健院/普惠验收服务商（渠道） |
| 渠道 | 上游即渠道联营（保健院儿保科辅导包/协会会员福利/普惠验收服务商白标）；地推单城打法；小红书园长社群 |

| 成本结构 | 开发（已沉没，系列复用后边际≈0）；获客（地推人力为主）；法规维护（每季度一次口径复核） |

## 2. 价值主张画布

**客户任务**：合规任务（备案/证照/健康证/配比/晨午检/演练/年报）、运营任务（排班/接送/消毒）、招生任务（家长参观/比价）。
**痛点**：忘期、补签、超配比、检查焦虑、家长问询答不上、幼儿健康事件说不清。
**收益期待**：不被罚、不担责、省时间、招生时有得展示。

**产品映射**：痛点 relief——三证钟/健康证钟（忘期→红黄绿）、晨午检同日同段唯一+异常强制处置（补签→不可补）、配比引擎（超员→开闸即拦）、迎检自证包 10 秒出（焦虑→从容）、健康事件状态机（说不清→全程留痕）。收益 creator——家长信任公示单（招生第一张纸）、当日送托单贴门（接送场景的可见合规）、月度小结（举办者/家长群的存在感）。

## 3. 蓝海战略四动作（ERRC）

| 动作 | 内容 |
|---|---|
| 剔除 Eliminate | 云端账号体系、培训成本、与接送/伙食/招生无关的后台功能 |
| 减少 Reduce | 每日录入到 ≤3 分钟（晨午检两段打勾为主）；证照录入到「照着证件抄一个日期」 |
| 提升 Raise | 拦截的法条解释力（每条拒绝理由都带条号）；出证的仪式感（快照+签字栏+脱敏公示） |
| 创造 Create | **家长信任公示单**——行业里没人把「信息公示义务」做成招生物料；合规雷达（立法在途显式提示） |

## 4. USP

> 唯一一款「法条内嵌、开园过闸、家长可看」的托育合规台账：拦截理由精确到条号，出证物直接可贴招生现场，数据不出本机。

## 5. Kano 模型

- **必备（M）**：证照/健康证到期提醒、晨午检留痕、配比核算、数据备份导出——没有即一票否决。
- **期望（O）**：六道闸拦截+法条理由、月度小结、迎检自证包——越准越好。
- **魅力（A）**：家长信任公示单、当日快照回放、合规雷达立法追踪、混合班配比属地参数化——传播点。
- **无差异（I，明确不做）**：财务/收费管理、家长聊天、照片直播、课程体系。

## 6. 供应链分析

**产品侧供应链**（做这个产品需要什么）：零依赖开源栈（HTML/JS/Node test/playwright）→ 供给无限、成本 0；法条数据源=gov.cn 政策库/卫健委法规司 PDF/教育部官网（一手核验，见 docs/14）→ 免费、可持续；无硬件、无第三方 API → 无断供风险。

**产品自身供应链**（产品在客户侧的运行链）：浏览器（手机自带）→ localStorage（本机）→ 出证物（单文件 HTML/打印/文本）→ 纸/微信。全程无服务器、无账号、无支付通道依赖——供应链最短，单点故障只有「浏览器存储被清」（缓解：导出备份+设置页引导）。

**分发供应链**（怎么到园长手里）：三级——①**上游即渠道**：区妇幼保健院儿保科（卫生评价/年检辅导场景天然接触园长）、托育协会（会员福利白标）、普惠验收服务商（验收辅导包内嵌）——白标 ¥1200/年/园，渠道拿 50%；②单城地推：扫园+30 秒示例演示；③线上：园长社群内容（「晨午检怎么查才不踩雷」）。第一桶金主打 ①：一批 10~30 家的协会/保健院订单即可验证付费假设（H5/H6）。

## 7. MVP 边界

**做**：机构建档三证钟、人员名册双钟、婴幼儿名册查验闸、配比引擎、晨午检卡（供餐/乳儿班类型驱动）、健康事件状态机、隐患状态机、送托六道闸+快照、变更备案、周期义务账（7 类）、十项体检、月度小结、迎检自证包、当日送托单、家长信任公示单（HTML/打印/文本）、导入导出、合规雷达。
**不做（MVP 外）**：家长端 App、接送打卡硬件、预收费资金对接、多园连锁视图、食谱营养计算、政府报送接口。
