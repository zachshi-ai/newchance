# 00 · 总览：从痛点到 MVP —— 托安单 TotSafe

> 一句话：把托育机构「每天必须做、检查必须查、家长最想看」的合规动作，装进一部手机的六道闸与四张纸里——**证在期、配比够、检已落，六道闸全过，这个早晨才开园。**

## 一、痛点（第一性原理切到底）

托育是「备案制 + 多线监管」密度最高的民生行业之一：卫健（备案/卫生保健/晨午检）、消防（年度检查合格证明）、市监（营业执照/食品经营许可证）、住建（场地）、公安（保安派驻/无犯罪核查）五线都管。而机构侧的现状解法是**纸质登记本 + 微信群 + 园长记忆**：健康证过期了谁还记得？乳儿班 1:3 的配比排班靠感觉；晨午检本子补签；家长问「你们消毒记录呢」只能翻柜子。**监管要的不是「你做了」，是「你能随时证明你持续做了」；家长要的不是「你安全」，是「你让我看见安全」。** 证明成本就是这个行业的第一性变量——它同时是合规成本和获客资产。

## 二、方案（零依赖本地优先 PWA）

机构建档（备案+消防年度证明/食品证/租约三证钟）→ 人员名册（健康证全员年检钟+岗位资质钟）→ 婴幼儿名册（接种证+入托体检查验闸）→ **每日晨午检卡**（异常逐人自动转健康事件：通知监护人→治愈凭证返园闭环）→ **送托六道闸**（备案证照在期/配比达标/证书在期/晨检已落/隐患闭环/健康事件处置，当场拦截带法条理由，放行存当日快照）→ 变更备案与周期义务账 → **四通道出证**：迎检自证包 / 当日送托单（贴园门口）/ 家长信任公示单（HTML+文本，脱敏）/ 月度小结（微信群）。

## 三、为什么现在（PESTEL-P 的窗口）

- **供给两年翻倍**：全国托育机构 12.6 万家（2025-12-26 卫健委发布，较前增 110%）、托位 666 万个——「入托难」正在变成「抢生源」，合规与信任直接决定招生；
- **立法在途**：《托育服务法（草案）》2025-12-22 初审（8 章 76 条），监管刚性只会上升；
- **普惠验收**：2025 年新增普惠托位 89.2 万个，普惠验收把台账与公示变成硬门槛；
- **育儿补贴落地**（2025 年起每孩每年 3600 元）持续抬升入托率。

## 五、诚实条款

技术可行性已在仓库内验证（**33/33 单元测试 + 31/31 浏览器端到端**）；商业假设（付费/留存/渠道）全部标注「待验证」并配有可证伪判据。本工具是机构自查、家长沟通与迎检备查的底账，**不替代备案、卫生评价、消防安全检查、食品经营许可等法定程序**；《托育服务法（草案）》尚未施行，现行口径锚定 58 号文两标准+76 号令+备案办法+WS/T 821，法律颁布后升级、不悄悄沿用草案条号。
