# 托安单 TotSafe · 托育机构合规台账（机会实验室 #31）

> 「证在期、配比够、检已落——六道闸全过，这个早晨才开园。」
> 面向 1~10 班小微托育机构（含幼儿园托班、单位办托）的零依赖本地优先 PWA：把卫健「人口家庭/托育服务」线的每日义务与周期义务装进一部手机，当场拦截不合规开园，四通道出证同时应付检查与招生。

## 痛点

全国托育机构 12.6 万家（卫健委 2025-12-26 发布，两年 +110%）、托位 666 万个——供给翻倍后行业从「拿托位」转入「抢生源」，合规与信任直接决定招生。而备案制+多线监管（卫健/消防/市监/住建/公安）的义务密度极高：消防年度证明、食品经营许可证、租期 ≥3 年租约、全员健康证一年一检、师幼配比 1:3/1:5/1:7 红线、每日晨午检两段、监控留存 ≥90 日、应急演习、年度报告……小微机构的现状解法是纸质登记本+微信群+园长记忆——**「做了」与「能随时证明」之间没有任何小微级工具，家长端更是空白。**

## 方案

- **机构建档三证钟**：消防安全检查合格证明（WS/T 821 4.1.4 年度口径）/食品经营许可证（供餐时）/场地租约（设置标准第 11 条 ≥3 年）红黄绿灯，备案回执登记。
- **人员名册双钟**：健康证全员年检钟（76 号令第 14 条+管理规范第 28 条）+负责人/保健/保安岗位资质钟（设置标准第 18 条）——过期禁上岗。
- **婴幼儿名册查验闸**：接种证（76 号令第 15 条(六)）+入托体检（管理规范第 11 条）未齐=红灯。
- **师幼配比引擎**：按乳儿班 1:3/托小班 1:5/托大班 1:7/混合班（从严 1:5）实时测算保育需求与收托上限（设置标准第 19/20 条）。
- **每日晨午检卡**：晨检+午检两段、同日同段唯一、条目按「供餐/乳儿班」自动增减；异常条目自动转隐患、异常幼儿逐人自动转健康事件。
- **健康事件状态机**：发现 → 通知监护人+处置意见（第 24 条）→ 凭治愈/健康证明返园核验（76 号令第 18 条）；疑似传染病报告留痕（第 16 条）；疑似家暴强制报案提示（第 25 条）。
- **送托六道闸**：备案证照在期 → 配比达标 → 证书在期 → 晨检已落 → 隐患闭环 → 健康事件处置——当场拦截带法条理由+埋点，放行存当日快照。
- **周期义务账**：应急演习/培训/消防设备月检/设施月检（含监控 90 日核查）/信息报送/年度报告/责任险（7 类打勾滚动）。
- **四通道出证**：迎检自证包（十段+签字栏）/当日送托单（贴园门口）/**家长信任公示单**（HTML+文本，全脱敏——把管理规范第 15 条信息公示义务变成招生物料）/月度小结（微信群文本）。
- **合规雷达**：《托育服务法（草案）》2025-12-22 初审（8 章 76 条）显式跟踪，颁布前不沿用草案条号。

## 快速开始

```bash
cd tot-safe
npm start          # → http://localhost:8109
npm test           # 33/33 单元测试
python3 tests/e2e.py   # 31/31 端到端（需 npm start 运行中；playwright+系统 Chrome）
```

## 诚实条款

技术可行性已在仓库内验证（33/33 单测 + 31/31 E2E）；商业假设全部标注「待验证」并配可证伪判据（docs/13 H1-H8）。本工具是自查、家长沟通与迎检备查底账，**不替代备案、卫生评价、消防安全检查、食品经营许可等法定程序**；属地卫健部门要求永远赢。幼儿与健康数据 100% 本机存储，出证物脱敏，埋点不含个人信息。
