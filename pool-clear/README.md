# 泳清单 PoolClear 🏊

> **小微游泳场所的水质自检台账与泳客信任公示台：每天两笔 30 秒，超线强制处置、复测才许闭环；缺检自动点名，迎检台账包一键打印；水质速报发家长群，公示页贴门上——敢晒才是真的干净。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 家长不用装 App

《游泳场所卫生规范》（卫监督发〔2007〕205 号）要求游泳场所每场开放前、开放时检测池水余氯、pH、温度并记录备查，**检测结果应公示并注明测定时间**；GB 37488-2019 把泳池水收紧到 pH 7.0~7.8、浑浊度 ≤1 NTU、游离性余氯 0.3~1.0 mg/L；《公共场所卫生管理条例实施细则》要求卫生管理档案至少保存两年，未按规定检测的可处 2000~20000 元罚款，情节严重的停业整顿直至吊证。小微泳馆的现状是纸台账 + 记忆 + 检查前突击：测了不留、留了不晒、晒了不闭环——抽检不合格公示一挂，家长用脚投票。泳清单把这段黑箱变成白箱：建档即口径（浸脚池单独 5~10 mg/L）→ 30 秒两笔打卡（超线强制留处置说明，复测达标才许闭环）→ 缺检自动点名、应检守恒体检卡 → 一键生成三样东西：微信家长群的**每日水质速报**、贴公示栏/发群里的**泳客公示页**、迎检用的**台账打印包**（含签字栏）。证照临期自动预警，数据 100% 本地。

## 3 条命令跑起来

```bash
cd pool-clear
npm start           # 等价于 python3 -m http.server 8088 --directory app
open http://localhost:8088
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程。

## 功能

| 模块 | 说明 |
|---|---|
| 🏊 **建档即口径** | 场馆（名称/卫生许可证号及有效期）+ 水池（主池/儿童池/浸脚消毒池/其他，消毒方式、投用日）+ 从业人员健康证 + 第三方全项检测报告——档案字段即台账落款；浸脚池单独口径（只测余氯 5~10，无 pH 要求） |
| 🧪 **30 秒两笔打卡（读数即判定）** | 余氯/pH 必测、浊度/水温选填；国标边界值闭区间判定（0.3~1.0 / 7.0~7.8 / ≤1 / 宜 23~30）；**超线强制填写处置说明才能落账**——异常不许裸奔进台账；同池同时点重复落账拒绝 |
| 🔁 **复测闭环链** | 处置后复测达标才许闭环（复测仍超线拒绝闭环）；未闭环异常一直挂在首页；删除闭环记录异常自动回到「待闭环」；连续全检天数是打卡习惯的第一钩子 |
| 📣 **三通道出证** | **每日水质速报**纯文本（微信家长群主通道，未检的池如实写「今日未检」）；**泳客公示页**单文件 HTML（贴公示栏/发群，未达标如实标「处置中」——205 号文公示义务的直接落地）；**迎检台账打印包**（体检卡：应检检次/足额/缺检点名/达标率/异常闭环率 + 逐日明细 + 签字栏） |
| 🔔 **证照临期预警** | 卫生许可证（四年）、健康证（年检）、第三方检测报告到期前 30 天自动进「今日」预警（天数可调） |
| 📒 **月度台账体检 + 数据自持** | 应检 = 天数 × 池数 × 每日频次，足额 + 缺检 == 应检守恒；达标率、异常闭环率、平均闭环时长按月汇总；限值口径全部参数化（属地口径永远赢）；100% 本地存储；JSON 导出/导入（换机迁移，含结构校验）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
池边网络差，PWA 离线可用；发速报走微信文本，不依赖任何在线服务；检测读数与泳客信息不出设备。**不做硬件、不做报送、不做教务**——在线监测平台与 CMA 检测机构是互补的原料管道，这里是场馆自己的自检台账与信任公示。

## 边界与免责

- **不做水质在线监测硬件、不做法定检测报送、不做会员/收银/教务**——读数手工录入（这是特性不是缺陷：读数来源无关，试纸、比色管、在线监测仪的读数一律手工落账；无硬件供应链负担、无报送合规负担、离线可用）。
- **台账是场馆自检留痕底稿，不是法定检测结论**：尿素、菌落总数、大肠菌群等实验室项目以 CMA 机构报告为准；本工具不宣称司法级存证，**法规原文、属地要求与检查人员口径永远赢**。
- **公示不粉饰**：未检写「今日未检」，超线未闭环标「处置中」；本产品不承诺「抽检必合格」。
- 限值口径默认为国标（GB 37488-2019 + 205 号规范）参数化，设置页可覆盖。
