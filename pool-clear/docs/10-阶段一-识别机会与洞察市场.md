# 10 · 阶段一：识别机会与洞察市场

> 本阶段回答：世界的哪个痛点值得做？用第一性原理拆到底，用 JTBD / 船模型 / 非消费者分析还原真实场景，用 PESTEL 扫宏观，用机会缺口矩阵定位空白。

## 1. 第一性原理拆解

不问"市面上有什么泳池 SaaS"，只保留不可再分的事实：

| # | 不可再分的事实 | 推论 |
|---|---|---|
| F1 | 水质自检是**每天真实发生**的法定动作：《游泳场所卫生规范》（卫监督发〔2007〕205 号）要求每场开放前、开放时检测余氯、pH、温度并记录备查（室内开放时每 2 小时测一次余氯）；检测结果**应公示并注明测定时间** | 泳馆的问题从来不是"要不要测"，是"测完之后什么都没留下"。**证明成本（把每天的达标变成可查证的记录并送到相信它的人眼前）是整个痛点的第一性变量** |
| F2 | 限值是刚性的、且被新国标收紧：GB 37488-2019 把人工游泳池水定为 pH 7.0~7.8（旧 6.5~8.5）、浑浊度 ≤1 NTU（旧 ≤5）、游离性余氯 0.3~1.0 mg/L；浸脚消毒池余氯 5~10 mg/L、每 4 小时更换（205 号文） | "凭手感加药、凭记忆记数"在新国标下系统性失效；试纸/比色管读数必须被结构化记录，否则无法对表——**判定口径本身应该是工具的一部分，而不是贴在墙上的记忆负担** |
| F3 | 不证明的代价阶梯上升：实施细则对未按规定检测水质者责令改正、警告、可处 2000 元以下罚款；逾期不改致卫生质量不符标准的处 2000~20000 元；情节严重的责令停业整顿直至吊销卫生许可证；卫生管理档案须分类记录、**至少保存两年** | 罚款是下限：抽检不合格名单公示（每年夏季各地卫监常规动作，公开报道口径）+ 家长用脚投票才是大头。**台账从"文书负担"变成"生存资料"——前提是它的维护成本趋近于零** |
| F4 | 泳馆的下游是"信任型消费"：家长选择带不带孩子来，水质是首要顾虑（每年夏季尿素、腺病毒等泳池舆情，公开报道口径）；微信家长群是泳培馆与家长沟通的绝对通道 | 水质证明天然有**营销资产属性**：敢每天晒水质的泳馆，等于当着家长把底牌翻开——公示既是义务的落地，也是获客武器。痛点与痒点共用同一份台账 |
| F5 | 检测的物理手段已经廉价成熟：DPD 余氯测试盒/比色管几十元级、耗材月频复购；pH 用比色或试纸；浊度目视比对。在线监测仪数千元级，是小微场馆的另一档预算 | 自检的数据源是**人工读数**——工具不需要绑定硬件，读数从试纸来还是从仪器来不影响台账成立（读数来源无关性）；这把供应链风险和价格门槛同时打掉 |
| F6 | 证照义务是周期性的、可预警的：卫生许可证有效期四年、须醒目公示；从业人员健康证每年一检；第三方全项检测（尿素/菌落/大肠，CMA 机构）按年度或泳季前进行 | 到期违约是纯遗忘问题——提醒是零成本的合规收益，顺手构成回访钩子 |
| F7 | 场馆高度分散且小微：社区泳培馆、健身房附属泳池、酒店泳池、学校机关泳池，单馆 1~5 个池、1~10 名员工；教练/救生员兼测水是常态 | 沉默的大多数没有预算上"智慧泳池"系统；工具必须是一个手机能完成的动作量级 |
| F8 | 泳池经营有强节奏：室内泳培全年两波（秋季学期 + 寒暑假），室外馆季节开放；卫生监督抽检集中在泳季 | 打卡习惯的建立期在淡季，台账的"变现时刻"在泳季抽检——产品节奏应与场馆经营节奏对齐 |

**第一性结论**：泳馆的生存确定性 = 「水质实际达标率 × 达标的可证明度 × 证明的可信达度」。三件事共用**同一本自检台账**：台账是处置的依据（达标）、迎检的档案（可证明）、公示的原料（可信达）。谁把"测完抄一笔、检查打一包、每天发家长群"的成本打到趋近于零，谁就把泳馆最重的合规负担变成最轻的获客资产。

## 2. 痛点 - 爽点 - 痒点模型（梁宁）

| 层 | 用户心理 | 泳清单对应 |
|---|---|---|
| **痛点**（恐惧/怕） | 怕卫监突击检查翻不出台账（罚款 2000~20000、停业整顿、吊证）；怕抽检不合格被公示、家长流失；怕"上次什么时候加的药"说不清；怕健康证/许可证过期了没人记得 | 每天两笔 30 秒落账（不再补抄）；缺检自动点名（突击检查也不虚）；超线强制处置说明 + 复测闭环（处置有据可查）；证照临期 30 天预警 |
| **爽点**（即时确定性） | 读数输入当场判定达标/超线；异常按话术处置、复测达标一键闭环；检查来了 10 秒打出一本带体检卡的台账；家长问"今天水质怎么样"，复制速报 3 秒回群 | 判定引擎 + 闭环链 + 迎检台账包一键生成 + 每日速报主通道 |
| **痒点**（虚拟自我） | "我的小馆比大馆还规范"；"我敢每天把水质晒给家长看——敢晒才是真的干净" | 印着场馆名与许可证号的泳客公示页（贴公示栏/发群）——小微泳馆的"透明专业"身份叙事，顺手把合规义务变成招生文案 |

优先级：痛点 > 爽点 > 痒点。MVP 只做痛点与爽点，痒点靠公示页的品牌落款顺手满足；不做硬件、不做报送、不做教务（见阶段三 ERRC）。

## 3. JTBD（待办任务）

**主任务陈述**：**当**每天开馆前测水、加药后复测、卫监上门检查、家长在群里问水质、健康证/许可证快到期时，**我要**拿得出"测了什么、多少读数、超线怎么处置的、复测是否达标"的完整台账，并把"今天水质达标"送到家长眼前，**以便**检查不慌（档案在）、处置不乱（闭环在）、招生不虚（公示在）、证照不漏（提醒在）。

| 维度 | Job | 现状方案的失败点 |
|---|---|---|
| 功能性 | 自检落账（读数即判定）；异常处置与复测闭环；缺检点名；迎检台账打包；每日公示；证照预警 | 纸台账补抄、异常凭记忆、缺检无人知、迎检靠突击、公示靠裱糊、证照靠运气 |
| 情感性 | 检查来了不心虚；出了舆情能自证"我们每天测、超线就处置"；加药有据不浪费 | 纸台账不敢给家长看，出事时翻不出"我们一直合规"的痕迹 |
| 社会性 | 向家长（透明透明再透明）、向卫监（档案规范）、向同行/加盟方（专业口碑）证明"我是认真管水的" | 没有任何体面的公示载体——公示栏是给检查看的，不是给家长看的 |

**竞品不是别的系统，而是「纸台账本 + 记忆 + 检查前突击」**——它免费且是行业默认动作，这是我们真正的敌人（见阶段二波特五力：替代品威胁）。

## 4. 船模型

> 用户要的从来不是船，是安全过河。这里河对岸 = 检查不慌、处置不乱、招生不虚、证照不漏。

| 元素 | 本场景 | 现状问题 |
|---|---|---|
| 乘客 | 1~5 个池的小微泳馆（社区泳培馆 / 健身房附属 / 酒店泳池 / 学校机关泳池） | — |
| 船 A：纸台账本 + 记忆 + 检查前突击 | 现状默认解，零成本 | 读数抄一遍就进抽屉、异常处置无闭环、缺检无人知、公示栏应付检查；出事时翻不出任何东西 |
| 船 B：会员/收银/教务 SaaS | 泳培馆常见的经营系统 | 管收银、管排课、管会员，**不管水质留痕**——水质在他们眼里是工程部的事，不是经营的事 |
| 船 C：在线监测仪 / 智慧泳池监管平台 | 数千元级硬件 + 城市级 ToG 试点（部分城市已推行水质在线监测公示） | 小微嫌贵、设备维护另算；平台管的是"监测与报送"，不管场馆自己的处置闭环，更不管把水质送到家长群里 |
| 船 D：第三方 CMA 检测 | 年度/泳季前全项检测报告（尿素/菌落/大肠） | 一年一份管不了每天；报告锁在抽屉里，家长看不见 |
| 河 | **每天真实发生的水质管理与检查者/家长能看见的证明之间的黑箱**：测了不留、留了不晒、晒了不闭环 | 四条船共同的黑水区 |

**定位推论**：泳清单**不造监测仪的船，也不造教务 SaaS 的船**，做挂在所有船上的"自检台账 + 信任公示"——读数从试纸来还是从监测仪来不重要（读数来源无关性，监测仪是互补的原料管道），重要的是"读数之后"第一次有了可查证的台账和可触达家长的公示形态。与监测平台互补（它管监测报送，泳清单管处置闭环与信任触达），与教务 SaaS 互补（管钱不管水），与纸台账正面对抗但迁移成本 ≈ 0（还是手机上两笔输入）。

## 5. 非消费者分析（Christensen）

| 非消费者类型 | 画像 | 为什么不用现有解 | 对产品的启示 |
|---|---|---|---|
| 社区泳培馆 | 1~2 个池，教练兼救生兼测水 | "智慧泳池是大馆的事"；教务系统里没有水质模块 | 免费开始；1~3 池全功能；名词全部说人话（"游离性余氯"界面简称"余氯"并附合规区间） |
| 健身房附属泳池 | 会籍思维，水质是成本项 | 没人为"看不见的收入"立预算 | 用获客叙事切（公示页 = 家长群的招生文案），台账是顺手记录 |
| 酒店泳池 | 工程部兼任，台账靠值夜班的顺手抄 | 系统是集团 IT 的事，单店插不上手 | 单馆可独立建档；台账包带场馆落款可打印交差 |
| 学校/机关泳池 | 对外开放时段短，后勤兼管 | 采购流程长、没人立项 | 个人先用的免费工具，打印台账包直接满足上级检查 |

非消费者共同阻碍排序：**"测了也没人看"（公示价值错觉）> "读数抄表麻烦"（动作成本）> "小馆没人查"（风险错觉）**。MVP 依次对应：速报/公示页直接发家长群（价值当场可见）、30 秒两笔（动作打到顺手）、首页把罚款阶梯与抽检公示标价（风险显性化）。

## 6. PESTEL 宏观扫描

| 维度 | 要点 | 对本机会 |
|---|---|---|
| **P** 政治 | 健康中国/全民健身政策扩容游泳供给；多地中考把游泳纳入选考 → 泳培刚需扩容；疾控体系每年对公共场所（泳池为重点）开展随机监督抽查 | 客群（泳培馆）与监管压力双扩张，顺风 |
| **E** 经济 | 泳培课时费几百到上千一期，家长付费意愿强；小微泳馆薄利、人力紧张 | 止损逻辑（避罚款、避舆情、快处置）比增长逻辑更值钱；工具必须省人力而不是费人力 |
| **S** 社会 | 每年夏季泳池舆情（尿素、腺病毒等，公开报道口径）反复教育家长关注水质；家长社群化（微信群）成为泳培馆标配 | 家长敏感度 = 公示的价值；微信群 = 速报的天然免费通道 |
| **T** 技术 | DPD 试纸/比色管廉价成熟；在线监测仪成本下行但小微仍嫌贵；PWA/打印是系统级能力 | 人工读数 + 结构化台账是当下的最优性价比；监测仪普及反而是原料管道升级（互补不替代） |
| **E** 环境 | 室外馆季节开放；高温季泳客多、水质波动大、换水加药频繁 | 夏季正是打卡高频期与抽检季；淡季（秋冬室内泳培期）是建档与习惯养成窗口 |
| **L** 法律 | 实施细则罚则阶梯（2000 → 20000 → 停业/吊证）；GB 37488-2019 收紧限值；205 号文把"公示"写成义务 | 义务成文 = 台账与公示是合规刚需而非经营偏好；限值收紧放大工具价值（判定口径内置） |

结论：宏观无逆风。P（泳培扩容 + 抽查常态化）与 L（义务成文 + 国标收紧）双顺风，S（舆情教育出的家长敏感度）把公示从成本变资产；T（试纸成熟）保证数据源零门槛；E（季节性）约束节奏但不约束机会成立。

## 7. 机会缺口矩阵

以"用户重要性 × 市场现有解完整度"定位空白：

```
重要性 高 │ ①在线监测仪/智慧泳池监管平台    ③【空白】场馆侧自检台账 + 泳客公示
          │ （大场馆与 ToG 主场，数千元级）  （30 秒两笔/超线处置闭环/缺检点名/
          │                                  迎检包/速报发家长群，无小微级轻产品）
重要性 低 │ ②会员/收银/教务 SaaS            ④泳池工程改造/获客代运营
          │ （红海，管钱不管水）              （重资金或重人力）
          └─────────────────────────────
             现有解完整度 高            低
```

- ③的四段拆解交叉验证：纸台账（不留不晒）、监测平台（管监测不管信任）、教务 SaaS（管钱不管水）、CMA 报告（一年一份锁抽屉）——**每一段都有人做，合起来无人做**。
- ①是大场馆与监管端的主场，小微嫌贵且它不做"处置闭环 + 家长触达"；③覆盖的是沉默的大多数（1~5 池小微泳馆）。
- ②与④偏离主线，无冲突也不碰（教务/消课属教培领域，本仓库 5 号项目消课单已占位，领域互斥）。
- 法规与产业事实给 ③ 背书：自检与公示义务成文多年、国标收紧、抽检公示常态化、家长群触达通道现成——**规则已生效、痛点有场景、轻产品空白仍在**。

**阶段一结论**：泳清单占位 ③——一条被自检公示义务、国标收紧与夏季舆情共同供养、被"纸台账 + 突击"证明协作真实存在、却被监测平台与教务 SaaS 同时忽略的缺口。
