# 00 · 总览：从世界痛点到可运行 MVP

> 项目：**宠托付 PetHandoff** —— 宠物托养交接单生成器
> 仓库：`newchance` · 状态：MVP 已开发并通过端到端验证（`app/` 目录，18/18 单元测试）
> 一句话：**当主人离家，照护质量 = 信息质量 × 照护者的执行力。宠托付把"信息质量"从口头叮嘱升级为一张结构化、可送达、可留痕的托养交接单。**

## 1. 痛点（真实世界，有据可查）

每逢节假日，数千万养宠家庭面对同一个问题：**把毛孩子交给谁，怎么交？**

- 中国城镇犬猫消费市场 **3002 亿元**（2024，+7.5%），犬猫总数 **1.24 亿只**；**83%** 宠物主把宠物视为家庭成员（[来源](14-调研来源.md#白皮书与市场数据)）。
- 节假日寄养价格普遍上涨 **30%~50%**、仍"一窝难求"，小型犬单日 357 元（新华网）；催生了上门喂养/"宠托师"新业态（单次 30~100 元）。
- 媒体与司法案例显示的断层：宠物走失、生病、受伤、断粮时有发生；寄养纠纷对簿公堂（犬受伤送医 8200 元）；行业"收费不透明、操作不规范"。
- 专家建议的第一道防线恰恰是本产品的核心：**"详细交接宠物喂养信息（如用药剂量、喂食量）"** —— 而现状是微信长语音、口头叮嘱和碎片记忆。

**第一性差距**：照护者拿到的是"主人以为说清楚了"的信息，不是"谁来看都能照做"的信息。

## 2. 方案（机会 → 产品）

**宠托付**：零依赖、本地优先的 PWA。

1. **宠物档案**：一只宠物的全部照护要素（喂食/用药/禁忌/应激/日常）。
2. **托养交接单**（核心）：选宠物、填托养时段与联系人，一键生成**照护者视角**的单页交接单 —— 下载 HTML 微信发送 / 复制纯文本粘贴 / 打印贴航空箱。禁忌项红条置顶，易走失体质自动警示。
3. **免疫·驱虫日程**：按犬/猫模板推算下次到期，30 天预警进首页待办。
4. **照护日志**：交接期间照护者随手记，主人远程掌握。
5. **禁忌速查**：犬猫常见有毒食物/植物，交接前 30 秒扫一遍。

## 3. 诚实的现状声明（真实可落地，不空中楼阁）

- **已验证**（本仓库内可复现）：核心逻辑 18/18 单元测试通过；浏览器端到端流程（建档 → 示例数据 → 待办计算 → 交接单生成 → 三通道输出）真实运行通过；零 npm/CDN/API 依赖，任意静态服务器 3 条命令可跑。
- **未验证**（需真实用户，见 docs/13 假设登记册）：付费意愿 H5、照护者真实使用率 H2、留存 H3 等 —— 全部以假门/访谈/埋点计划列出，判据可证伪，不预设成功。
- **边界与免责**：不做医疗建议；疫苗/驱虫模板标注"遵医嘱"；数据 100% 本地存储，无私有云。
