# 宠托付 PetHandoff 🐾

> **2 分钟，生成一张照护者真正会看的宠物托养交接单 —— 微信一发即达。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 不构成医疗建议

当主人离家，照护质量 = 信息质量 × 照护者的执行力。宠托付把"微信长语音 + 口头叮嘱"升级为一张结构化、可送达、可留痕的托养交接单：禁忌红条置顶、喂食精确到克、用药剂量单列、紧急联系与常去医院一页俱全。

## 3 条命令跑起来

```bash
cd pet-handoff
npm start          # 等价于 python3 -m http.server 8080 --directory app
open http://localhost:8080
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程。

## 功能

| 模块 | 说明 |
|---|---|
| 📄 **托养交接单** | 选宠物、填时段与联系人 → 一键生成。三通道送达：**下载 HTML 文件**（微信/QQ 发送）、**复制纯文本**（微信直接粘贴）、**打印/存 PDF**（贴航空箱）。禁忌红条置顶、易走失体质自动警示、喂食全天总量自动合计、时间戳版本声明 |
| 🐶 宠物档案 | 多宠管理：种类/品种/生日/体重/绝育/芯片/识别色 |
| 🥣 护理指令 | 照护者视角：喂食计划、用药/保健品、禁忌、性格与应激点、走失风险、日常事务 |
| 💉 免疫·驱虫日程 | 内置犬/猫模板（行业惯例，遵医嘱），自动推算下次到期，30 天预警进首页待办，过期置顶 |
| 🧾 照护日志 | 交接期间随手记（喂食/饮水/遛弯/铲屎/用药/异常），一键复制发给主人 |
| ☠️ 禁忌速查 | 犬猫常见有毒食物/植物速查，注明"不完整、不构成医疗建议" |
| ⚙️ 数据自持 | 100% 本地存储；JSON 导出/导入（家庭备份、换机迁移，含结构校验）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md#6-供应链分析重点软硬两条链)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
除托管平台外零第三方依赖，PWA 安装后完全离线。数据不出设备，隐私是架构属性而非承诺。

## 边界与免责

- 本应用不构成医疗建议；疫苗/驱虫模板为行业公开惯例，个体方案请遵医嘱。
- 疑似误食有毒物质请立即联系兽医，不要等待症状出现。
- 数据仅存于本机浏览器；清除浏览器数据 = 删除档案，请用「设置 → 导出备份」。
