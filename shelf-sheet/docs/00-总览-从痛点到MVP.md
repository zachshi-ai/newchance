# 00 · 总览：从痛点到 MVP（药清账 ShelfSheet）

> 机会实验室 **#21 号项目** · 药品零售监管线 · 小微零售药店效期时钟与 GSP 养护合规台账。
> 本文档是四阶段方法论的地图：每一个框架都真实应用于本项目（细节见 10~14 号文档），不是模板套话。

## 一句话

**过期一盒，罚没一年——下架永远比辩解便宜**——药清账把小微零售药店每天真实发生的效期管理、温湿度日双录、凭处方销售的拒售留痕、月度养护变成拿得出手的合规痕迹，检查来了 30 秒出迎检自证包。

## 痛点

零售药店的法定义务每天都在走：药品按批号管效期（第 57 条）、直接接触药品人员每年健康检查（第 50 条）、储存采取冷藏防潮防虫鼠措施并做监测记录（第 59 条、84 号令第 41 条）、处方药凭处方销售且不得开架（条例第 43 条、84 号令第 42 条）、药品经营许可证 5 年一换（条例第 42 条）。而**超过有效期的药品是劣药**（第 98 条）：销售劣药货值 10~20 倍罚款，**零售不足 1 万元按 1 万元计算**（第 117 条）——一盒 15 元的药，罚款 10 万~20 万元起步；未遵守 GSP 逾期不改罚 10 万~50 万元（第 126 条）。而占绝大多数的单体药店与 1~10 店小连锁的现状解法是效期靠记忆、温湿度纸表格补签、拒售不留痕、检查前突击清货架——**"货架上的效期债"与"能证明的效期管理"之间没有任何小微级工具**。

## 方案

零依赖本地优先 PWA——四本账 + 五只钟 + 三种出证：

- **四本账**：药品建档与批次效期账（批号/效期照包装抄，三色档自动点名）、温湿度日双录（上午/下午各一笔，超限必须写处置并复测销案）、拒售登记簿（无处方不卖、不合格处方不调配——拒下的每一单都是没被罚的证据）、养护与隔离报损账（月度养护打卡、下架隔离自动生成待处置单、销毁/退货留痕销案）。
- **五只钟**：许可证 5 年钟、药师注册证钟、效期三色钟（催销 180 天/红线 90 天，参数化）、温湿度漏录钟、周期义务钟（健康检查 365 天为《药品管理法》第 50 条口径/温湿度计校准/药事培训）。
- **三种出证**：近效期催销处置单（贴柜台照单执行，双签字）、迎检自证包（单文件 HTML 含签字栏，持续合规对口第 53 条）、月度小结（微信文本）。

## 快速开始

```bash
cd shelf-sheet && npm start   # → http://localhost:8098
npm test                      # 纯逻辑层单元测试（node --test）
```

## 诚实条款

技术可行性已在仓库内验证（26/26 单元测试 + 浏览器端到端：建档 → 示例数据 → 看板红灯 → 进货建批三色档 → 出库转隔离 → 温湿度补录与超限处置 → 拒售登记 → 月度小结与体检 → 刷新持久化 → 迎检包下载全链路）；本工具是药店自查与效期管理的底账——不碰进销存与财务、不做医保结算、不做追溯码报送、不碰电子处方与审方；温区限值与近效期阈值为参数化通识口径，**药品说明书标示的储藏条件、属地规则与连锁制度永远赢**；法定条号全部为现行版口径（《药品管理法》2019 修订、《实施条例》2026 修订国务院令第 828 号、84 号令）并集中于 docs/14 逐条带出处维护；顾客信息最小披露只存本机；商业假设全部标注"待验证"并配有可证伪判据。
