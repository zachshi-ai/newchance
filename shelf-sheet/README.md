# 药清账 ShelfSheet 💊

> **小微零售药店的效期时钟与 GSP 养护合规台账：效期三色档自动点名、温湿度日双录、拒售登记簿、近效期催销处置单——过期一盒罚没一年，下架永远比辩解便宜，检查来了 30 秒出证。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 数据不出设备

零售药店的法定义务每天都在走：药品按批号管效期（《药品管理法》第 57 条）、直接接触药品人员每年健康检查（第 50 条）、储存采取冷藏防潮防虫鼠措施并做监测记录（第 59 条、84 号令第 41 条）、处方药凭处方销售且不得开架（《实施条例》第 43 条、84 号令第 42 条）、药品经营许可证 5 年一换（条例第 42 条）。而**超过有效期的药品是劣药**（第 98 条）：销售劣药货值 10~20 倍罚款，**零售不足 1 万元按 1 万元计算**（第 117 条）——一盒 15 元的药，罚款 10 万~20 万元起步；未遵守 GSP 逾期不改罚 10 万~50 万元（第 126 条）。占绝大多数的单体药店与 1~10 店小连锁的现状是效期靠记忆、温湿度纸表格月底补签、拒售不留痕、检查前突击清货架——药清账把这段黑箱变成白箱：建档上钟 → 进货建批 30 秒（三色档自动点名）→ 每天 30 秒温湿度两笔（超限写处置即闭环）→ 无处方就拒售、拒售即登记 → 月度养护一键打卡 → 一键出催销处置单 / 迎检自证包 / 月度小结。

## 3 条命令跑起来

```bash
cd shelf-sheet
npm start           # 等价于 python3 -m http.server 8098 --directory app
open http://localhost:8098
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程。

## 功能

| 模块 | 说明 |
|---|---|
| 🏪 **药店建档 + 双证钟** | 名称/负责人/地址 + **药品经营许可证 5 年钟**（条例第 42 条、84 号令第 17 条，逾期=无证经营 15~30 倍罚款）+ 药师注册证钟（84 号令第 10 条配备义务）；临期 180 天点名 |
| 💊 **药品建档 + 进货建批** | 储藏分类照说明书抄（常温/阴凉/冷藏）；批次按**批号/效期**照包装抄（第 57 条购销记录字段口径），同药品同批号同效期唯一 |
| 🚦 **效期三色档** | 催销 ≤180 天 / 红线 ≤90 天 / 过期=劣药红线（参数化可覆盖）；最先到期的永远排最前；过期在架直接点名「第 98 条劣药、第 117 条零售不足 1 万按 1 万计罚 10~20 倍」 |
| 📤 **出库与隔离闭环** | 售出/下架隔离/退回/报损/召回五方式，超量**整体拒绝**（账实守恒）；下架隔离与召回自动生成待处置隔离单，销毁/退货销案留痕——不合格药品去向可追溯；误记可撤销（数量精确回滚） |
| 🌡 **温湿度日双录** | 上午/下午各一笔（同日同次唯一），场所温湿度+阴凉柜/冷藏柜读数，超限自动判定（限值参数化）；**超限的记录照样收，但必须写处置措施并销案**——84 号令第 41 条监测记录的台账化 |
| 🛑 **拒售登记簿** | 无处方索购/处方不合格/买赠要求，10 秒登记——凭处方销售处方药（条例第 43 条）、处方药不得开架与买赠（84 号令第 42 条）的现场痕迹；**拒下的每一单都是没被罚的证据** |
| 🗓 **养护 + 周期义务账** | 月度养护打卡（发现异常品种必写处置）；员工健康检查（第 50 条明文义务）/温湿度计校准/药事培训三类义务打勾自动滚动 |
| 🩺 **账本体检** | 八项灯位打分：许可证/过期在架/近效期红线/温湿度漏录/超限未处置/养护/药师双证/周期义务——迎检前先自查 |
| 📑 **三通道出证** | **近效期催销处置单**（贴柜台照单执行，质量负责人+营业员双签字）/ **迎检自证包**（单文件 HTML 含签字栏，八段全景，持续合规对口第 53 条）/ 月度小结（微信文本） |
| ⚙️ **数据自持** | 100% 本地存储；顾客建议只登记姓氏或尾号（最小披露），处方不留存（纸质原件按 84 号令第 42 条药店自存 5 年）；JSON 导出/导入（含结构校验）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
药店在县城也在乡镇，网络时好时坏，PWA 离线可用；月度小结走微信文本，不依赖任何在线服务；顾客信息只存本机（本地优先即《个人信息保护法》最小披露的实现方式）。**不做进销存与财务、不做医保结算、不做追溯码报送、不碰电子处方与审方**——收银系统、医保平台、追溯系统是互补不是对手，这里是药店自己的效期与养护底账。
