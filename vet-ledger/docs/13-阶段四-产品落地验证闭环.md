# 13 · 阶段四：产品落地验证闭环（兽诊账 VetLedger）

## 1. DSTE 主线（从市场洞察到执行）

市场洞察（docs/10：高频×高刚性空白格 + 2025 专项通知窗口）→ 战略意图（成为小微动物诊疗机构的"自证黑匣子"与处方守门人）→ 创新焦点（名册处方闸、超温冻结闸、患宠材料单）→ 业务设计（免费基线获客 + 出证时刻付费 + 经销商白标放大）→ 执行（本仓库 MVP → 90 天验证 → 渠道复制）。

## 2. MVP 范围（技术验证已在仓库内完成）

- 一本名册 + 六本账 + 四只钟 + 三道闸 + 三种出证（清单见 docs/00）。
- 纯逻辑层全部落进 `core.js` 纯函数，`node --test` 28/28 全绿；单文件 HTML 出证无外部资源、含签字栏与 XSS 转义。
- 浏览器端到端已验证：建档 → 示例数据 → 看板红灯 → 处方闸三连拦截 → 正常落账 → 超温冻结 → 免疫出证 → 医废移交 → 事件闭环 → 月度小结与体检随动作实时变化（40→60 分）。

## 3. HDD 假设登记册（H1~H8，全部可证伪）

| # | 假设 | 可证伪判据（30 天窗口） | 埋点（本地 traces 事件流） |
|---|---|---|---|
| H1 | 诊所愿意建档并登记许可证信息 | 建档后 7 日内填写证号+勾选公示 ≥60% | `save-station` |
| H2 | 人员名册被真实维护（不是摆设） | 建档 14 日内名册 ≥1 名执业兽医师且 30 日内有变动维护 ≥30% | `add-staff`/`toggle-staff` |
| H3 | 诊疗落账形成习惯 | 激活后第 4 周周落账 ≥3 天的诊所占比 ≥40% | `add-visit`（按日去重） |
| H4 | 冷链双录被执行 | 有疫苗批的诊所日均双录 ≥1.5 次；超温记录带处置说明 100% | `add-coldchain`（excursion 比例） |
| H5 | **处方闸真实拦截**（最有价值证伪点） | 有落账诊所中，30 日内出现 ≥1 次被拦截记录（助理开方/缺编号）的占比 ≥20%——**若几乎为零，说明名册是假的或没人走处方药流程，闸机叙事重写** | `add-visit` 失败事件 |
| H6 | 免疫台账被使用且出证 | 有疫苗批的诊所 30 日内 ≥1 条免疫记录 ≥50%；检查季迎检包导出率 ≥30% | `add-rabies`/`inspect` |
| H7 | 付费意愿成立 | 试用诊所 Pro 转化 ≥5%；或累计出证 ≥10 次的诊所转化 ≥20% | `paywall-view`→`pro-unlock` |
| H8 | 经销商渠道成立 | 3 家经销商试用白标中 ≥1 家付费续用且下游激活率 ≥30% | `channel-seed`（白标记来源） |

最有价值的证伪点：**H5**——处方闸是全产品差异化主张（USP），如果拦截从未发生，"名册处方权"叙事就是伪需求，价值主张要重写为纯出证工具。

## 4. OHELM 循环

Objective（动物诊疗的履责痕迹可自证）→ Hypothesis（H1~H8）→ Experiment（免费基线投放 20~50 家诊所：1~2 个县级经销商订货群 + 执业兽医继续教育班）→ Learning（埋点 traces 导出→假设判定）→ Metric（北极星+护栏）→ 下轮迭代（口径/摩擦/定价）。

## 5. 北极星与护栏

- **北极星：周活跃落账诊所数**（一周内 ≥3 天有诊疗落账）。
- 护栏指标：断更率（有档但连续 ≥7 天无落账占比）；冷链双录达成率（有疫苗批诊所的当日 ≥2 次占比）；处方缺口数（rxViolations>0 的诊所占比，产品自己的承诺指标：只降不升）。

## 6. 90 天验证排期（与行业节奏对齐）

| 周 | 动作 | 节点依据 |
|---|---|---|
| 1~2 | 仓库 MVP 冻结；找 5 家真实诊所做 30 分钟上手观察 | 修摩擦不改方向 |
| 3~6 | 免费基线投放 20~50 家诊所（1~2 个县级兽药经销商订货群）；每周导出 traces 判 H1~H4 | 常态期先养习惯；新证换发（2025-09 起全面启用新版许可证）后证照信息更新是天然接触点 |
| 7~9 | 联系 3~5 家兽药/疫苗经销商与宠物耗材商推白标试用（判 H8）；上线 Pro 付费开关（判 H7） | 经销商年底回款与下游合规盘点窗口 |
| 10~13 | 年度报告冲刺：盯"每年 3 月底前"节点（判 H6 出证与 H3 留存）；首批患宠材料单真实使用案例回访 | 年度报告钟是全产品最硬的日历锚 |
| 13 末 | 判定：北极星 ≥40 且 H3/H5/H6 至少两条通过 → 加渠道复制；否则回到摩擦重做 | 诚实条款：不把兴趣当验证 |

## 7. 第一桶金三路径（金额诚实标注）

1. **主路径·经销商白标**：县级兽药/疫苗经销商 ¥1500/年/商，白标分发其下游 100~300 家诊所。渠道动机：下游被停业=应收坏账；经销商自身有购销记录义务（条例第 28 条）——工具帮它把"下游规范"变成卖点。首单现实目标 **1 家 = ¥1500**。
2. **辅路径·诊所 Pro**：¥99/年（名册不限量+出证盖章版抬头+备份），30 家 = **¥2970**。
3. **备选·设备商联营**：冷藏柜/显微镜/检测设备商装机即开通（冷链钟与设备售后天然绑定），按 ¥10~15/台/年返佣——量小但零边际成本。

**第一桶金合计现实区间：90 天 ¥3,000~7,000**。不吹百万 ARR：这是乡镇与县域生意，验证优先于规模。
