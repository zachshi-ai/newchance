# 兽诊账 VetLedger 🐾

> **小微动物诊疗机构（宠物医院/诊所）的合规台账：人员备案名册 + 处方闸、病历三钟、疫苗冷链双录、医废移交钟、事件立即报告钟、年度报告钟——检查来了 30 秒出证，纠纷来了 10 分钟出材料单。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 数据不出设备

宠物诊疗是监管收紧最快的赛道之一：机构要**悬挂许可证并公示从业人员**（《动物诊疗机构管理办法》，农业农村部令 2022 年第 5 号，第 17 条）、**病历档案保存不少于 3 年**（第 22 条）、**每年 3 月底前报上年度诊疗情况**（第 30 条）、**变更名称/负责人 15 个工作日内办变更**（第 14 条）；**执业助理兽医师不得开处方**（《执业兽医和乡村兽医管理办法》，部令 2022 年第 6 号，第 19 条）、**使用未在本机构备案的执业兽医机构被罚 1000~5000 元**（2022-5 号第 35 条）；**过期兽药即劣兽药**（《兽药管理条例》第 48 条）、**无方使用处方药没收违法所得并处 5 万元以下**（第 66 条）、**严重不良反应立即报告**（第 50 条）。农办牧〔2025〕20 号把治理推到新高度：2025-09-01 起全面启用新版电子诊疗许可证，2025-11-30 前机构与备案兽医全部纳入兽医卫生综合信息平台。现状是诊疗记在病历本、温度抄在墙上表格、兽医证复印件塞抽屉、医废靠口头交接——兽诊账把这段黑箱变成白箱：建档上钟 → 名册取人 → 30 秒落账（人不对/无方/批次不可用，落账瞬间硬拒绝）→ 疫苗冷链每日两次双录（超温必须写处置）→ 一键出迎检自证包 / 月度小结 / 患宠材料单。

## 3 条命令跑起来

```bash
cd vet-ledger
npm start           # 等价于 python3 -m http.server 8104 --directory app
open http://localhost:8104
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程（含三道闸的拦截演示）。

## 功能

| 模块 | 说明 |
|---|---|
| 🏥 **机构建档 + 证照公示** | 名称/许可证号/诊疗范围/发证机关；**悬挂公示**勾选（第 17 条，未落实 1000~5000 元）；**变更钟**：市场主体变更登记日 +15 个工作日倒计时（第 14 条） |
| 👩‍⚕️ **人员备案名册** | 执业兽医师/助理/乡村兽医三类；**处方权的名册底座**——所有开方、出证动作从名册取人；离职停用不删除，历史处方仍可回溯到人 |
| 📋 **诊疗台账（处方闸）** | 30 秒一诊：主诉/诊断/人员/处方笺编号；**助理兽医师开处方药硬拒绝**（2022-6 号第 19 条）、**处方药无编号硬拒绝**（处方药办法第 7 条） |
| 💊 **兽药与疫苗批台账** | 进货核对/批号/效期三级灯（90/30 天/过期）；**过期即劣兽药，使用前闸机拦截**（条例第 48 条）；超温/异常批次**冻结闸**（解冻必须写判定结论） |
| 🌡 **疫苗冷链双录** | 每日两次、同日同时段唯一；区间参数化（默认 [2, 8]℃，按标签贮存条件）；**超温必须写处置措施，不许裸记** |
| 🐕 **狂犬免疫台账** | 免疫证明=养犬登记法定凭证（防疫法第 30 条）；**只认名册内执业兽医师签发**；疫苗批次过期/冻结则拦截接种 |
| 🗑 **医废与病死动物台账** | 暂存→移交闭环；暂存超线（默认 2 天，参数化）红灯点名（办法 2022-5 号第 26 条） |
| 🔔 **事件台账** | 不良反应/染疫两类；**严重的按"立即报告"口径**：当天闭环为按时、迟报如实打标不粉饰（条例第 50 条、防疫法第 31 条） |
| 🗓 **年度报告钟 + 周期义务账** | 每年 3 月底前报上年度（第 30 条，未报转致防疫法第 108 条）；消毒/冷藏设备/培训打勾自动滚动 |
| 🩺 **账本体检** | 十项灯位打分：公示/变更/名册/断更/处方/冷链/效期/医废/事件/年度报告——迎检前先自查 |
| 📑 **三通道出证** | 月度小结（微信文本）/ **迎检自证包**（单文件 HTML 含签字栏，十段对口第 17/22/23/26/30 条制度要求）/ **患宠材料单**（单次诊疗+同期免疫+同期冷链证据链，纠纷应对底稿） |
| ⚙️ **数据自持** | 100% 本地存储；宠主建议只登记姓氏或尾号（最小披露）；JSON 导出/导入（含结构校验）；本地 traces 事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
县域诊所在菜市场也在写字楼，网络时好时坏，PWA 离线可用；月度小结走微信文本，不依赖任何在线服务；宠主信息只存本机（本地优先即《个人信息保护法》最小披露的实现方式）。**不做进销存、不做 CRM、不做检疫申报与平台报送接口**——经营是 HIS 的事，报送是官方平台的事，这里是诊所自己的自证底账。

## 与仓库相邻项目的边界

- **#1 宠托付 pet-handoff**：C 端宠物寄养交接（宠主↔寄养人），无监管线；本项目是 B 端动物诊疗机构的监管合规台账——主体、法源、付费逻辑均不同。
- **#6 购销单 agri-ledger**：农业农村线·乡镇农资店**农药**购销台账；本项目是农业农村（畜牧兽医）线·**动物诊疗机构**诊疗合规——同部委不同司局，法源（防疫法/部令 2022-5、6 号/兽药条例 vs 农药管理条例）、主体、台账对象均不同。
- **#21 药清账 shelf-sheet**：**人用**零售药店 GSP 台账（药监线）；本项目是**兽医**诊疗机构（农业农村畜牧兽医线）——法源、监管机关、台账对象（诊疗活动+处方+疫苗冷链 vs 药品零售储运）全部不同。

## 第一桶金（详见 docs/13）

主攻「**兽药/疫苗经销商联营**」：经销商业务员每周拜访下游诊所，诊所被停业 = 应收坏账与货源断档；经销商自身有购销记录义务（《兽药管理条例》第 28 条）——帮下游合规存续 = 保护经销商自己的资产负债表与追溯台账。¥1500/年/商白标分发其下游 100~300 家诊所；诊所侧 ¥99/年 Pro。90 天现实目标 **¥3,000~7,000**，验证优先于规模。
