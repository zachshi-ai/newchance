# 11 · 阶段二：机会筛选评估（护学账 BusRoll）

## 1. 波特五力（诚实评估）

- **现有对手**：车队管理 SaaS（面向客运/物流大车队，万元级年费+实施）、校车监控平台（政府侧追溯报送）。**没有任何产品面向 1~10 台车的小微民办园/校车公司做「趟次点名自证」**——大平台管「车在哪」，没人管「点名有没有真发生」。
- **新进入者**：低壁垒（与全系项目一样诚实承认）——护城河只能靠法条颗粒度+点名状态机的正确性+属地口径库。
- **替代品**：微信群报「到了」+纸质点名表（零成本但零证明力、可事后补造）；幼儿园家委会监督（非制度化）。
- **供应商**：零依赖（本地 PWA、无云、无硬件），供应商议价力≈0。
- **购买者**：民办园与校车公司极度分散、议价弱，但付费习惯弱是真实风险——定价 ≤ 299/年 对齐「一次罚款 1 万」的心智账户。

## 3. TAM-SAM-SOM（宽区间诚实标注，权威口径待复核）

- **TAM**：全国校车服务涉及主体 = 配备校车的民办园 + 民办中小学 + 校车服务公司。教育部历年教育统计显示民办幼儿园数量在万级（近年因出生率下降持续收缩），专用校车保有量为十万辆级口径——**两数均标注「权威口径待复核」**，不作为收入测算的乘数。
- **SAM**：其中 1~10 台车、无 IT 系统、确有校车依赖（农村/县域/接送半径长）的小微主体，按行业通识约占一半以下——同样宽区间。
- **SOM**：上市首年可触达 = 渠道联营（校车服务商/经销渠道下级）+ 属地示范园，目标两位数付费单位；收入测算不预设渠道成功率。

## 4. 机会-可行性四象限

- **机会大+可行高**：趟次点名+证照钟（法规锚点全部原文核验、执法节奏可观察）→ **主攻**。
- **机会大+可行低**：家长定位直播（硬件/隐私/责任）→ 不做。
- **机会小+可行高**：演练培训题库（内容型、易复制）→ 不做。
- **机会小+可行低**：跨园区调度 → 不做。

## 5. 风险矩阵

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 民办园关停潮压缩 TAM | 高 | 中 | 定位「合规存续工具」——越出清越需要自证；定价覆盖短回收 |
| 记录被质疑「事后补」 | 中 | 高 | 点名含人数守恒与时序状态机（未检查不能点名、未点名不能下车），补造需整链伪造；底稿定位、不宣称司法存证 |
| 属地细则口径冲突 | 中 | 中 | 全参数化+「属地永远赢」条款；docs/14 逐条出处 |
| 大平台下延免费功能 | 低 | 高 | 深耕「趟次点名状态机+迎检包」的微小场景，平台看不上也不愿担责的颗粒度 |
| 事故连带舆情 | 低 | 高 | 诚实条款：工具不判真伪、只保完整与闭环；「台账是义务的底线不是事故的护身符」 |
