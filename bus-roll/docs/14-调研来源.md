# 14 · 调研来源与条号出处（护学账 BusRoll）

> 核验方法：全文以维基文库收录的《校车安全管理条例》全文为底本逐条摘录，并与地方政府 .gov.cn 原文转载（徐水区校车细则、山西省实施办法检索页）交叉核对条号；法规为国务院令第 617 号，2012-04-05 公布施行，**施行至今未修订、条号稳定**。检索受限口径如实标注。

## 一、《校车安全管理条例》（国务院令第617号，2012-04-05 公布施行）——本工具全部法定口径

| 条 | 原文要点（摘录） | 工具对应 |
|---|---|---|
| 第2条 | 校车=依照本条例取得使用许可，用于接送接受义务教育的学生上下学的 7 座以上载客汽车 | 适用范围 |
| 第9条 | 学校可以配备校车；道路旅客运输经营企业、城市公共交通企业及校车运营单位可提供校车服务 | 客户细分（学校/服务提供者双主体） |
| 第10条 | 建立健全校车安全管理制度、**配备安全管理人员**、加强安全维护、**定期对校车驾驶人进行安全教育** | 设置页安全管理人员字段；义务账 driverEdu |
| 第11条 | 学校与校车服务提供者签订**校车安全管理责任书**，报教育行政部门**备案** | 设置页责任书备案日 + 义务账 bookFile |
| 第12条 | 学校对教师学生监护人开展交通安全教育，**定期组织校车安全事故应急处理演练** | 义务账 edu / drill |
| 第14条 | 取得校车使用许可五条件，其中(五)**已经投保机动车承运人责任保险** | 车辆四钟之 carrier |
| 第15条 | 公安机关交通管理部门发给**校车标牌**，在行驶证上签注校车类型和**核载人数** | 建档字段（标牌号/核载） |
| 第16条 | 校车标牌载明号牌号码、所有人、驾驶人、线路、开行时间、停靠站点、发牌单位、**有效期** | 车辆四钟之 plate |
| 第18条 | **禁止使用未取得校车标牌的车辆提供校车服务** | 红线提示（标牌未登记=红灯） |
| 第20条 | **校车应当每半年进行一次机动车安全技术检验** | 车辆四钟之 inspection（+6 个月，月末钳制） |
| 第21条 | 配备**逃生锤、干粉灭火器、急救箱**等安全设备并确保性能良好；按规配备行驶记录卫星定位装置 | 义务账 deviceCheck |
| 第22条 | 建立**安全维护档案**（一车一档的法定形态）；不符合安全技术条件的**应当停运维修，消除安全隐患** | 一车一档视图；隐患门禁依据 |
| 第23条 | 校车驾驶资格六条件：(一)相应准驾车型 3 年以上经历、**年龄 25~60 周岁**；(二)近 3 个记分周期无满分；(三)无死亡重伤事故责任；(四)无酒驾醉驾、近 1 年无客运超员超速；(五)无犯罪记录；(六)身心健康 | 驾驶人年龄红线（25/60）；资格条件提示 |
| 第24条 | 向公安交管申请，符合条件的在驾驶证上**签注准许驾驶校车** | 驾驶人「取得资格日」字段 |
| 第25条 | 未取得校车驾驶资格**不得驾驶**校车；**禁止聘用**未取得资格的驾驶人 | 建趟次拒绝 DRIVER_UNQUALIFIED |
| 第26条 | **校车驾驶人应当每年接受公安机关交通管理部门的审验** | 驾驶人审验钟（+12 个月） |
| 第34条 | **校车载人不得超过核定的人数，不得以任何理由超员**；学校和服务提供者不得要求超员超速 | 上车点名硬拦截 OVERLOAD |
| 第38条 | **应指派照管人员随校车全程照管**；定期对随车照管人员进行安全教育 | 建趟次强制 escortIds；义务账 escortTraining |
| 第39条 | 照管人员五职责：(三)**清点乘车学生人数**、帮助落座**系好安全带**、确认车门关闭后示意起步；(五)**核实学生下车人数，确认乘车学生已经全部离车后本人方可离车** | 趟次四步点名的第2/3步；车内三查；人数守恒 |
| 第41条 | 驾驶人出车前应当对**制动、转向、外部照明、轮胎、安全门、座椅、安全带**等车况进行检查，**不得驾驶存在安全隐患的校车上道路行驶**；不得载学生加油 | 出车前七项检查（逐项原文列举）；带病开不了趟门禁 |
| 第44条 | 使用拼装/报废车接送学生：驾驶人 2000~5000 元+吊销；车辆所有人 **8万~10万元** | 痛点量化 |
| 第45条 | **使用未取得标牌的车辆提供校车服务或未取得资格的人员驾驶校车：扣车+1万~2万元罚款**，违法所得没收；情节严重吊销运输许可 | 痛点量化 |
| 第46条 | 不按规定配备安全设备或不按规定安全维护：责令改正，**1000~3000 元** | 痛点量化 |
| 第47条 | 无资格驾驶校车：**1000~3000 元**，情节严重吊销驾驶证 | 痛点量化 |
| 第48条 | 出车前未检查/驾驶隐患车上路等五种情形：责令改正可处 200 元 + 通行违法**从重** | 出车前检查的罚则锚 |
| 第50条 | **超员：扣留车辆至违法状态消除**，依道交法**从重处罚** | OVERLOAD 拦截文案 |
| 第53条 | **未指派照管人员随车全程照管：责令改正可处 500 元**；照管人员未履职责令改正、拒不改正处分解聘 | NO_ESCORT 拦截依据 |
| 第54条 | 情节严重的**吊销校车使用许可**、收回标牌 | 痛点量化 |
| 第55条 | 学校违规通报批评；发生学生伤亡事故的，**民办学校责令暂停招生，情节严重吊销办学许可证**，责任人 5 年禁业 | 痛点最高锚（民办园 extinction-level） |
| 第60条 | 入园幼儿确需集中接送的，应使用**幼儿专用校车**并遵守本条例 | 适用范围含幼儿园 |
| 第61条 | **省级人民政府制定实施办法**（属地参数化的法律依据） | 「属地永远赢」条款 |

相关（未逐条核验、仅作背景，标注检索受限）：
- 《刑法》第133条之一(三)（刑法修正案(九)，2015）：从事校车业务**严重超过额定乘员载客**或严重超速→危险驾驶罪。「严重超过」的具体幅度属执行口径，工具不内置数值、只做核载红线（第34条），文案标注入刑风险。
- 《机动车驾驶证申领和使用规定》（公安部令）含校车驾驶人审验的办理细则；本工具以条例第26条「每年审验」为钟表口径，公安部令具体条号**检索受限未逐条核验、如实标注**。

## 二、执法节奏与痛点佐证

- 永州公安交警「护航开学季」校车安全大检查（新湖南/今日永州，2026-08-25）：逐台排查制动、轮胎、灯光，核验驾驶人资质、**年检保险信息**，隐患现场督促闭环整改；**核对车辆维保、驾驶人培训、隐患整改等记录**，现场登记台账并督促限期整改，「坚决杜绝带病校车投入运营」。→ 证明「证照+台账」正是开学检查的核查清单。
- 《广州市校车安全管理规定》2022-12-15 常务会议通过、2023-03-01 施行（广州市教育局政策解读，gov.cn 转载）：属地立法持续活跃。
- 保定市徐水区校车安全管理实施细则（徐水区政府网，2024，援引冀政办发〔2015〕20号、保校车联办〔2023〕1号）：县区级细则+联席会议制度常态运行。
- 山西省实施《校车安全管理条例》办法（中国政府网检索页）：省级实施办法普遍存在（第61条落实）。
