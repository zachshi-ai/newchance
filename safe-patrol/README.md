# 安巡单 SafePatrol

> 小微工贸企业的安全生产自查台账与动火作业许可 —— **检查来之前，台账先在。**
> 机会实验室第 10 号项目（领域：工贸小微 · 安全生产自查与动火作业台账 · 应急管理监管线）

## 它解决什么

1~50 人的加工厂、注塑坊、木器厂、仓储点，法定义务每天连着（隐患在长、证照在走、动火在发生），台账却只在检查前存在。《安全生产法》第 41 条要求隐患排查治理情况**如实记录**；应急管理部令第 10 号把**特种作业无证上岗直接判定为重大事故隐患**；安法第 97 条的罚则是 10 万元以下、逾期未改正停产停业整顿并处 10 万~20 万（检索口径）。纸检查表 + 微信群 + 记性，在"如实记录"面前结构性不成立。

**安巡单的做法**：30 秒十二项自查（异常强制留隐患）→ 隐患登记→整改→复查销案全闭环（只打勾不留痕被拒绝）→ 动火开票闸机（无有效焊工证，这张单**开不出来**）→ 证照三态亮灯（过期即红，点名到期办理）→ 培训学时与演练频次体检 → 一键迎检自证包（微信文本 / 打印版单文件 HTML / 直接打印）。

## 快速开始

```bash
cd safe-patrol && npm start   # → http://localhost:8091
npm test                      # 25/25 单元测试（node --test，零依赖）
```

零 npm 依赖、零 CDN、零 API：纯前端 PWA + localStorage，数据 100% 存本机，换机走 JSON 导出导入。首次打开点「先看示例数据」可以看到红黄绿全状态的演示账本。

## 功能地图

| 模块 | 一句话 |
|---|---|
| 今日安全台 | 五类红灯一屏点名，「今天做什么」按优先级排好 |
| 隐患闭环 | 登记 → 整改 → 复查销案；逾期红灯；闭环率进体检摘要 |
| 动火作业 | 开票三闸（证闸/措施闸/监护闸）+ 完工销票；被拒的开票留埋点 |
| 人与证 | 员工名单、6 类证照三态引擎、学时与演练体检 |
| 迎检包 | 账本体检 + 五本台账一页纸，三通道送达，含签字栏 |
| 设置 | 厂档、全部规则参数可覆盖（属地规则永远赢）、导出导入 |

## 诚实条款

- **已验证**：25/25 单元测试 + 浏览器端到端（闸机拒绝过期证、异常强制留隐患、迎检包生成）+ 截图核验；打印版单文件离线可用。
- **待验证**：全部商业假设（H1-H8）标注"待验证"并配有可证伪判据；闸机拦截事件（hotwork_gate_blocked）是最有价值的验证数据。
- **边界**：企业自查底账——不构成安全评价，不替代法定报送、企业安全制度与应急预案文本；不核验证件真伪（提示官方平台）；动火单是企业内部许可的数字化，高危行业法定审批另行适用；本地记录不宣称司法级存证；罚额与学时/频次口径见 [docs/14](docs/14-调研来源.md)（检索/通识口径诚实标注），产品参数全部可覆盖——**属地规则与最新公告永远赢**。
