## 2. MVP 边界（做什么 / 明确不做什么）

**做**：厂档与员工名单；证照档案三态引擎（6 类证种）；动火开票闸机（证闸/措施闸/监护闸 + 销票）；隐患闭环状态机（登记→整改→复查销案 + 逾期红灯）；30 秒十二项自查（异常强制留隐患）；培训学时与演练频次体检；迎检自证包三通道（微信文本 / 打印 HTML / 直接打印）；参数全部可覆盖；JSON 导出导入。

**不做（诚实清单）**：监管报送（政务平台的事）；隐患拍照上传与 OCR（现场网络与耐心都不可靠，V2 评估）；特种作业证真伪核验（官方查询平台的事，本工具只管日历并提示核验）；应急预案文本生成（已证伪候选，见阶段二 RICE）；多人协作与云同步（小微现实是单机单厂长）。

## 4. OHELM 循环（周迭代节拍）

**O**bserve（看埋点与回访）→ **H**ypothesis（从 H1-H8 取最弱环节）→ **E**xperiment（一周内能上线的最小改动）→ **L**earn（判据过/不过）→ **M**easure（北极星与护栏指标同看）。

例：若 H2 不达标且 `check_rejected` 高频 → 假设"异常必填说明太烦" → 实验：把说明输入框改为异常项选中时自动展开并预填检查项名称 → 度量 rejected 率下降幅度。

## 5. 北极星指标与护栏

- **北极星：周活跃自查企业数**（周内 ≥1 次 check_submit 的企业数）——它同时代表留存、习惯与台账成立。
- 护栏：隐患 7 日销案率（防"为打卡而打卡"）；hotwork_gate_blocked 率（闸机真实拦截，防摆设）；迎检包月使用率（防工具与检查场景脱钩）。

## 6. 第一桶金三路径（按启动成本排序）

1. **直销种子（第 1~4 周，¥0 成本）**：属地 5 家工厂上门手工服务——帮建档、陪一次自查、打印第一份迎检包，收 ¥99/年。验证 H1/H2/H6，拿到第一批真实台账。
2. **培训机构联营（第 5~8 周）**：找 1 家区县级安全培训机构谈白标 ¥1200/年：其学员企业结业即得一年工具，机构获得证照到期预警的复训招生线索（H7/H8）。首单即回本（一个试点 = 1.2 万，覆盖全部开发边际成本）。
3. **劳保商随货分销（第 9~12 周）**：2~3 家劳保/消防器材商按 ¥600/年/商进货价白标，随灭火器年检业务分发。

定价锚：一次"未如实记录"的限期整改 = ¥99 的 100 倍；一期焊工复训班学费 = 白标年费的 3~5 倍。两头都是数量级错配。

## 7. 90 天验证排期（与执法节奏对齐）

| 周 | 动作 | 里程碑 |
|---|---|---|
| 1-2 | 种子工厂手工服务（直销路径 1） | 5 家建档，H1 开始计数 |
| 3-4 | 每周回访 + OHELM 迭代；补迎检包真实使用记录 | H2/H3 首批数据 |
| 5-6 | 培训机构试点签约（路径 2） | 1 家白标上线，H7 启动 |
| 7-8 | 试点机构首批 30 家分发与激活 | H7 判定（≥30 家） |
| 9-10 | Pro 付费墙实验（证照不限量 + 盖章版抬头） | H6 首批转化 |
| 11-12 | 复训线索回访（联动判定）+ 劳保商渠道试水 | H8 判定；决定加注或转向 |

节奏锚点：**6 月安全生产月**与岁末年初执法强化期是需求脉冲，试点必须早于下一个脉冲完成。

## 8. 诚实条款（不把未验证的信念当成果）

- 技术可行性已在仓库内验证（25/25 测试 + 浏览器端到端：闸机拒绝过期证、异常强制留隐患、迎检包生成与三通道）。
- 商业假设（H1-H8）**全部待验证**，判据可证伪；种子期数据回来前不谈规模化。
- 本工具是企业自查底账：不构成安全评价、不替代法定报送/企业安全制度/应急预案文本；动火单是企业内部许可的数字化（高危行业法定审批另行适用）；证照真伪以官方平台核验为准；本地记录不宣称司法级存证——**台账如实记录是义务的底线，不是事故的护身符**。
- 罚额与口径标注"检索口径/通识口径"（见[调研来源](14-调研来源.md)），产品参数全部可覆盖，属地规则与最新公告永远赢。
