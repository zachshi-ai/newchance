# 12 · 阶段三：机会转化产品方案

> 本阶段回答：机会变成什么产品、价值主张怎么立、供应链怎么走？商业画布定结构，价值主张画布定卖点，蓝海四动作定边界，Kano 定优先级，供应链分析定生死。

---

## 1. 商业画布（9 块）

| 块 | 内容 |
|---|---|
| 客户细分 | 1~50 人小微工贸企业（金属加工/注塑/木器/服装/印刷/仓储）：厂长即安全员，无 EHS 预算；渠道侧：县区安全培训机构、劳保消防器材批发商 |
| 价值主张 | **检查来之前，台账先在**——30 秒自查打卡、隐患闭环、动火无证开不出票、证照不超期、迎检一页纸 |
| 渠道 | ① 安全培训机构白标联营（结业礼包）；② 劳保/消防器材商随货分销；③ 镇街检查表发放场景的随发二维码；④ 直销（事故新闻后 72 小时内属地触达） |
| 客户关系 | 工具型自助 + 渠道代服务（机构客户经理就是客服一线）；无佣金分成纠纷——白标定价一次性 |
| 收入流 | 厂长侧 ¥99/年 Pro（证照不限量 + 迎检包自定义抬头盖章版 + 多厂区）；渠道侧 ¥1200/年/机构白标（分发其下游企业）；免费版：10 人以内全功能可用（先让台账成立，再谈付费） |
| 关键资源 | 判定标准的软件化能力（令 10 号 → 闸机）；检查项内容模板（内容供应链）；渠道名单与信任 |
| 关键活动 | 检查项模板的属地化维护；渠道试点与分发运营；假设验证（H1-H8） |
| 关键伙伴 | 安全培训机构（复训招生联动）、劳保商、属地应急管理服务站/协会（公益背书） |
| 成本结构 | 近零边际成本（纯前端）；主要成本是渠道试点地推与内容维护的人工 |

## 2. 价值主张画布

**客户任务**：应付检查不心虚；动火干活不惹祸；证照不超期；隐患别烂尾；出了事说得清。

**痛点**：检查前突击补台账；翻箱倒柜找证；隐患开了单没人管；培训签名凑数被戳穿；动火就是喊一嗓子。

**期待收益**：检查 10 分钟过；罚款风险可见地变小；厂长手机上看一眼就知道今天要办什么。

**产品供给（痛点→解药）**：

| 痛点 | 解药 | 软件机制 |
|---|---|---|
| 突击补台账 | 打卡即台账 | 30 秒十二项自查，异常强制留隐患（安法 41 条"如实记录"的软件门禁） |
| 翻箱倒柜找证 | 证照日历 | 证面有效期录入 → 红/黄/绿三态，60 天黄线（可调） |
| 隐患烂尾 | 闭环状态机 | 登记→整改→复查销案，逾期红灯；只打勾不留痕被拒绝 |
| 动火凭胆量 | 开票闸机 | 焊割动火必须选当日有效焊工证，过期证开票被拒（令 10 号第三条(二)的软件执行） |
| 检查心虚 | 迎检自证包 | 一页纸：账本体检 + 五本台账 + 签字栏；微信文本 / 打印 HTML / 直接打印三通道 |

**收益创造**：账本体检摘要（闭环率、红黄灯计数）把"安全"从感觉变成数字——可截图发股东、可张贴厂门口（痒点）。

## 3. 蓝海四动作（ERRC）——边界即定位

| 动作 | 内容 | 理由 |
|---|---|---|
| 剔除 | 监管报送、视频监控/物联网硬件、在线卖课、安全标准化创建辅导、四色风险图 | 报送是政务平台的事；硬件是重资产；卖课是培训机构的饭——碰了就是与渠道为敌 |
| 减少 | 风险分级管控（减为一套检查项模板）、设备管理（减为证照+叉车定检两件事）、表单自由度（减为结构化三态） | 小微要的是"够用的正确"，不是"完备的复杂" |
| 增加 | **动火开票闸机**（把判定标准变成开票前的一行代码）、**迎检包账本体检**（闭环率/红黄灯一页纸）、**复训联动**（证照黄灯即培训机构招生线索） | 三个增加项全部直击证明成本，且竞品（纸/Excel）结构性给不了 |
| 创造 | "检查来之前，台账先在"的日常态：安全从迎检材料变成每天 30 秒的动作 | 把低频恐惧转成高频习惯，留存与口碑都长在习惯上 |

## 4. USP（独特销售主张）

> **「应急管理部令第 10 号说：无证动火属重大事故隐患。安巡单把它变成开票闸机——作业人证件过期，这张动火单开不出来。」**
> 全网只有我们把判定标准写成了代码；纸制度拦不住的火，一行 if 拦得住。

辅助 USP：迎检一页纸——「检查要看的五本台账，一次打印，含账本体检与签字栏」。

## 5. Kano 模型优先级

| 类别 | 功能 | MVP 处置 |
|---|---|---|
| 基本型（没有就没人用） | 本地存储、数据导出备份、打印可用、免费可用 | ✅ 全做 |
| 期望型（越多越愿意付） | 证照到期预警、隐患逾期红灯、学时/演练体检、迎检包 | ✅ 全做（核心付费点） |
| 兴奋型（说了才想要） | 无证动火拒绝开票、账本体检摘要、复训联动提示 | ✅ 前两项已做；复训联动属渠道侧，V2 |
| 反向型（做了减分） | 强制拍照上传（现场没网/没耐心）、社交功能、排行榜 | ❌ 不做 |

## 6. 供应链分析（产品侧三链 + 产品自身供给）

**内容链（原料 → 生产）**：
- 原料：法规与判定标准全文（政府公开、免费、权威）——安法 41/97 条、令 10 号 64 项、《消防法》21 条、培训与演练频次口径；执法高频词（检查表内容）来自属地公开执法清单与通识。
- 生产：把法条拆解为 12 项通用自查项、6 项动火措施、6 类证照种类的**模板化翻译**——这是本项目唯一的内容成本，也是可积累的内容资产（属地化版本是 V2 扩展位）。
- 供给风险：法条修订 → 参数化设计（黄线/红线/周期全部企业可调），"属地规则与最新公告永远赢"写进产品宪法。

**技术链（零依赖供给）**：纯前端 PWA + localStorage，无服务器、无数据库、无第三方 API；出证物是自包含单文件 HTML——供应链上没有会断的环节，边际成本为零，数据主权在厂长本机（敏感的处罚记录与员工证件信息不出设备，这本身就是卖点）。

**分发链（渠道即上游，上游即受益者）**——本项目的生死线：
- **安全培训机构**（首选渠道）：掌握全区持证企业名单，天然触点（初训/复审/年审班）；动机比流量更深一层——特种作业证 3 年一复审，**证照到期预警就是复训招生的自动线索源**，台账工具替培训机构把"该复训的学员"按天筛出来。白标 ¥1200/年/机构 = 一期复训班的半张桌牌钱。
- **劳保/消防器材批发商**（次选）：卖灭火器的知道每家厂的门口在哪，随货送"一年台账服务"是现成的差异化话术。
- **镇街应急办/协会**（公益触点）：检查表发下来时附二维码，"这个表用手机 30 秒填完"——不承诺背书，只借场景。

**劳动力链**：无资质门槛（软件开发 + 法条内容整理 in-house）；地推验证期用兼职安全工程师做渠道培训（按次结算，非雇佣）。

---

**阶段三结论**：产品 = 打卡即台账 × 开票即闸机 × 一页纸迎检；蓝海边界靠"剔除报送与硬件"守住渠道友谊；供应链上游（培训机构）同时是分销商与受益者——这是比流量型渠道更深一层的绑定。进入[阶段四：产品落地验证闭环](13-阶段四-产品落地验证闭环.md)。
