# 10 · 阶段一：识别机会与洞察市场

> 本阶段回答：世界的哪个痛点值得做？用第一性原理拆到底，用 JTBD / 船模型 / 非消费者分析还原真实场景，用 PESTEL 扫宏观，用机会缺口矩阵定位空白。

---

## 1. 第一性原理拆解

不问「市面上有什么口腔诊所软件」，只保留不可再分的事实：

| # | 不可再分的事实 | 推论 |
|---|---|---|
| F1 | 口腔诊疗器械侵入人体组织或接触黏膜，WS 506-2016（强制性卫生行业标准）要求**一人一用一消毒/灭菌**，牙科手机等高度危险器械必须灭菌 | 「每用一个包都要有台账」是法定动作，不是经营偏好 |
| F2 | 灭菌效果**肉眼不可见**——指示剂变色是间接证据，且只有连着批次记录才有意义 | 器械安全是典型的**信任品**：无法被看见，只能被记录证明 |
| F3 | 单条记录没有价值：锅次、监测、效期、**患者**四类记录必须**连成链**（患者→包→批次→锅→监测结果）才算「可追溯」 | 产品的第一性对象不是「记录」，是**链的可拼装性**——断链的台账等于没有台账 |
| F4 | 纠纷与诉讼中，隐匿、遗失、无法提供资料的医疗机构可被**推定有过错**（民法典 1222 条口径） | 「拿不出」的代价远大于「没做」——记录的存在性与完整性本身是法律风险变量 |
| F5 | 小微诊所的现状 = 清洗消毒记录本 + 灭菌器运行记录本 + 医废交接本三本手写账，指示胶带贴在机壳上，发放靠记忆 | 三本账互不关联，链路天然断裂：患者端点缺失、监测与锅次对不上、效期全凭感觉 |
| F6 | 口腔是**消费医疗**：患者自费、选择自由、社交点评发达——感染事件会被差评与媒体无限放大 | 一次断链的成本 = 行政处罚 × 停业损失 × 口碑崩塌，风险被市场杠杆放大 |

**第一性变量**：追溯链的**可拼装性**——四类记录能不能在 30 秒内拼成一条完整的、拿得出的链。灭菌单的全部设计都为这个变量服务。

## 2. 痛点-爽点-痒点

| 层 | 内容 | 产品对应 |
|---|---|---|
| **痛点**（不做会痛） | ① 监督所双随机检查，「三本账」缺页、漏记、对不上要现场解释甚至受罚；② 患者投诉感染，翻不出「这个患者用的器械是哪锅哪批、监测合不合格」；③ 生物监测阳性要做召回，但发放没记录，连「用过这锅的患者是谁」都数不出来 | 一锅一单落账；患者标识闭合追溯链；召回自动生成已发放名单 |
| **爽点**（做完立刻爽） | 检查进门 30 秒打出整月灭菌台账；患者质疑时 30 秒在微信回一张追溯单；体检灯全绿的心里有底 | 迎检包 / 追溯单三通道出证；院感体检打分 |
| **痒点**（用了更想用） | 把追溯单印上诊所抬头变成「消毒透明的诊所」——把合规动作变成获客素材；无菌柜效期红绿灯的秩序感 | 追溯单可打印公示；效期先灭先用的看板秩序 |

## 3. JTBD（任务待办模型）

**当**患者投诉感染或监督所上门检查时，**当**我要证明「这个患者用的器械经过合格灭菌」时，**我想要**在 30 秒内拼出完整的灭菌追溯链（哪口锅、哪批包、化学/生物监测结果、谁操作的、发放给了谁），**这样我**不被推定过错、不停业、不丢口碑。

- **功能性任务**：落锅次账、记监测、管效期、发放在案、出证
- **情感性任务**：不用再「检查前突击补本子」的恐惧；真出事时「我拿得出完整记录」的底气
- **社会性任务**：向患者与监督者证明「这家诊所消毒是透明的」

## 4. 船模型（我们造谁的船，不造谁的船）

| 船 | 是否造 | 理由 |
|---|---|---|
| 诊所管理 SaaS 的船（预约/病历/CRM/收费） | **不造** | 领健 e 看牙、牙医管家等已充分竞争；诊所老板的付费心智在获客与经营，不在台账；我们只做台账，SaaS 是互补不是对手 |
| 医院 CSSD 消毒供应追溯系统的船 | **不造** | 老肯、三维海容等面向医院消毒供应中心，部署重、价格数万起、按院感科流程设计——小微诊所「一台锅一个护士」的场景被结构性忽略 |
| 灭菌器厂商物联网的船 | **不造** | 传感器联网方案绑硬件、服务连锁与大机构；不联网的存量小微诊所够不着 |
| **追溯链的拼装台的船** | **造** | 四类记录（锅/监测/效期/患者）的本地拼装 + 出证——这正是断链现场（小微诊所）唯一没人承接的位置 |

## 5. 非消费者分析

| 非消费者 | 现状 | 为什么会变成消费者 |
|---|---|---|
| 夫妻诊所（1 椅~2 椅，无专职护士） | 三本账半途而废，指示胶带当记录 | 免注册零成本、30 秒一锅、一部手机就能用——比「维持三本假账」更省力 |
| 只给医生配「诊疗软件」的诊所 | 院感台账仍在纸本，软件里没有患者端点 | 不替换任何系统，补上 SaaS 没有的追溯链与出证通道 |
| 被「追溯系统」报价吓退的连锁（3~10 家店） | 医院级系统太重，索性各店纸本 | 本地优先、按店自持、免费起步——先跑单店再谈连锁 |

## 6. PESTEL 宏观扫描

| 维度 | 与本机会相关的信号 |
|---|---|
| **P** 政治 | 院感监督「双随机一公开」常态化；WS 506-2016 强制性标准持续执行；医疗质量安全在基层监管权重上升 |
| **E** 经济 | 口腔行业从增量转存量竞争，种植牙集采后利润变薄——老板对「不产生收入的合规投入」敏感，但对「停业与诉讼」更敏感；免费起步 + 年费百元的定价贴着存量期心理账户 |
| **S** 社会 | 消费医疗的信任敏感度极高，消毒透明成为患者选择因子；社交媒体把感染事件放大为本地新闻 |
| **T** 技术 | 小型 B 级/卡式灭菌器在诊所普及（锅是现成的，账没跟上）；智能手机即终端；PWA 本地存储技术成熟到零成本 |
| **E** 环境 | 医疗废物集中处置监管收紧（交接联单电子化在各地推进），倒逼交接台账规范 |
| **L** 法律 | 民法典 1222 条推定过错；WS 506 强标；医废条例 3 年保存——「拿不出记录」的法定成本明确且上行 |

## 7. 机会缺口矩阵

|  | 记录**在**（有记录） | 记录**连**（链路完整） | 记录**出**（可出示证明） |
|---|---|---|---|
| **医院级 CSSD 追溯系统** | ✅ | ✅ | ✅（但重、贵、按院流程） |
| **口腔诊所 SaaS 附属模块** | ➖（有消毒登记项） | ❌（无患者端点、无召回闭环） | ❌（无迎检出证形态） |
| **灭菌器厂商物联网** | ✅（设备侧数据） | ➖（不含发放与患者） | ❌ |
| **小微诊所现状（纸本+记忆）** | ➖（三本断账） | ❌ | ❌（突击补本） |
| **灭菌单 SterilSheet** | ✅（一锅一单） | ✅（患者→包→锅→监测全链 + 召回名单） | ✅（追溯单/迎检包三通道 30 秒出证） |

**空白定位**：「记录连 + 记录出」象限在小微价格带（0~¥99/年）内无承接者——这是灭菌单的机会缺口。
