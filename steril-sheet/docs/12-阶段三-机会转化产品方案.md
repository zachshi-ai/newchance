# 12 · 阶段三：机会转化产品方案

> 本阶段回答：机会怎么变成一个可卖的产品？用商业画布与价值主张画布定结构，用蓝海四动作定差异化，用 Kano 裁 MVP，最后把供应链想透——本项目供应链分析的重头戏是**灭菌耗材链**（生物指示剂与包装袋是周周复购品，经销商上门即天然演示场景）与**分发链**（灭菌器/耗材经销商即渠道，装机即开通）。

---

## 1. 商业画布（Business Model Canvas）

| 模块 | 内容 |
|---|---|
| **客户细分** | 小微口腔诊所：1~5 台牙椅、1~2 台小型/卡式灭菌器、无专职院感员（护士长兼）、纸本记账；渠道客户：**口腔设备/耗材经销商**（灭菌器装机与指示剂复购的流转节点，见 §6.3） |
| **价值主张** | 对诊所：测完 30 秒落账、四类记录自动连成链、过期拒发不靠自觉、监测阳性自动出召回名单、迎检/追溯 30 秒出证——「拿得出，才叫有台账」；对患者：可查的消毒透明；对经销商：装机即开通的服务卖点 + 下游诊所合规存续 = 耗材复购客户池保全 |
| **渠道通路** | ① 经销商装机即开通（主攻，白标联营）；② 口腔器械展会与 dealers 私域；③ 种子诊所口碑（追溯单本身就是带诊所名片的传播物） |
| **客户关系** | 本地自持免注册（无锁定焦虑）；微信群种子共创；经销商代客服务（白标后台） |
| **收入来源** | 诊所 Pro ¥99/年（器械包不限量 + 追溯单自定义抬头 + 年度迎检包）；经销商白标联营 ¥1500/年/商；灭菌器厂商预装合作（按激活分成）——**全部待验证** |
| **核心资源** | WS 506 口径参数化引擎与迎检话术（内容资产）；追溯链数据模型（患者→包→锅→监测）；本仓库可复现的 MVP 与 32/32 测试 |
| **关键业务** | 落账/效期/召回三大闭环的持续打磨；渠道商装机培训；监测口径的内容运营（标准更新时更新参数默认值） |
| **重要伙伴** | 灭菌器/耗材经销商（渠道）；灭菌器厂商（预装）；地方口腔诊所协会/微信群（信任节点） |
| **成本结构** | ≈0 边际成本（零后端零依赖）；主要成本是创始人的时间：渠道谈判、口径运营、种子服务 |

## 2. 价值主张画布

**顾客侧（护士长/诊所老板）**
- 顾客任务：每天落锅次账、每周做生物监测、每月应付检查台账、出事时自证清白
- 痛点：三本账对不上、发放没人记、检查前突击、真出事拿不出链、召回无从下手
- 期望收益：检查不慌、纠纷有据、无菌柜不压过期货、合规变成可展示的信任

**产品侧（灭菌单）**
- 止痛药：一锅一单 30 秒落账；四类记录自动连链；**过期包发放被工具硬性拒绝**；监测阳性自动冻结在库并生成已发放患者名单
- 创造收益：院感体检打分（心里有底）；迎检包/追溯单 30 秒出证；效期先灭先用的自动排序
- 差异化姿势：不碰挂号病历收费（SaaS 的地盘）、不碰传感器（厂商的地盘）、不碰报送（监管平台的地盘）——只做诊所自己的追溯底账

## 3. 蓝海战略四动作框架（ERRC）

| 动作 | 内容 | 为什么 |
|---|---|---|
| **剔除** | 挂号/病历/收费/影像；物联网传感器与硬件；监管报送对接；多门店集团管控 | 全部是重成本、强竞争或他人地盘；每一项剔除都换来了零依赖与离线可用 |
| **减少** | 器械目录粒度（不做单把器械级追踪，做到「包」级——小微的真实管理单位）；操作步骤（落账一屏完成） | 单器械级追溯是医院 CSSD 的精度需求，包级已满足诊所的追溯与检查需要 |
| **提升** | 出证速度（检查前突击补本 → 30 秒打出）；召回可执行性（无从下手 → 名单自动生成）；效期秩序（记忆 → 先灭先用自动排序） | 提升的都直接落在「证明成本」这个第一性变量上 |
| **创造** | 院感体检打分；**已发放患者召回名单**（纸本时代根本不存在的能力）；装机即开通的渠道形态 | 创造项全部来自「记录连 + 记录出」的空白象限（docs/10 机会缺口矩阵） |

## 4. USP（独特销售主张）

> **「消毒灭菌，一锅一单连成链——检查 30 秒打出台账，患者查询 30 秒回一张追溯单。」**

三句话讲清楚：锅次账（一锅一单）、链（患者→包→锅→监测）、证（30 秒出证）。对比纸本：它连得上；对比 SaaS：它不用联网不换系统；对比追溯系统：它免费起步、一部手机就够。

## 5. Kano 模型裁 MVP

| 层 | 功能 | MVP 取舍 |
|---|---|---|
| **必备**（没有就没人用） | 灭菌落账（装载/化学/BD/生物/操作者）；效期三态；发放记录；月度台账 | ✅ 全部内置 |
| **期望**（越多越好） | 先灭先用 FIFO；过期/冻结拒发硬门禁；周期任务预警（生物监测/医废/健康证/耗材效期） | ✅ 内置，参数可覆盖 |
| **兴奋**（讲了才想要） | 监测阳性一键召回名单；院感体检打分；迎检包打印版；追溯单微信文本通道 | ✅ 召回名单与迎检包内置；自定义抬头留给 Pro |
| **不做**（Kano 的反面清单） | 传感器对接、监管报送、病历系统、电子签章司法存证 | 明确写进边界与免责 |

## 6. 供应链分析（本项目的重头戏）

### 6.1 产品侧：灭菌耗材链（渠道动机的来源）

```
灭菌器厂商 → 设备/耗材经销商 → 口腔诊所（我们的用户）
                  │
                  ├─ 生物指示剂（按监测周期周周复购）
                  ├─ 化学指示卡/标签（按锅次复购）
                  ├─ 灭菌包装袋/卷料（按锅次复购）
                  └─ 清洁润滑剂（按月复购）
```

- **耗材是经销商的命根**：指示剂与包装袋是持续性收入，诊所被罚停业 = 经销商客户池流失。帮诊所把台账立住 = 保全经销商自己的资产负债表——渠道动机与用户利益同构（与 6 号项目「农资赊销保全」同构但行业不同）。
- **生物指示剂周周消耗 = 天然回访节奏**：经销商/服务商每次上门收样送检，就是一次「帮诊所看体检灯、教落账」的演示场景。渠道即服务，服务即演示。
- **效期管理反哺耗材销售**：指示物/消毒剂效期台账让诊所按期换新——渠道商乐于见到自己被写进客户的周期任务里。

### 6.2 产品自身的技术链（零依赖决策）

无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。诊所消毒间/前台网络差是常态，PWA 离线可用；患者标识与锅次数据不出设备。打印版为单文件 HTML（内联样式、无外部资源），微信文本为主通道——**供应链上没有任何一环会让我们停摆**。

### 6.3 分发链：经销商即渠道（第一桶金主攻）

- **为什么是装机场景**：小型灭菌器 2~5 万/台是诊所的大件投资，装机当天是诊所对「设备管理」最有承诺感的一刻——装机即开通一年白标版（经销商 logo + 诊所信息），演示成本为零，转化在情绪最高点完成。
- **渠道产品**：经销商版 ¥1500/年——白标后台（自己的诊所客户池）+ 装机码批量发放 + 下游诊所落账活跃月报（复购预警：活跃掉头的诊所正是该上门拜访的）。
- **第二渠道**：灭菌器厂商预装（出厂附带一年授权），按激活分成；展会场景（口腔设备展）现场演示「迎检 30 秒」。
