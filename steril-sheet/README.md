# 灭菌单 SterilSheet 🦷

> **小微口腔诊所的器械清洗消毒灭菌追溯单与院感自查台账：一锅一单连成链，效期先灭先用，过期拒发不靠自觉，监测阳性自动出召回名单，迎检追溯 30 秒出证。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 一部手机就能用

WS 506-2016《口腔器械消毒灭菌技术操作规范》（强制性卫生行业标准）要求口腔器械**一人一用一消毒/灭菌**、牙科手机等高度危险器械必须灭菌、清洗包装灭菌监测**记录并可追溯**——灭菌效果肉眼不可见，**台账是唯一的证明**。而小微诊所的现状是三本手写账 + 机壳上的指示胶带 + 靠记忆发放：患者用过哪个批次、哪锅监测合不合格，谁也拼不出完整的一条链；纠纷中「拿不出资料」可被推定有过错（民法典 1222 条口径），感染事件还会被差评无限放大。灭菌单把这段黑箱变成白箱：灭菌落账 30 秒（装载/化学/BD/生物/操作者一屏记全，锅编号自动生成）→ 无菌柜先灭先用（过期与召回冻结包的发放被工具硬性拒绝）→ 监测阳性一键召回（在库冻结 + 已发放患者名单 + 处置销案闭环）→ 追溯单/迎检包三通道 30 秒出证。

## 3 条命令跑起来

```bash
cd steril-sheet
npm start           # 等价于 python3 -m http.server 8090 --directory app
open http://localhost:8090
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程（含一条可销案的召回链）。

## 功能

| 模块 | 说明 |
|---|---|
| 🍲 **灭菌落账（一锅一单）** | 装载明细 + 化学/BD/生物监测 + 操作者 30 秒记全；锅编号自动生成（日期-锅代码-当日序号，如 20260905-M1-01）；化学不合格必须写处置说明且不放行；落账未来日期的锅直接拒绝——编的账进不了台账 |
| 🧦 **无菌柜（先灭先用）** | 在库按失效日自动排序（纸塑 180 天/布类 7 天，逐包可改）；临期黄线过期红灯；**过期与召回冻结包发放被硬性拒绝**，错误信息直接告诉你先去哪处置 |
| 🧾 **使用落账（患者端点）** | 发放必填患者标识（姓名缩写/病历号即可，最小披露不出设备）——没有患者端点，追溯链就不闭合；自动按失效日 FIFO 跨批次接力分配 |
| 🔴 **召回闭环（红线引擎）** | 生物监测阳性 → 批次冻结 + 自动生成已发放患者名单 → 在库处置登记（守恒校验，不许多处置）→ 写明处置经过才能销案；合格后不可改判，防事后洗账 |
| 🔔 **周期任务台账** | 生物监测周期、培养结果宽限、医废交接（条例口径 ≤2 天）、人员健康证、指示物/消毒剂效期——到期自动亮灯，检查前心里有底 |
| 🏥 **院感体检** | 七项自查打分（监测连续性/培养结果/过期在库/召回闭环/医废/健康证/耗材效期），红灯逐项点名到批次 |
| 📤 **出证三通道** | **追溯自证单**（按患者拼出「哪口锅哪批包、监测结果、谁操作」，召回历史如实打标）/ **月度迎检包**（锅次台账 + 体检结论 + 负责人签字栏）：微信文本复制 / 单文件 HTML 打印版 / 直接打印——患者和监督所都不用装任何东西 |
| 📒 **数据自持** | 100% 本地存储；JSON 导出/导入（换机迁移，含结构校验）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
消毒间网络差是常态，PWA 离线可用；出证走微信文本与本地打印，不依赖任何在线服务；患者标识与锅次数据不出设备。**不做挂号病历收费、不碰传感器、不做监管报送**——诊所 SaaS 与监管平台是互补不是对手，这里是诊所自己的追溯底账。

## 边界与免责

- **不做挂号/病历/收费/影像，不做物联网传感器，不做监管报送，不做电子签章司法存证**——器械包与操作者手工录入（特性不是缺陷：无数据源合规负担、离线可用、零成本）。
- **追溯单是诊所的自查与告知记录，不是司法证据**：本工具不宣称司法级存证；诊疗协议与原始记录永远赢；「曾启动召回」的打标是如实呈现——发生过、处置过、闭环了，本身就是合规的证据。
- 监测频次（默认每周）、效期（纸塑 180 天/布类 7 天）、医废间隔（≤2 天）均为行业通识先验的参数化预填，设置页可覆盖——**WS 506-2016 原文、设备说明书与属地要求永远赢**。
- 患者标识最小披露（姓名缩写/病历号即可），100% 本地存储；打印台账定位「自查与迎检备查」，不承诺执法采信。
