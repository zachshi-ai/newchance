# 适飞单 WingSheet 🛸

> **小微无人机队合规台账：判档器（微/轻/小/中/大，第62条）→ 一机一档两钟（实名登记第10条 / 责任保险第12条）→ 操控员三钟（执照6年 92.61 / 定期检查24个月 92.81 / 农用操作证书第16条2款）→ 申请台账「前1日12时」红线（第26条）→ 航前检查放行（第32条11项，带病机不开飞）→ 降落闭环与安全问题24小时报告钟（第40条）——飞之前就知道差哪张纸，检查来了 30 秒出证。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 数据不出设备

低空经济起飞（2025 年注册无人机 328.7 万架、+51%；操控员执照 41.55 万本、+68%）的同一时刻，执法密度也在陡增：761号令（2024-01-01）、CCAR-92（交通运输部令2024年第1号）、GB 42590—2023（2024-06-01）、**GB 46761—2025（2026-05-01 起实名登记+激活扩到 250 克以下微型机）**，再到**新《治安管理处罚法》第46条（2026-01-01）黑飞可拘留、施行首日即开罚单**。1~5 人航拍工作室、县域植保飞手、兼职持证飞手——这些人的证照钟散在脑子里、申请时限靠运气、检查前一夜补记录。适飞单把这本账变成白箱：判档上钟 → 航前放行 → 申请盯红线 → 一键出迎检自证包/飞行记录卡/月度小结。

## 3 条命令跑起来

```bash
cd wing-sheet
npm start           # 等价于 python3 -m http.server 8102 --directory app
open http://localhost:8102
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**载入示例数据**」，看板上的红灯都是演示钩子，30 秒体验完整门禁流程。

## 功能

| 模块 | 说明 |
|---|---|
| 🛸 **判档器** | 空机重量+最大起飞重量 → **微/轻/小/中/大**五档自动判定（第62条边界：0.25/4/7/15/25/150 千克），农用意向校验第62条(八)作业包线（真高≤30米/平飞≤50km/h/半径≤2000米/起飞≤150千克）并给出第11条3款运营合格证豁免；建档前实时预览该机的义务清单 |
| 🗂 **一机一档两钟** | **实名登记钟**（第10条，GB 46761—2025 起含微型机；未登记=开飞被拒）、登记标志粘贴确认（92.211/92.213）、**责任保险钟**（第12条：经营性任何机型+小/中/大非经营性）、存量机「不能自动报送识别信息」标志（第61条→一律申请批准后飞行） |
| 👮 **操控员三钟** | 执照有效期 **6 年**（92.61，期满 30 个工作日前更新提示）、**定期检查 24 个日历月**（92.81）、大型机/IFR **熟练检查 12 个日历月**（92.83）、农用操作证书复训（第16条2款，周期参数化）；执照过期/检查超期=建架次被拒 |
| 📮 **申请台账三段时钟** | **拟飞行前 1 日 12 时前**提交（逾期提交硬性拒绝，第26条）→ 空管**前 1 日 21 时前**批复登记 → **起飞前 1 小时**报告确认（第30条，未登记起飞被拒）；管制空域、飞越集会人群、投放物品、中继/集群、存量机——事由勾选即触发；批复不可挪用到其他日期 |
| 🚦 **航前检查放行** | 第32条行为规范 + GB 42590 的 11 项检查逐项确认（微型机识别信息项按第24条自动豁免）；有异常必须先立检修单与处置措施，**检修闭环前「起飞」被硬性拒绝**（带病机不开飞） |
| 🛬 **架次闭环 + 24 小时钟** | 起飞→降落闭环，经营性架次记收入；标记飞行安全问题必须写明情况，**「降落后 24 小时内报告」钟自动起算**（第40条），逾期一直亮红灯 |
| 🗓 **周期义务账** | 年度运营报告（92.671，违者 1万~3万）、性能参数复核（第14条/92.209）、电池健康（GB 42590）、固件与电子围栏更新（第32条(二)）、农用证书复训——法定周期钉死，「定期」口径参数化 |
| 🩺 **八灯体检** | 机队钟/操控员钟/运营合格证/申请欠账/未闭环架次/24小时报告/检修单/周期义务——确定性扣分，迎检前先自查 |
| 📑 **三通道出证** | **迎检自证包**（单文件 HTML：主体档案+判档一机一档+操控员+申请批复+近期架次+检修闭环+义务账+体检，含签字栏）/ **飞行记录卡**（一架次一卡，操控员/安全负责人签字栏）/ **月度小结**（微信文本，收入与安全同屏） |
| ⚙️ **数据自持** | 100% 本地存储，不记客户身份信息（数据最小披露）；JSON 导出/导入（含结构校验）即离线归档（对齐 92.547 飞行数据≥12个月、申请数据≥15个月的留存口径）；本地事件流可导出（`flight_started` 拒绝、`inspect_generated` 等 HDD 埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 野外/县域弱网离线可用；无第三方 API → 无停服风险。**
植保队在田埂上、航拍在山里，网络时好时坏，PWA 离线可用；飞行位置与收入是飞手最敏感的数据，本地优先=数据不出设备；不记录客户身份信息（最小披露）。**不做空域地图、不做代办申报、不做保险交易、不做社交**——大厂 App、官方 UOM 平台、保险经纪是互补不是对手，这里是飞手自己的合规底账。

## 第一桶金（详见 docs/13）

心智锚 =「一次无照飞行 5000~5 万、黑飞可拘留——一年台账钱不到罚单零头」。主攻**保险经纪白标**（¥1500/年/渠道：责任险是第12条强制险，年年续保年年触点，理赔时航前放行+申请批复记录就是证据包）与**培训机构结业礼**（¥99/码随执照课程分发，41.55 万本执照增量就是渠道流量）；植保队按作业季年费深绑。90 天目标 ¥1 万~3 万现金，验证付费真实度而非规模。

## 诚实条款

法规条号全部一手核验（2026-09-07，出处见 [docs/14](docs/14-调研来源.md)），但**属地细则与空管要求永远赢**；本工具不替代实名登记、运营合格证、飞行申请等法定手续与执法认定；商业假设（付费/渠道/留存）全部标注"待验证"并配有可证伪判据——我们不把未验证的信念当成果。
