# 瓶安单 BottleSafe 🛢️

> **瓶装液化气二级网点的配送与入户安检合规台账：送气落账顺手，瓶数守恒不扯皮，入户安检逐项不漏，隐患整改复访销案，年度安检钢瓶证件不逾期，监管检查 30 秒打出台账包。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 一部手机就能用

每送出一瓶液化气，网点就把一份易燃易爆品和一份法律责任一起送到了用户手里：《城镇燃气管理条例》（国务院令第 583 号）要求燃气经营者指导用户安全用气、对用户燃气设施**定期进行安全检查**，不履行义务有责令改正与罚款等罚则（罚额口径检索受限已标注）；十堰"6·13"事故后全国燃气安全专项整治常态化，"送气必检"、实名购气在多地落地；隐患只登记不复查，事故后"早就发现了却放任"责任更重；一户存几只瓶全凭记忆，餐馆以瓶抵款越记越乱。而二级网点（乡镇供应站/配送站）的现状是**纸安检单塞抽屉 + 瓶数靠脑子 + 检查前突击**——储配站系统不覆盖承包末梢、政府追溯平台管报送不管自证。瓶安单把这段黑箱变成白箱：用户建档 → 送气落账（在户瓶数守恒自动算）→ 入户安检五项逐检（有隐患必须登记整改）→ 复访合格才销案 → 年度安检/钢瓶检验/证件到期自动点名 → 隐患告知单当场打印签字、检查 30 秒出证。

## 3 条命令跑起来

```bash
cd bottle-safe
npm start           # 等价于 python3 -m http.server 8086 --directory app
open http://localhost:8086
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程（含隐患未闭环红灯、年度安检逾期、钢瓶超期与证件过期演示）。

## 功能

| 模块 | 说明 |
|---|---|
| 🧑‍🌾 **用户建档 + 实名底档** | 名称/电话/地址/常用瓶型一次建好，配送与安检共用；钢瓶档案登记瓶号与检验到期（照瓶身钢印抄，周期通识口径 48 个月、预警窗 90 天，可调）；员工证件台账 30 天预警——超期瓶与过期证件都是红线 |
| 🛵 **配送落账（守恒账）** | 满瓶送出/空瓶收回按瓶型分行（5kg/15kg/50kg）；**在户瓶数 = 送出 − 收回，由流水唯一派生**；收回超过在户瓶数**整单拒绝**（超收守卫）；金额可选；撤销精确回滚（撤销导致负数同样拒绝）；守恒体检（净送出 = 在户合计）常亮 |
| 🔍 **入户安检（责任账）** | 软管/减压阀/钢瓶/灶具连接/通风环境**五项逐项必检**（正常/隐患/不适用）；**有隐患必须登记整改措施才让落账**——「检了不处置」是事故后责任放大的根源 |
| 🔁 **复访销案闭环** | 未闭环隐患在看板红灯点名 → 一键进入复访模式（同户、日期不得早于原单）→ 复访合格销案；仍有隐患则接棒未闭环、原单转已复核；被复访引用的单不可删（删除会凭空销案） |
| 📅 **三类到期点名 + 断更体检** | 年度安检（默认 365 天，通识口径"每年至少一次"，可调）从未/逾期/临期四态点名 · 钢瓶检验到期 · 员工证件到期；配送台账断更日逐日点名（回看窗可调） |
| 🧾 **隐患告知单三通道** | 隐患单 → 告知单（整改要求 + 复访约定 + 停气条款 + **签字栏**，站点与许可证落款），微信文本同步发用户；合格单 → 安检回执——"我提醒过、他签收了"第一次变成可留存的凭据（告知单是提醒凭据不是责任切割） |
| 🖨️ **迎检打印包** | 站点与许可证号 · 体检结论（未闭环/到期/瓶检/证件/断更/守恒六查）· 入户安检台账（闭环列）· 配送台账（守恒体检）· 年度安检到期点名 · 钢瓶检验台账 · 员工证件——单文件 HTML 离线可用，30 秒出证 |
| ⚙️ **数据自持（交接即盘点）** | 100% 本地存储（用户底档与瓶账不出设备）；JSON 导出/导入（换机迁移含结构校验；**网点移交时整体带走用户底档 + 在户瓶数 + 未闭环隐患**）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
乡镇网络差照常用；出证走微信文本与本地打印，不依赖任何在线服务；用户底档与瓶账不出设备。**不碰充装追溯、不做政府报送、不做订气平台、不装报警器硬件**——充装赋码与流向报送是充装单位与监管平台的事，这里是网点自己的经营底账与自证凭据。

## 边界与免责

- **不碰充装追溯、不做政府报送、不做订气平台、不装报警器硬件**：瓶号手输照瓶身抄（这是特性不是缺陷：无硬件门槛、无报送合规负担、离线可用）。充装赋码与流向数据以充装单位与监管平台为准。
- **内置安检项与周期是通识口径预填，绝非属地执法口径**：入户五项（软管/减压阀/钢瓶/灶具连接/通风环境）为常见检查通报关键词的通识整理，绝非完整安检清单；年度安检 365 天、钢瓶检验 48 个月、预警窗 30/90 天均为通识默认值——**以《城镇燃气管理条例》原文与属地燃气管理部门要求为准，设置页全参数化可覆盖**。
- **打印台账不承诺执法采信**：迎检包是网点自查与备查底账（含守恒体检与隐患闭环），帮助站长"当场拿得出、说得清"；本地记录不具备司法级不可篡改性，不替代法定报送、公证存证或监管平台数据；隐患整改的法定效力以属地要求为准。
- **告知单是提醒凭据不是责任切割**：用户签字表示"知悉隐患与整改要求"，不等于责任转移；事故责任认定以司法机关与属地规则为准——**法律永远赢**。
- **工具不判真伪，只保完整与闭环**：补录数据如实存在（录入即留痕），台账的可信度建立在连续真实的记录上——本工具不提供任何"一键生成完美台账"的功能，造假风险自担。
- **用户底档最小留存**：仅存名称、电话、地址与常用瓶型，不存身份证影像；数据 100% 本地存储，换机/交接走 JSON 导入导出。
