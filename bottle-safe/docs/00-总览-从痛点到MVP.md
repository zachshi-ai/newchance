## 1. 痛点（真实世界，有据可查）

每送出一瓶液化气，网点就把一份易燃易爆品和一份法律责任一起送到了用户手里：

- **安检是法定义务**：《城镇燃气管理条例》（国务院令第 583 号）要求燃气经营者指导用户安全用气并对用户燃气设施**定期进行安全检查**，不履行义务有责令改正与罚款等罚则（通识口径，罚额检索受限已标注）；2021 年十堰"6·13"事故后，全国城镇燃气安全专项整治常态化，"送气必检"、实名购气在多地落地执行。
- **隐患只有闭环才有意义**：发现软管老化只登记不复查，事故后"早就发现了却放任"比"没检查"更重——纸隐患单开出去就石沉大海。
- **瓶账是资产账**：满瓶送出、空瓶收回，一户存几只瓶全凭记忆，餐馆以瓶抵款越记越乱；钢瓶是网点的主要实物资产，超期瓶在用户手里流转没人盯。
- **年度任务靠编**：逐户安检全覆盖的任务，纸表时代分不清哪户检了哪户没检，月底一天突击编单——逐户核对面前必然露馅。
- 现状解法 = **纸安检单塞抽屉 + 瓶数靠脑子 + 检查前突击**：储配站系统不覆盖承包末梢、政府追溯平台管报送不管自证——**配送与安检之间的证明黑箱没有任何小微级工具承接**。

## 2. 方案（机会 → 产品）

**瓶安单**：零依赖、本地优先的 PWA。

1. **用户建档即实名底档**：地址/电话/常用瓶型一次建好，配送与安检共用；钢瓶档案登记瓶号与检验到期（通识口径 48 个月周期、90 天预警窗，可调）。
2. **配送落账**（守恒账）：满瓶送出/空瓶收回按瓶型分行，在户瓶数由流水唯一派生（送出−收回）、**超收拒绝**（负数守卫）；站点级守恒体检（Σ配送净瓶 = Σ在户瓶）常亮。
3. **入户安检**（责任账）：软管/减压阀/钢瓶/灶具/通风五项逐检；**有隐患必须登记整改措施才让落账**；复访合格才销案，复访仍有隐患则接棒未闭环——"隐患—整改—复访"第一次成为可出示的完整链条。
4. **三类到期点名 + 断更体检**：年度安检（365 天可调）从未/逾期/临期四态点名、钢瓶检验到期、员工证件到期；台账断更日逐日点名。
5. **三通道出证**：隐患告知单（印刷级单文件 HTML，站点落款 + 整改要求 + 复访约定 + **签字栏**，微信文本同步发用户）/ 配送与安检台账文本（微信转发）/ 迎检打印包（站点与许可证 + 守恒体检 + 安检台账含闭环列 + 到期点名，30 秒出证）。
6. **体检与数据自持**：未闭环隐患 / 安检逾期 / 瓶检与证件过期 / 断更四查；100% 本地存储，JSON 导出/导入（交接即盘点），本地事件流可导出（验证闭环数据入口）。

## 3. 诚实的现状声明（真实可落地，不空中楼阁）

- **已验证**（本仓库内可复现）：核心逻辑 40/40 单元测试通过（含瓶数守恒与负数守卫、守恒体检残差、隐患强制整改、复访销案与非法复访拒绝、年度安检/瓶检/证件周期边界、断更体检、告知单与台账确定性、XSS 转义、打印包单文件无外部资源、导入导出往返与四种拒绝）；浏览器端到端全流程（示例数据 → 看板红灯 → 配送落账守恒 → 隐患落账强制整改 → 复访销案 → 告知单生成 → 迎检包导出）真实运行通过；零 npm/CDN/API 依赖；SW 缓存版本化。
- **未验证**（需真实用户，见 docs/13 假设登记册）：落账留存（H1）、迎检包真实使用与采信（H2）、告知单真实签字（H3）、付费意愿（H4）、储配站渠道（H5）——全部标注"待验证"并配有可证伪判据。
- **边界与免责**：不碰充装追溯、不做政府报送、不做订气平台、不装报警器硬件；内置安检项与周期是通识口径预填、以条例原文与属地要求为准（参数永远可覆盖）；打印台账不承诺执法采信；工具不判真伪、只保完整与闭环；告知单是提醒凭据不是责任切割。

## 5. 与既有项目的领域隔离（用户约束）

本方向为**燃气流通 · 瓶装液化气网点配送与入户安检合规台账（B2B 小微网点 · 住建/城管燃气监管线）**，已对照仓库根 README 领域登记表与 `newidea` 仓库 62+ 点子做领域排除：不与 `pet-handoff`（C 端宠物照护）、`food-sentry`（市监线 · 餐饮食品安全台账）、`turn-sheet`（民宿短租周转与布草供应链）、`work-proof`（人社线 · 雇主侧用工合规）、`class-off`（教培预收费课时账）、`agri-ledger`（农业农村线 · 农药购销台账）、`car-sheet`（商务/消费者保护线 · 二手车车况披露）重叠，也不与仓库内进行中草稿方向（生态环境线汽修危废、公共场所卫生线泳池水质）重叠，更不与 `newidea`（个人/家庭账本经济学 + 开发者工具，无任何燃气/液化气方向）重叠。监管部门（燃气管理部门）、付费主体（二级液化气网点与一级储配站）、使用场景（配送落账与入户安检/隐患整改出证）、行业语境（定期安检义务、隐患整改闭环、钢瓶守恒）均不同域——详见 [docs/14 内部交叉参照](14-调研来源.md)。
