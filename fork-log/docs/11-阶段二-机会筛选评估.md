# 阶段二 · 机会筛选评估

## 1. 波特五力

| 力量 | 强度 | 判断 |
|---|---|---|
| 现有竞争 | 低 | 小微场车合规台账无成熟供给：车队 SaaS 管运营不管合规，EAM 太重；「74 号令日管控台账」是 2023 年后出现的新位 |
| 新进入者威胁 | 中 | 技术门槛低，但法条口径沉淀（定检判档/复审窗口/五道闸的条号锚点）与登记表先发是护城河；风险主要是本地监管科技大厂下探 |
| 替代品 | 中 | 纸卡+Excel 免费（真实替代品）；74 号令 146/149 条把「记录与留痕」从美德变成刚需，是压替代品的法规杠杆 |
| 买方议价力 | 中 | 单价低（¥百元/年）、转换成本高（台账连续性即价值），但小微付费意愿需验证（H6） |
| 供方议价力 | 低 | 零依赖技术栈无供应锁死；分发依赖渠道商（见 docs/12 供应链），渠道初期议价力有限 |

**结论**：结构最好的组合=低现有竞争+法规造出的新义务+免费替代品被罚则压住——值得进入，胜负手在分发渠道与「打卡习惯」留存。

## 3. TAM-SAM-SOM（宽区间，诚实标注）

- **TAM**：全国在册场车 230.86 万台（2024 年底官方通报口径）。假设平均一个使用单位 3~10 台，使用单位量级 ≈ 25 万~70 万家（**无全国权威统计，宽区间待复核**）。
- **SAM**：3~50 台规模、无专职设备管理员的仓储/物流/制造/市场类小微单位，假设占 40%~50% ≈ 10 万~35 万家。
- **SOM（90 天~12 个月）**：经渠道分发+直营验证获取 1%~2% ≈ 1000~7000 家 × ¥199~299/年 ≈ **首年 ¥30 万~150 万理论上限；第一桶金目标保守取 ¥3,000~10,000（见 docs/13）**。所有乘数均为假设，判据见 H2/H6。

## 4. 机会-可行性四象限

```
        机会价值 高
            │
   ①大型车队管理 SaaS    ②★场车合规台账★
     （红海、重研发）       （法定新义务+空白供给）
──────────────┼────────────── 可行性
   ③重资产叉车租赁平台    ④IoT 安全监控硬件
     （资金密集）           （供应链重、周期长）
            │
        机会价值 低
```

②落入「高机会 × 高可行性」象限：法规刚造出义务、供给空白、零依赖技术栈可一周交付、渠道（经销商/定检机构/租赁商）现成。
