# 阶段三 · 机会转化产品方案

## 1. 商业画布

| 模块 | 内容 |
|---|---|
| 价值主张 | 「带病叉车开不出去」——五道闸派工 + 日管控周排查月调度三本法定文书自动生成 + 检查进门 30 秒出证 |
| 客户细分 | 3~50 台叉车的仓储/物流/制造/市场/景区小微使用单位（场车安全员与单位负责人是双用户） |
| 渠道 | ①叉车经销商/租赁商白标（上游即渠道）②定检机构合作推荐 ③属地特种设备安全培训/考核机构联营 |
| 客户关系 | 本机自服务 + 渠道代运维；出证物即留存钩子 |
| 收入流 | 单位 Pro ¥199~299/年（出证通道+多车档案）；渠道白标 ¥1500/年/商（分发 10~100 家） |
| 关键资源 | 法条口径引擎（周期/窗口/罚则锚点）、派工闸逻辑、仓库互斥登记位、渠道关系 |
| 关键活动 | 打卡闭环打磨、出证物保真、渠道开拓、法规追踪（74 号令执法动态） |
| 关键伙伴 | 叉车经销商、租赁商、特检机构、特种设备培训机构、保险经纪（场车责任险理赔要记录） |
| 成本结构 | 近零边际（无服务器，本地优先）；主要成本=渠道返佣与法规追踪人力 |

## 2. 价值主张画布

**客户任务**：每天派车不踩雷；检查来了拿得出东西；证照定检不忽然过期；出事时自证已履职。
**痛点**：记录分散在纸卡/Excel/微信；补表一夜；罚则真金白银；司机流动证件失控。
**收益期待**：少花钱、少跑腿、检查快过、出事有底。
**产品供给**： pain relievers——五道闸当场拦截、三色证照钟、复审窗口点名、闭环台账；gain creators——零风险报告一键留痕、迎检包十段对口 146 条、派工单快照存档（148 条：履职记录=免罚抗辩证据）。

## 3. 蓝海战略四动作（ERRC）

- **剔除**：车辆调度排班（车队系统的事）、卫星定位/IoT 硬件（车联网的事）、监管报送（监管平台的事）、纸卡印刷与改造（不做硬件）。
- **减少**：录入字段（一车一档 6 个必填以内）、打卡动作（30 秒/台/日）、学习成本（种子数据即教程）。
- **增加**：派工五道闸（全行业小微工具没有的门禁）、零风险报告语义（74 号令 142 条的软件化）、复审窗口 30 天黄线（旧口径 3 个月已废止的口径纠偏）。
- **创造**：拦截埋点账（每次拒绝都是「没被罚的证据」）、派工单核对快照（落账时点的定检/证照状态存档）、迎检自证包十段结构（对口监督检查内容清单）。

## 4. USP

**「无证司机、过期定检、未打卡的叉车——今天一样都开不出去；开出去的每一趟，都自动留了合规证据。」**
一句话区分车队 SaaS（管运营）与 EAM（管资产）：叉车账管的是「法定动作的证明链」。

## 5. Kano

- **必备（没有就不用）**：一车一档与定检钟；N1 证钟；日管控打卡；数据本机与导出备份。
- **期望（越多越满意）**：闸机拦截的准确与速度；出证物的完整与排版；周排查/月调度文书自动生成。
- **魅力（没想到会被满足）**：复审窗口按新规 30 天（而不是讹传的 3 个月）；严重隐患自动停用并卡派工；拦截记录本身成为检查时的「正面资产」；派工单快照能证明「当时核过」。
- **无差异（不做）**：车辆定位、油耗、维保工单、薪酬考勤。

## 6. 供应链分析（充分供应链视角）

**产品侧（客户的合规供应链）**：
- 上游：叉车制造商→区域经销商→租赁商（产权与登记的源头，87 号意见：登记在产权单位所在地、跨区作业不重复登记）；
- 服务链：特检机构（定检供给，约检窗口=产品提醒的对接口）、特种设备考试机构（N1 考证与复审）、配件维修商（隐患整改的执行方）、保险（场车责任险，理赔要巡检与隐患记录）；
- 监管链：市监局特种设备监察（使用登记/日常检查/处罚）、县局「两员」抽查考核（147 条《场车使用安全管理人员考核指南》）。
**产品自身供应链（零依赖技术链）**：无 npm/无后端/无 CDN——HTML+ESM+localStorage+SW 缓存，供应链风险≈0，交付即交付。
**分发链（上游即渠道，本仓库第 11 次复用）**：叉车经销商/租赁商是天然渠道——下游客户（用车单位）被停业/处罚=经销商应收坏账与复购流失；¥1500/年/商白标分发其客户池（10~100 家），渠道动机=设备续销关系保全。第二渠道=特检机构与培训机构：报检提醒为其降低失约率，复审窗口名单为其提供生源线索。
