# 拍片单 XrayPass（机会实验室 34 号项目）

> 口腔诊所/宠物医院等小微放射诊疗机构合规台账：**把 449 号令辐射安全许可、46 号令放射诊疗许可、设备年检、人员培训与剂量、妊娠询问红线，做成按下快门前瞬间的拍片六道闸，把每一次拍片做成自带合规快照的自证物。**

## 痛点

装一台牙科 X 光机要同时持**辐射安全许可证**（生态环境线：5 年、届满 30 日前延续）和**放射诊疗许可证**（卫生线：与执业许可证同时校验）——上海黄浦通报案例正是「持放射诊疗证但无辐射安全证」用机被罚（双证缺一）。设备要**每年至少一次状态检测**（46 号令第 20 条）、操作人员**培训考核不合格不得上岗**（449 号令第 28 条）、**个人剂量监测最长不超过 90 天**（55 号令第十一条）、育龄妇女拍片前**应问明是否怀孕**（46 号令第 26 条(三)）。无证用机低限罚 **1 万**、逾期不改正**停产停业或吊销许可证**（第 52 条）——2024 年以来马尔康、达州、乐山、南川、泰安的口腔机构通报连成一片。约 10 万放射工作单位里绝大多数是只有一两台机器的小微机构，现状解法是证压玻璃板下、剂量计塞抽屉、检测报告检查前夜翻箱倒柜——**「机在检、人在训、量在读」与「能证明」之间没有任何小微级工具。**

## 方案

零依赖本地优先 PWA——机构建档（**判型引擎**：口腔/其他医疗/动物诊疗 → 证件清单自动生成，双证钟）+ 设备一机一档（状态检测+场所防护检测双钟，停用联动）+ 人员名册（培训钟+剂量钟）+ **拍片六道闸**（双证在期 → 设备检测在期 → 培训在期 → 剂量在期 → 妊娠询问红线——当场拦截带法条理由+埋点留痕；过闸落账即存四期合规快照）+ 放射事件闭环状态机 + 变更/重新申领台账（第 11/12 条）+ 周期义务账（年度评估/演练/健康检查提醒）+ 十项体检 + 三通道出证（迎检自证包八段 HTML 含签字栏 / **拍片合规核对单**单次拍片证据链 / 月度小结微信文本）。

## 快速开始

```bash
cd xray-pass && npm start   # → http://localhost:8112
npm test                    # 25/25 单元测试
python3 tests/e2e.py        # 25/25 浏览器端到端（需本机 Chrome + http.server 8112 已启动）
```

## 诚实条款

技术可行性已在仓库内验证（25/25 单元测试 + 浏览器端到端 25/25：示例建档 → 看板红灯 → 超期人员/超期设备/妊娠未问/已怀孕四连拦截 → 问明未孕过闸落账 → 快捷补登复拍放行 → 月报拦截计数 → 自证包/核对单出证 → 刷新持久化全链路，零页面错误）；449 号令现行版（2019 二修）经维基文库全文逐条、46 号令 2016 修订经 nhc 官方 PDF+江苏卫健双源、55 号令现行经 nhc 法规库确认、射线装置分类经 66 号公告原文核验，全部集中于 [docs/14](docs/14-调研来源.md)（**雷区：双证分属生态/卫生两线、55 号令仍现行（「2024 新版」传言未获官方证实）、牙科与 CT 均为Ⅲ类装置、生态线年度评估≠卫生线许可证校验**）；黄浦/马尔康/达州/乐山/南川/泰安六地执法实证均为政府官网或官方媒体口径；449 号令维基文库转录未逐字比对公报原版、55 号令全文逐字、属地校验与检测频次细则等受限口径已如实标注待核；本工具不替医生做医疗照射正当性判断——只强制问明与留痕（特殊需要放行但如实打标）；不替代辐射安全许可、放射诊疗许可、校验、建设项目审查与个人剂量监测服务等法定程序，不承诺执法采信；口腔院感归灭菌单（#9）、职业健康监护归岗卫账（#22）、动物诊疗主体管理归兽诊账（#27），领域互斥；受检者身份不登记（最小披露），数据 100% 本机；商业假设（建档留存/落账习惯/妊娠询问执行率/特殊需要留痕真实性/出证使用/付费/渠道白标）全部标注「待验证」并配有可证伪判据。
