# docs/13 · 阶段四：产品落地验证闭环

## DSTE 主线

从「发现差距」到「设计执行」：市场差距=116 条罚则升格后的合规证明真空（2023 年起法律价）；产品差距=没有任何小微级工具把第 105 条三条件变成每日动作；执行主线=**旺季检查节奏驱动**（雪季开板 11~12 月、暑期潜水/攀岩旺季 6~8 月）拉新，月度小结/迎检包使用驱动留存。

## MVP 范围裁剪

**做**：场馆建档+许可证钟、人员名册证书钟、器材检验钟、日检卡（异常自动转隐患）、开馆五道闸+当日快照、隐患闭环状态机、变更台账、周期义务账、十项体检、三通道出证、导出备份。
**不做（本 MVP 边界）**：多门店总部视图、约课/收银/会员、监管报送接口、赛事活动许可办理（仅义务提醒）、游泳场所（领域互斥归 #12 泳清单）、IoT/传感器、云同步与多人协作。

## HDD 假设登记册（H1~H8，全部可证伪）

| # | 假设 | 验证方式 | 证伪线 |
|---|---|---|---|
| H1 | 场馆主知道 116 条罚则并认为与自己有关 | 建档访谈 20 家 | <30% 能说出任一罚额 → 教育成本超预期 |
| H2 | **开馆单会变成每日真实动作**（核心假设） | 本地埋点：周落单≥5 天的场馆占比 | 30 天留存 <30% 且周落单<3 天 → 闸机心智失败 |
| H3 | 日检卡同日唯一不会导致月底补填弃用 | 日检落卡日期分布 | 落卡集中在月末 >50% → 义务卡变纸面台账 |
| H4 | 隐患闭环状态机被真实使用而非绕开 | 埋点：整改→销案完成率 | 整改登记后 7 天未销案 >50% → 流程过重 |
| H5 | 出证物真实出示（对检查者/家长） | 自访+埋点 inspect/opening-print 事件 | 90 天出证使用率 <20% → 自证价值空心 |
| H6 | 渠道白标付费真实（经销商愿替下游买） | 3 家经销商意向金 | 0 家愿付 ¥1,500 → 渠道模型重设计 |
| H7 | 属地差异可控（参数化够用） | 5 省用户反馈周期差异 | 出现不可参数化的结构性差异 → 属地化成本重估 |
| H8 | 续期窗口（30 日）提醒带来续期成功率提升 | 窗口期用户回访 | 无感知差异 → 许可证钟降级为普通提醒 |

## OHELM 循环

- **Onboard**：示例数据 30 秒看清全流程（看板红灯→拦截→闭环→出证）。
- **Habit**：每日开门第一动作=过闸开馆；日检卡嵌在闸机前一道。
- **Engage**：三只钟每天点名、义务账月度滚动。
- **Loyalty**：月度小结进微信群=向合伙人/店长群体扩散。
- **Monetize**：Pro 解锁（器材不限量+出证抬头）+渠道白标。
- 埋点全部本地（traces 字段，不出设备，可在设置页导出）——与业务台账严格分离。

## 北极星指标

**周活跃开馆单数**（每周落单≥1 张的场馆数）——唯一同时捕捉「开门频次×闸机使用×留存」的指标。护栏指标：日检落卡率、隐患 7 日闭环率、拦截事件数（拦截=价值证据）。

## 第一桶金三路径（90 天 ¥3,000~10,000）

1. **渠道白标**（主攻）：岩点/造雪/潜水装备经销商 2~4 家 × ¥1,500/年，随发货/巡店触达下游 30~100 家场馆——动机：下游被停业=经销商坏账+复购断流。
2. **场馆 Pro 直销**：¥99~299/年 按项目数阶梯，旺季检查季转化。
3. **保险经纪联营**：责任险经纪以「有台账=核保更优」推荐，转介分成——第 33 条鼓励投保+理赔要当日记录，利益天然一致。

## 90 天验证排期（与旺季和执法节奏对齐）

- **D1~14**：法规口径冻结（docs/14）+ 示例数据打磨 + 5 家种子场馆建档（本地安装）。
- **D15~30**：拦截/落单埋点复盘 H2/H3；雪季前（11 月）渠道首谈——造雪/雪具经销商白标 2 家。
- **D31~60**：省级专项检查季跟访 3 次，验证 H5 出证真实使用；打磨迎检包字段。
- **D61~90**：H6 渠道付费意向金结算；TAM/SAM 用真实触达数据校准；决定加码（多店视图）或转向。
