# docs/12 · 阶段三：机会转化产品方案

## 商业画布

- **价值主张**：「五道闸全过，这扇门才开——开出来的每一张开馆单，都是你今天合规开门的证据」。
- **客户细分**：1~3 家门店的攀岩馆/室内滑雪馆/潜水俱乐部主理人（25~40 岁数字化原住民）；2~5 店小连锁；装备与器材经销商（渠道）。
- **渠道**：①岩点/攀岩装备经销商白标；②造雪机/雪具/魔毯供应商白标（冰雪经济 49 号文后设备商向下游渗透最快）；③潜水装备与培训体系代理商；④场馆协会/体育局产业处推介。
- **客户关系**：本地工具自助+旺季检查季社群运营。
- **收入流**：场馆 Pro ¥99~299/年（器材不限量+出证盖章版抬头）；渠道白标 ¥1,500/年/商。
- **关键资源**：条号级法规内容库（docs/14）、五道闸引擎、GB 19079 系列口径参数化。
- **关键活动**：法条维护、渠道联营、旺季（雪季开板/暑期潜水季）拉新。
- **重要伙伴**：装备器材经销商（上游即渠道）、场馆责任险经纪（理赔要当日记录）。
- **成本结构**：零服务器（本地优先），边际成本≈0。

## 价值主张画布

- **顾客任务**：每天合法开门；检查进门拿得出证据；证期不被忘；出事后说得清当天状态。
- **痛点**：罚则升格后的恐惧（116 条 5 万~50 万）；排班与证书对不齐；检查前夜补材料；续期窗口（30 日）错过即自动失效。
- **期望收益**：30 秒过闸开门；10 秒出证；义务账自动滚动；快照留痕。
- **产品与服务**：五道闸+三只钟+日检卡+隐患闭环+变更台账+出证三通道。
- **止痛**：闸机当场拦截=把违法成本变成当天的操作提示；快照=检查瞬间的答案已在账上。
- **创造收益**：开馆单打印版贴前台=给家长的信任物料（合规可视化）。

## 蓝海战略四动作（ERRC）

- **剔除**：约课排课、会员储值收银、营销获客、监管报送接口、IoT 硬件——全是红海或是别人的船。
- **减少**：落账动作压到 30 秒（点名勾选即落账）；证照录入压到「照证抄一次」。
- **增加**：开馆五道闸（法条引擎做成的门禁）；异常自动转隐患（日检→闭环→再开门的强制回路）；落账当日快照（不可事后修改的时间戳证据）；当日开馆单打印版（自证物即获客物料）。
- **创造**：本品类第一个「开门即合规」的工具——把《体育法》第 105 条三条件翻译成每天的门禁动作。

## USP

**「证在期、人够数、器在检——五道闸全过，这扇门才开；开过的每一天都自己留了证。」**
对照竞争者的差异：SaaS 卖经营效率，本工具卖「合法开门的可证明性」——在 116 条罚则时代后者才是刚需。

## Kano 模型

- **基本型**：许可证/证书/器材三只钟+到期提醒（没有=不合格）。
- **期望型**：检查卡按项目自动生成、义务账自动滚动、十项体检打分。
- **兴奋型**：开馆闸当场拦截带法条理由（把「不知道违法」变成「开不出门」）；异常自动转隐患、闭环才放行；迎检自证包一键出；拦截埋点账（每次拦截都是没被罚的证据）。

## 供应链分析（三层）

1. **用户行业的供应链**：场馆 ← 装备/器材/设备经销商 ← 品牌商；场馆 → 消费者（含未成年人培训场景）。合规风险沿链传导：下游场馆被责令关闭=经销商复购断流+应收坏账；事故=全行业舆情收紧。
2. **产品自身的供应链（技术链）**：零依赖——纯前端 PWA、localStorage 存储、无云无 API 无硬件，供方只有法规原文（免费权威）。风险=0 供应链风险，代价=无云同步（导出 JSON 备份解决）。
3. **分发链**：**上游即渠道**（本仓库第 13 次复用）：经销商手握下游 30~100 家场馆的订货微信与赊销关系，下游被停业=经销商的坏账与客户池流失——帮下游合规存续=保护经销商自己的资产负债表。第二渠道=责任险经纪（第 33 条鼓励投保，核保理赔都要看日常记录）。
