# 开馆单 VenuePass（机会实验室 30 号项目）

> 滑雪/潜水/攀岩场馆（高危险性体育项目经营单位）合规台账：**把《体育法》第 105 条「三条件」做成每天开门瞬间的开馆五道闸，把「持续符合」做成三只钟与一本义务账，把每一张开馆单做成自带当日快照的自证物。**

## 痛点

《体育法》2022 修订把高危体育经营许可升格为法律并把罚则全面加码——无证经营责令限期关闭、逾期不关罚 **10 万~50 万**；违法经营罚 **5 万~50 万**，严重后果吊销证照、**五年禁入**（第 116 条）。而许可证的合法性地基每天都在动：届满 **30 日**前申请续期（17 号令第 14 条，逾期未申请自动失效）、经营期间保持「规定数量」持证人员且持证上岗（总局检查标准 5 条）、设施器材维护保养+定期检测、应急预案要演练。811 家攀岩馆+748 家滑雪场+数百家潜水俱乐部几乎全是 2019 年后开的小微新店，现状解法是微信群排班+脑子记证期+检查前一夜凑材料——**「人在岗、证在期、器在检」与「能证明」之间没有任何小微级工具。**

## 方案

零依赖本地优先 PWA——场馆建档（许可证钟，届满 30 日续期窗口自动黄）+ 人员名册证书钟 + 器材一物一档检验钟 + 每日开放前检查卡（按项目自动生成，异常必写处置并自动转隐患）+ **开馆五道闸**（证在期/人数达标/证书在期/日检已落/隐患闭环，当场拦截带法条理由+埋点留痕，过闸落账即存当日快照）+ 隐患闭环状态机 + 变更手续台账 + 周期义务账（演练/培训/设施检测/保险/赛事许可自查）+ 十项体检 + 三通道出证（迎检自证包九段 HTML 含签字栏 / 当日开馆单打印版 / 月度小结微信文本）。

## 快速开始

```bash
cd venue-pass && npm start   # → http://localhost:8108
npm test                     # 24/24 单元测试
python3 tests/e2e.py         # 27/27 浏览器端到端（需本机 Chrome + http.server 8108 已启动）
```
