# 护安单 CareLedger

> 小微养老机构的服务安全台账 —— 九防评估、每班 30 秒打卡、事件闭环与家属告知、周期义务点名、检查 30 秒出证。
> 零依赖 · 本地优先 PWA · 数据不出设备。

```bash
cd care-ledger && npm start   # → http://localhost:8089
npm test                      # 21/21 单元测试
```

## 为什么需要它

- **GB 38600-2019**《养老机构服务安全基本规范》是养老服务业第一个强制性国标（2022-01-01 全面实施）：九防（噎食/误食/压疮/烫伤/坠床/跌倒/走失/他伤自伤/活动意外）评估与防护是强制底线。
- **《养老机构管理办法》（民政部令第 66 号）**：入院评估（第 15 条）、24 小时值班（第 28 条）、突发事件应急预案与定期演练（第 31 条）、信息档案保存不少于服务协议期满后五年（第 32 条）；民政部门**每年至少一次现场检查**（第 38 条）；未按强标提供服务可被警告直至 3 万元以下罚款（第 46 条）。
- **纠纷现场**（民法典第 1198 条安全保障义务）：跌倒、噎食、压疮、走失四类事故的裁判焦点是"照护是否到位、发现是否及时、是否通知了家属"——三问的答案全部落在记录上，拿不出记录就要吃下更大的责任比例。
- 而 10~100 床民办院的现状解法 = 纸本交接本 + 记性 + 微信语音：断更没人看见、事件只走口头、演练体检靠运气。

**护安单 = 把"做了"变成"能证明持续做了"。**

## 功能速览

| 模块 | 做什么 | 硬规则 |
|---|---|---|
| 老人 | 建档 + 九防风险评估 | 建档即全「未评估」点名；watch/high 级别强制写防护措施 |
| 值班 | 每班 30 秒打卡（署名 + 交接要点） | 同班次唯一；异常必须写明处置；夜巡次数不足自动亮灯；缺班自动点名 |
| 事件 | 跌倒/噎食等事件登记 → 闭环 | **家属告知（时间+方式+通知人）与复盘整改填不齐，拒绝结案** |
| 周期 | 评估复评 / 应急演练 / 员工体检 | 到期/临期点名；完成打勾自动滚动下一轮 |
| 自证包 | 按老人 × 时段一键出证 | 微信文本 / 打印版单文件 HTML（含查阅签字栏）/ 直接打印；**记录缺口如实列出，不掩饰** |
| 设置 | 班次、夜巡下限、周期天数 | 全部参数化——属地口径永远赢 |

本地优先不是口号：老人健康与家属信息 100% 存于本机浏览器（这本身就是 66 号令第 32 条个人信息保护义务的实现方式），换机走 JSON 导出/导入，埋点本地可导出用于验证。

## 诚实条款

- 技术可行性已在仓库内验证（21/21 测试 + 浏览器端到端：建档 → 评估 → 打卡 → 闭环门禁 → 出证全链路）。
- 自证包是机构自查与沟通记录，**不宣称司法级存证**；不替代法定信息档案、视频监控记录与民政报送。
- 不提供"补记洗白"——缺口如实列出，补记必须注明；工具的立场是帮认真照护的机构自证，不是帮失职的机构化妆。
- 商业假设（评估留存/打卡留存/闭环使用/出证使用/付费/渠道联营）全部标注"待验证"，配有可证伪判据（docs/13）。
