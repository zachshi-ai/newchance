# 10 · 阶段一：识别机会与洞察市场

> 本阶段回答：世界的哪个痛点值得做？用第一性原理拆到底，用 JTBD / 船模型 / 非消费者分析还原真实场景，用 PESTEL 扫宏观，用机会缺口矩阵定位空白。

---

## 1. 第一性原理拆解

不问"市面上有什么养老软件"，只保留不可再分的事实：

| # | 不可再分的事实 | 推论 |
|---|---|---|
| F1 | 照护质量是典型的**信任品**：家属看不见凌晨三点的护理站，监管看不见每一班的巡查，法官更不可能时光倒流回跌倒现场——服务过程**无法被看见，只能被证明**。GB 38600-2019《养老机构服务安全基本规范》（养老服务领域第一个强制性国家标准，2019-12 批准发布，2022-01-01 起全面实施，[国家标准全文公开系统已核验](14-调研来源.md)）把"九防"（防噎食、防食品药品误食、防压疮、防烫伤、防坠床、防跌倒、防走失、防他伤和自伤、防文体活动意外）变成强制底线 | **证明成本**（把看不见的照护变成拿得出手的记录）是整个痛点的第一性变量。谁把"做了"变成"能证明持续做了"，谁就给机构装上了生存基建 |
| F2 | 记录义务是**法定的、逐条可核验的**：《养老机构管理办法》（民政部令第 66 号，2020-11-01 施行，[司法部官网全文已核验](14-调研来源.md)）第十五条入院评估制度、第十九条健康档案与"转送救治**并通知紧急联系人**"、第二十八条"实行 24 小时值班"、第三十一条应急预案与"**定期**开展演练"、第三十二条信息档案"保管期限不少于服务协议期满后五年"；第三十八条民政部门"**每年**对养老机构服务安全和质量进行不少于一次的现场检查"；第四十六条罚则——未建评估制度、未按强制性国标提供服务、未依规定预防和处置突发事件，责令改正、警告，情节严重可处 3 万元以下罚款 | 这不是"数字化偏好"，是**持证经营的成本项**。备案后 20 个工作日内首次现场检查（第三十八条），每年至少查一次，双随机抽查对"风险高的机构提高频次"（第三十九条）——记录就是检查现场的第一追问点 |
| F3 | 纠纷的举证压力**全部落在机构一侧**：《民法典》第一千一百九十八条安全保障义务（经营场所、公共场所的经营者未尽义务承担侵权责任）+ 服务合同违约竞合；公开裁判文书与行业通识口径下，跌倒、噎食、压疮、走失四类事故是养老机构诉讼的主场，裁判焦点集中在"**照护是否到位、发现是否及时、是否通知了家属**"——而这三问的答案全部落在记录上，拿不出记录的机构按行业通识会被认定举证不能，责任比例显著上浮 | 台账同时是**合规凭据、理赔证据与声誉防线**：检查、保险理赔、家属质询、诉讼四个场景共用同一本账。对一家 30 床的民办院，一例败诉赔偿（数十万元级）> 全年护理耗材支出——损失函数决定了痛点真实 |
| F4 | 记录是**每班次、永不停止**的纪律：24 小时值班意味着一天至少 2~3 个班次、365 天不断档；纸本交接本断一天，检查现场就是"你这记录是补的吧"——连续性一旦存疑，整本台账的可信度归零 | 断更是台账可信度的最大杀手。工具的第一职责不是"帮你照护"（照护动作本来就有），是**让"做完顺手落一笔"成本趋近于零、让断更与漏处置在爆发前被看见** |
| F5 | 小微机构的现状解法 = **挂墙的纸本交接本 + 老板娘的记性 + 微信语音**：巡查做了、字也签了，但纸本经不起"连续 90 天逐日核对"；家属问"我妈今天怎么样"靠回忆回答；出了事连夜补记录——字迹时间全是破绽 | 现状解法的失败不在"没照护"，在**记录无法自证连续、事件没有闭环、周期（评估/演练/体检）没有人盯**——三件事都是软件极擅长而纸本结构性做不到的 |
| F6 | 业态高度分层：智慧养老平台与机构管理系统（呼叫系统、IoT 看护、全模块 SaaS，数万元级 + 年费 + 实施培训）服务公办与大型连锁；政府侧监管平台管备案与报送；**10~100 床的民办养老院、乡镇敬老院、社区嵌入式中型机构被整个市场排除在外**——它们买不起全家桶，也没有信息科 | 小微机构是非消费者（见 §5）；一部值班手机 / 一台值班室 iPad，就能把"证明基建"建起来——硬件不必是前置条件 |
| F7 | 民办养老是**微利 + 高责任 + 支付方敏感**的生意：2024 年末注册登记养老机构 4.0 万个（床位 507.7 万张，[民政部 2024 年民政事业发展统计公报口径](14-调研来源.md)），机构数量同比还在收缩——倒闭潮里活下来的机构，最怕的不是没客人（老龄化托底需求），是**一起赔偿官司**；同时机构还鼓励投保责任保险（66 号令第三十四条），保险neeeds风控证据 | 定价必须免费增值、年费一百元量级；付费叙事是"赔偿与处罚的止损 + 家属信任的增益"，不是"提效降本"；渠道必须借监管节奏（年底年检、双随机抽查、专项检查）与保险续保节奏 |

**第一性结论**：养老机构的生存确定性 = 「九防评估的完备性 × 值班记录的连续性 × 事件处置的闭环性（含家属告知）× 周期义务的按时性」，四件事共用**同一本服务安全账**。谁把"照护完顺手落一笔、缺一班点名一班、出了事必须走完告知与复盘、检查 30 秒打出整月台账"的成本打到趋近于零，谁就把 GB 38600 的强制底线从墙上的标语，变成机构的信任资产。

## 2. 痛点 - 爽点 - 痒点模型（梁宁）

| 层 | 用户心理 | 护安单对应 |
|---|---|---|
| **痛点**（恐惧/怕） | 怕民政检查时纸本"连不上、补的痕迹太明显"；怕老人夜里跌倒没及时发现；怕出了事家属问"你们到底有没有人盯着"拿不出证据；怕噎食、走失后举证不能全责赔偿；怕演练、体检、评估过期被当场指出；怕员工没培训就上岗出事 | 九防评估建档即点名（watch/high 强制写措施）→ 缺班自动点名 → 事件未走完家属告知与复盘**不允许结案** → 周期义务到期亮灯 → 自证包 30 秒出证——风险在爆发前被看见 |
| **爽点**（即时满足） | 检查人员来了不慌；家属群里甩出当日记录瞬间有面子；交接班不再靠喊；夜班有没有巡够次数终于有人知道 | 30 秒一键班次打卡（署名 + 平安）；自证包微信文本直发；缺班、夜巡不足、未闭环事件全部自动点名，不用翻本子 |
| **痒点**（理想自我） | "我们是记录齐全、家属放心的正规机构"——差评时代，老人家属选院第一问就是"照顾得细不细"；星级评定（GB/T 37276 口径）与家属信任共同指向"这家机构井井有条" | 自证包打印版的机构抬头 + 查阅签字栏；九防防护措施一览成为家属参观时的讲解材料——把合规成本变成招生信任的展示面 |

## 3. JTBD（待完成的任务）

> 当我**把老人收住进来**，我想在第一分钟就知道他有哪些风险、该采取什么防护（When 我签下服务协议，I want 一次把九防评估做完并有据可查，so I can 让后续每一班照护有依据、出了事有底）。

> 当我**每晚交接班**，我想 30 秒确认今天每一班都有人署名落账、夜巡够了次数、异常有人接手（When 我交出钥匙，I want 交接要点和异常处置留痕，so I can 明天任何追问都有答案）。

> 当我**遇到跌倒/噎食/走失**，我想在处置完的第一时间通知家属、补全复盘，并把这一切变成拿得出手的记录（When 突发事件发生，I want 强制闭环——处置、告知、复盘缺一不可，so I can 对家属有交代、对监管有底账、对法官有证据）。

> 当我**迎接年检/抽查/家属参观**，我想按老人、按时段一键拿出"我们是怎么照护的"完整记录（When 检查或质询发生，I want 30 秒生成自证包，so I can 不再连夜补记录）。

| 任务维度 | 雇佣的产品 | 被解雇的方案 |
|---|---|---|
| 功能性 | 把九防评估、值班巡查、事件处置、周期义务变成一本连得起、拿得出的账 | 纸本交接本 + Excel + 记忆 |
| 情感性 | 检查不慌、家属质询不虚、出了事有底气 | 出事后的恐惧与连夜补录 |
| 社会性 | "正规、负责、透明"的机构形象 | 出事上通报名单后的信任崩塌 |

## 4. 机会缺口矩阵

| | 现有供给已解决 | 现有供给未解决 |
|---|---|---|
| **用户已意识到** | 大型机构的全模块管理（智慧养老平台/机构管理系统：呼叫、照护记录、排班、计费） | **小微机构的"证明成本"**：买不起全家桶的 10~100 床民办院，没有工具把九防评估、每班打卡、事件闭环、周期义务连成一本能自证的账——纸本连不成链，Excel 不会点名 |
| **用户未意识到** | 监管与保险的数据接口（报送、IoT） | **记录的连续性本身就是价值**：多数机构以为"做了"就行，没意识到"能证明连续做了"才是检查、理赔、诉讼的生死线——直到收到整改通知书或传票 |

**机会定位**：右上象限的空位——**已意识到的痛（检查与纠纷）× 未被解决的供给（小微级证明基建）**。

## 5. 非消费者分析

| 非消费者 | 为什么被排除 | 转化路径 |
|---|---|---|
| 乡镇/社区民办小型养老院（10~50 床） | 全家桶数万元 + 实施培训 + 信息科门槛；老板兼院长，没人管系统 | 零安装 PWA + 30 秒打卡 + 微信文本通道，值班手机即可用 |
| 公办乡镇敬老院（改造后的老机构） | 有财政拨款但采购流程长，免费政府平台只管报送不管经营底账 | 免费核心 + 本地存储打消数据顾虑；打印台账直接服务迎检 |
| 连锁机构的边缘单店 | 总部有系统，但单店安全台账常游离在总部报表之外 | 单店轻量用，导出 JSON 汇总给总部 |

## 6. PESTEL 宏观机会扫描

| 维度 | 信号 | 对本项目的含义 |
|---|---|---|
| **P** 政治 | 老龄化是国家战略（积极应对人口老龄化上升为国家战略）；GB 38600-2019 强标全面实施 + 66 号令确立"每年至少一次现场检查 + 双随机 + 失信提高频次"的常态化监管；民政部门对养老机构重大事故隐患的整治持续高压 | 合规刚性持续增强——监管节奏就是获客节奏（年底年检、专项检查前是采购窗口） |
| **E** 经济 | 2024 年末注册养老机构 4.0 万个、同比 -1.2%（[统计公报口径](14-调研来源.md)）——供给出清进行时；60 岁以上人口 3.1 亿（22.0%，国家统计局 2024 公报）需求长期托底 | 出清期活下来的机构对"赔偿止损"最敏感——恰是付费意愿最强的客群；机构微利决定定价锚点在百元级 |
| **S** 社会 | 独生子女一代父母进入高龄，"替我看着爸妈"是普遍焦虑；养老纠纷与负面报道放大家属对机构的天然不信任 | 透明化（每日记录、家属告知）从成本变成招生卖点——痒点的社会基础 |
| **T** 技术 | 微信普及 + 智能手机在护理站已常态；PWA/本地存储技术零门槛；IoT 与呼叫系统对小微仍是过度方案 | 零依赖本地优先 PWA 恰好卡在"能力已到位、方案未下沉"的窗口 |
| **E** 环境 | — | 弱相关（消防与建筑安全属住建/消防线，本产品不做、已在边界声明） |
| **L** 法律 | 民法典 1198 安全保障义务；66 号令第四十六条罚则（未按强标提供服务最高 3 万元 + 警告 + 责令改正，情节严重涉刑责）；档案保存 ≥ 协议期满后五年；鼓励投保责任保险（第三十四条） | 法定义务逐条可引用——产品的红线引擎有权威锚点；责任险渠道（第四条路径）有法条背书 |

**PESTEL 结论**：政策（强标 + 常态检查）、社会（信任焦虑）、技术（手机已到位）三线共振，经济维度供给出清反而筛出了最痛的付费客群——宏观窗口成立。
