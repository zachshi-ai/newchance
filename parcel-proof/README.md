# 递安单 ParcelProof 📦

> **小微快递末端网点的三项制度自证与服务台账：备案 20 日红线倒计时、投诉 7 日答复钟、拦截登记簿、考核罚款申诉挽回账、底单销毁台账——检查来了 30 秒出证，罚款来了 10 分钟出申诉单。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 数据不出设备

快递末端网点（快递超市/驿站兼收寄点/承包区站点）站在寄递安全的闸口上，而闸口的义务全是网点的：收寄要**验视内件并作出验视标识**、寄件人要**查验登记身份**、用户投诉要**自接到之日起 7 日内处理并告知**、快递运单要**定期销毁**、培训演练要定期开展、末端网点**开办 20 日内要备案**——《快递暂行条例》（2025 年修订，国务院令第 806 号）第 19/23/29/32/35/36 条，罚则 1 万起步、验视违规转致《反恐怖主义法》第 85 条 10 万~50 万。还有一条没人替网点记的钱线：**总部考核罚款月月挨罚，申诉要证据**。现状是送货单背面记流水、投诉靠翻微信群、底单塞麻袋、备案日在老板脑子里——递安单把这段黑箱变成白箱：建档上钟 → 每天 30 秒三确认落账 → 拦截就登记（拦下来的每一件都是没被罚的证据）→ 投诉答复钟自动算 → 罚款登记、申诉、挽回金额进账 → 三通道出证。

## 3 条命令跑起来

```bash
cd parcel-proof
npm start           # 等价于 python3 -m http.server 8096 --directory app
open http://localhost:8096
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程。

## 功能

| 模块 | 说明 |
|---|---|
| 🏪 **网点建档 + 备案钟** | 名称/品牌/负责人/开办日；**开办之日起 20 日内备案**红线倒计时（条例第 19 条），已备案登记编号与备案日转绿；备案违规罚则（第 50 条）随钟展示 |
| ✅ **每日三项制度落账** | 验视/实名/安检三确认 + 收寄件数，30 秒一笔、同日唯一；勾了「未执行」必须写原因——如实登记是底线，体检会点名缺口日 |
| 🛑 **拦截登记簿** | 拒绝验视/拒绝实名或身份不实/疑似禁寄——登记原因与处置（当场退回/报告邮管/报告公安/暂存），暂存与报告类必须闭环销案；**拦截名册是正面自证资产** |
| 💬 **投诉台账 + 7 日答复钟** | 登记（现场/总部考核转来/12305 转办）→ 答复截止日自动计算（条例第 29 条），红黄绿点名；答复可超期登记但**如实打标「超期」**——不粉饰 |
| 💰 **考核罚款与申诉挽回账** | 罚款入账（编号/金额/依据/可关联投诉）→ 登记申诉 → 结果落账（全额撤销/部分减免/维持原罚，金额守恒校验、一次定案）→ **月度挽回金额看得见**；按笔生成**申诉材料单**（关联投诉时间线 + 前后 15 天落账与拦截证据 + 签字栏） |
| 🗑 **底单销毁台账** | 定期销毁的落实痕迹（方式/数量/经办/监销）；周期钟超线点名（条例第 35 条，90 天为参数化通识口径）——信息泄露倒查第一问就是销毁记录 |
| 🗓 **周期义务账** | 安全培训/应急演练/消防器材/车辆电池充电四类，打勾自动滚动下一周期，逾期点名（条例第 21/36 条 + 应急部令第 5 号第 37 条场景） |
| 🩺 **账本体检** | 八项灯位打分：备案/断更/三确认完整性/拦截闭环/投诉答复/罚款挂账/销毁/义务——迎检前先自查 |
| 📑 **三通道出证** | 月度小结（微信文本）/ **迎检自证包**（单文件 HTML 含签字栏，八段全景，检查重点对标条例第 46 条）/ 申诉材料单 |
| ⚙️ **数据自持** | 100% 本地存储；当事人建议只登记姓氏或尾号（最小披露）；JSON 导出/导入（含结构校验）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
末端网点在乡镇也在城中村，网络时好时坏，PWA 离线可用；月度小结走微信文本，不依赖任何在线服务；当事人信息只存本机（本地优先即《个人信息保护法》最小披露的实现方式）。**不做实名收寄报送、不做件数对账、不碰政府平台接口、不做财务进销存**——实名与路由是总部系统的事，报送是邮管平台的事，这里是网点自己的自证底账。
