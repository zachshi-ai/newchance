# 12 · 阶段三：机会转化产品方案

> 本阶段回答：机会怎么变成一个可卖的产品？用商业画布与价值主张画布定结构，用蓝海四动作定差异化，用 Kano 裁 MVP，最后把供应链想透——本项目供应链分析的重头戏是**师资供应链**（课时费底账）与**分发链**（教具/演出服供应商即渠道）。

---

## 1. 商业画布（Business Model Canvas）

| 模块 | 内容 |
|---|---|
| **客户细分** | 非学科小微培训机构（舞蹈/美术/体育/音乐/编程/书法，1~2 场地、几十到几百学员、夫妻店 + 兼职教师）；单飞教师工作室；渠道客户：**教具/画材/演出服/乐器配件供应商**（联营贴牌，见 §6.3） |
| **价值主张** | 对机构主：课时负债账清清楚楚、家长问余额 10 秒回复、临期过期先知道、退费试算给双方台阶、教师课时费月底不扯皮、60 课时红线体检；对家长：明白消费，每一节课都算得清；对教师：结算有双方共认的底账 |
| **渠道** | 直达：小红书/抖音"退费纠纷/课时扯皮"场景内容 + 机构主微信群；渠道：**教具/演出服供应商联营**（上游供应商即分销商）、教师 KOL 社群团长分佣、县域机构主社群 |
| **客户关系** | 免费自助 + 内容号陪跑（预收费合规/对账话术内容）；教具商渠道由商家代维护客户关系 |
| **收入来源** | 免费版（单校区全功能）；Pro 待验证（H4 假门 ¥199/年）：多校区、经营报表、自定义对账单抬头；教具商联营年费 ¥1500/商（白标 ≤50 家机构）待验证（H5） |
| **核心资源** | 消课/对账内容模板库（红线政策跟踪 + 家长话术）、"消课单 = 课时对账"品类心智、教具商渠道关系 |
| **关键业务** | 模板内容运营（政策与话术跟踪）、渠道拓展（教具商/教师 KOL）、留存运营（余额/临期预警） |
| **重要伙伴** | 教具/演出服/画材供应商（渠道 + 内容源：机构采购节奏的真实口径）、静态托管平台、教师 KOL 社群 |
| **成本结构** | 近零边际成本：无服务器账单、无 npm 审计、单人维护；获客内容制作为主要成本 |

## 2. 价值主张画布（Value Proposition Canvas）

**客户侧（小微机构主）**

| 客户任务 | 痛点 | 期望收益 |
|---|---|---|
| 课后把课时记对 | 纸卡/Excel 回头再记 = 永远不记 | 点名即落账 30 秒，点错可撤销 |
| 回答家长"还剩几节课" | 翻表回微信，慢且心虚 | 对账单复制 10 秒发送，机构品牌落款 |
| 课包到期前消化/谈延期 | 过期才发现，家长闹"为什么不早说" | 临期 30 天窗 + 过期未消点名 |
| 退费谈判 | 没有已消课时凭据，只能吵 | 按包折算的退费试算单，赠课/过期单列 |
| 月底结教师课时费 | 两本账对不上扯皮 | 按月自动汇总的教师课时工资表 |
| 预收费合规自查 | 说不清自己是否踩 60 课时红线 | 建包即体检，红线/变相打包当场亮灯 |

**产品侧**

| 功能 | 减痛 / 创益 |
|---|---|
| 一课一消落账 + 精确回滚 | 减痛：账实一致，点错不怕 |
| 家长对账单三通道（微信文本为主） | 创益：家长零安装，信任可交付 |
| 余额/临期/过期三类预警 | 减痛：续费触点 + 过期纠纷疫苗 |
| 退费试算（逐包折算、赠课不折现） | 创益：给双方一个都能看的数 |
| 教师月课时工资表 | 创益：劳资对账底账，一份流水两份价值 |
| 60 课时红线体检 | 创益：合规自查顺手完成 |

**契合检验**：六个客户任务 ↔ 六项功能一一对应，无"我们做了但没人要"的悬空功能。

## 3. 蓝海战略四动作框架（ERRC）

| 动作 | 内容 | 效果 |
|---|---|---|
| **剔除 Eliminate** | 招生营销/裂变、在线排课预约、在线收退费/支付、监管平台报送、多角色权限与实施培训 | 与教培 SaaS 正面会战的战场全部放弃；支付合规与报送义务一并剔除 |
| **减少 Reduce** | 建档字段（学员 3 项、课包 6 项）、消课动作（勾学员 → 落账两步）、报告格式（对账单一种模板） | 把"系统"从文书工作降为微信级别动作 |
| **增加 Increase** | 余额/临期/过期三类预警、退费逐包试算单、教师月课时工资表、60 课时红线体检、对账单双方签字栏 | 把"记课时"升级为"有账、有预警、有凭据、有台阶"的负债管理闭环 |
| **创造 Create** | **"预收费与课消之间的确定性"**——机构从未体验过的负债透明；家长侧第一次收到结构化课时对账单 | 非消费者（纸卡作坊、单飞教师、反 SaaS 老板）转化为用户 |

## 4. USP（独特销售主张）

> **唯一为小微非学科机构设计的课时账本：上完课点名即消课，微信发家长即对账；余额临期先知道，退费试算有台阶，教师课时费月底不扯皮。不做招生、不做排课、不做在线收退费，家长不用装 App，免费开始。**

- 对比纸卡 Excel：有账、有预警、有凭据，"回头再记"变成"当场记完"；
- 对比教培 SaaS：不要钱（单校区）、不要学、不要实施，专管 SaaS 不管的那一段（课时负债与对账）；
- 对比监管平台家长端：它是资金存管通道，消课单是机构自己的经营底账——互补不替代。
- 三句话之外的克制：**不说"保证续费"，不说"替代报送与存管"**——证据效力边界见诚实条款（docs/13 §6）。

## 5. Kano 模型 → MVP 范围裁剪

| 类型 | 功能 | MVP 取舍 |
|---|---|---|
| 基本型（没有就骂） | 学员/课程/教师建档、购课建包、点名消课落账、对账单导出（文本/HTML/打印） | ✅ 已做（35/35 测试覆盖核心逻辑） |
| 期望型（越多越好） | 消耗顺序（正课先/临期先/FIFO）、余额/临期/过期预警、消课撤销回滚、重复点名拒绝 | ✅ 已做 |
| 兴奋型（超出预期） | 退费试算单、教师月课时工资表、60 课时红线与变相打包体检 | ✅ 已做（数据齐了自动出现）；自定义抬头/报表进 Pro/迭代池（H4 验证后再投入） |
| 无差异（别做） | 招生裂变、家校朋友圈、成长相册、积分商城、排课日历 | ❌ 永不做（偏离课时账主线） |

## 6. 供应链分析（重点：师资链 + 技术链 + 分发链）

### 6.1 机构侧供应链（教培为家长整合的"上游"——消课单把最重的一环数字化）

机构交付"一学期能力成长"，其上游最重的变动成本是**师资供应链**：兼职教师按节计酬、流动性大、结算靠各记各的账。消课单的动作映射：

| 环节 | 链路 | 暗账（没人记的部分） | 消课单的动作映射 |
|---|---|---|---|
| 排课上课 | 固定课表 + 临时调课 | 调课后谁上了谁没上全靠记忆 | `applySession` 按日点名落账，同科目同日重复点名拒绝 |
| 课时消耗 | 学员课包逐节核销 | 纸卡划课滞后、Excel 不聚合 | 一课一消：正课先/临期先/FIFO，跨包自动接续 |
| 劳资结算 | 月底教师对课表结课时费 | 两本账对不上就扯皮，旺季更甚 | `teacherPayroll` 按月自动汇总，每节 × 单价，导出即结算单底稿 |
| 退费结算 | 家长提出退费 → 按已消折算 | 没有凭据只能吵，赠课过期各说各话 | `refundEstimate` 逐包折算、赠课不折现、过期单列——试算单即谈判桌 |

**场地与教具供应链**：房租按月固定（与课消无关，不做）；教具/画材/演出服是机构的高频采购（见 §6.3 渠道复用）——消课单不碰采购（ERRC 剔除），只把"上课人次"这本账记准，它是机构与一切上游谈判的底气。

### 6.2 产品自身供应链（MVP 的技术依赖链，逐项消除单点故障）

与 pet-handoff / food-sentry / turn-sheet 同一架构纪律：**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**

| 依赖 | 决策 | 单点故障消除 |
|---|---|---|
| 后端/数据库 | 无（localStorage 本地优先） | 无云账单、无停服；学员姓名/课时/金额不出设备；县城机构网络差照常用 |
| 第三方库 | 无（core.js 纯函数，日期/顺序/试算/导出自实现） | 无供应链投毒面；`node --test` 零依赖可测 |
| 分发 | 任意静态服务器（`python3 -m http.server` 3 条命令） | 文档根即部署根，可迁移任意托管 |
| 对账/导出 | 微信文本 + 单文件 HTML（内联样式）+ 系统打印 | 不依赖任何在线渲染/消息服务，家长零安装 |
| PWA 离线 | sw.js 缓存应用壳（版本化 + `cache:'reload'` 更新） | 断网可用；升级可靠到达 |

### 6.3 分发供应链（获客链路——上游供应商即分销商的结构性优势）

```
内容制作（小红书/抖音："退费扯皮的第一现场是没有消课账" 场景内容 + 对账单模板引流）
      ↓ 免费工具承接（零摩擦，扫码即用）
直达用户（机构主微信群 / 单飞教师 / 县域机构社群）
      ↓ 规模化放大（本项目独有的渠道结构）
渠道分层：① 教具/画材/演出服/乐器配件供应商联营（B2B2C）：商家把消课单贴牌赠给下游 50 家客户机构
         → 商家动机：客户机构经营得越久采购越多；课时账清晰 → 机构存活率上升 → 采购基本盘扩大；
           白标对账单落款 = 商家每周对机构的品牌触达
         → 消课单动机：一个省级画材/舞蹈用品经销商背后是 100~1000 家活跃机构，获客成本 ≈ 0
         ② 教师 KOL 社群团长分佣：舞蹈/美术/音乐老师社群是机构主的聚集地，团长按成交 20% 分佣
         ③ 单飞教师自用迁移：老师从机构独立时带走自己的消课单 = 产品跟着人走
```

每层渠道都已有真实存在的服务商（教具经销商、教师社群团长）——不需要发明新的中间商，只需给他们一个更好送的商品。**教具/演出服供应商是全链路里"上游供应商反过来是分销商"的角色——供应链即渠道，与翻房单的洗涤厂联营同构但领域不同。**

---

**阶段三结论**：商业结构成立的关键在"近零成本 + 免费增值 + 教具商渠道复用"；产品差异化在"把预收费与课消之间的负债黑箱变成白箱，并顺手记了师资劳资对账的底账"。所有付费与渠道假设进入阶段四的假设登记册逐一证伪。
