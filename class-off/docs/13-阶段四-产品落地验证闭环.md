# 13 · 阶段四：产品落地验证闭环

> 本阶段回答：怎么证明这个产品会成（或不成）？用 HDD 把信念变成可证伪假设，用 OHELM 循环推进验证，用 90 天排期对齐教培学期节奏，并确立第一桶金。

---

## 1. 假设登记册（HDD）

| # | 假设 | 判据（可证伪） | 验证方法 | 状态 |
|---|---|---|---|---|
| H1 | 机构会持续点名消课（动作留存是全产品的地基） | ≥40% 建档机构第 14 天仍有消课记录新增 | 本地事件流（`session` 埋点，设置页可导出）+ 20 家种子机构微信群自愿回传 | ⬜ 待验证 |
| H2 | 对账单会被真实发给家长（核心动作） | ≥50% 有课包机构每月导出对账单 ≥1 次；文本复制（微信）占比 ≥70% | 埋点：`statement` 事件按 action 分桶（copy/download/print） | ⬜ 待验证 |
| H3 | 退费试算在真实纠纷中被使用 | 有退费场景的机构中 ≥30% 使用过试算并反馈"有台阶" | 埋点：`refund-estimate` 事件密度 + 种子访谈 | ⬜ 待验证 |
| H4 | 付费意愿存在且锚点在两百元内 | 假门按钮点击率 ≥5%；或 ≥10 家愿付 ¥199/年 | 假门 Pro（多校区/报表/自定义抬头，点击后如实告知"功能规划中"）+ 直接报价访谈 | ⬜ 待验证 |
| H5 | 教具/演出服供应商愿意联营分销 | ≥3 家供应商试点贴牌、合计覆盖 ≥60 家机构 | 本地画材/舞蹈用品经销商扫街拜访（一个经销商辐射 100~1000 家机构），白标包 ¥1500/年 | ⬜ 待验证 |
| H6 | 教师工资表被用于真实结算 | ≥40% 活跃机构在月末导出/查看过教师课时汇总 | 埋点：board 页 payroll 曝光 + settings 导出 | ⬜ 待验证 |
| H7 | 学员规模呈长尾（小机构占多数但中大机构存在） | <50 学员占比 ≥60%；≥10% 用户 >100 学员 | 埋点：建档学员数分布（若中大机构超预期，提前把 Pro 多校区转正） | ⬜ 待验证 |
| H8 | 用户会主动备份/迁移数据 | JSON 导出使用率 ≥10% | 埋点：`export-json` 事件 | ⬜ 待验证 |

**已证伪风险预案**：若 H1 < 20%（消课动作不成立——课后记不住 R2 成真），转向"教师课时费对账单"单点工具（弱化点名叙事，强化月度劳资结算——同一个 core，换一个入口叙事）；若 H2 < 30%（对账单没人发），对账价值主张被证伪，产品无钩子，止损关停，把红线体检拆给合规内容号做引流素材另起炉灶。

## 2. OHELM 验证循环

每条假设按 **Objective → Hypothesis → Experiment → Learn → Measure** 循环推进，学习结果写回假设登记册，不做完循环不进入下一轮投入：

| 环节 | 本项目的落地形式 |
|---|---|
| **O** Objective | 90 天内证明"机构愿意把课时账从纸卡 Excel 升级为点名消课 + 发对账单"（H1+H2+H3） |
| **H** Hypothesis | 上表 H1-H8，一条一个预期数值 |
| **E** Experiment | ①20 家种子机构（8 舞蹈/4 美术/4 体育/2 音乐/2 单飞教师）微信群陪跑（本地优先工具的天然局限：埋点在端上，靠用户自愿导出 + 周回访）②假门付费 ③本地画材/舞蹈用品经销商扫街 10 家、谈 3 家贴牌试点 |
| **L** Learn | 每两周一次循环复盘：判据达标 → 升级投入；不达标 → 触发对应预案（H1/H2 预案） |
| **M** Measure | 北极星：**周活跃消课学员数（周内至少出现在 1 条消课记录中的学员数）**；护栏指标：对账单导出率（H2）、消课动作 14 天留存（H1）、教师工资表使用率（H6） |

**北极星指标说明**：不选下载量（vanity）、不选机构注册数（无门槛），选"每周至少被消一次课的学员数"——它同时代表机构留存、真实课消行为与学员在管规模，且与机构的经营健康度同向。

## 3. 第一桶金（确立）

三条腿并进，以 ② 教具/演出服供应商联营为杠杆主攻：

| 路径 | 定价 | 第一笔钱的现实性 | 90 天目标 |
|---|---|---|---|
| ① 机构 Pro | ¥199/年（多校区 + 经营报表 + 自定义对账单抬头）；单校区永久免费 | 假门点击 → 直接报价转化；锚点贴"一节体验课收入"的心理账户 | H4 判据：≥10 家付费或假门点击 ≥5% |
| ② **教具/演出服供应商联营（主攻）** | ¥1500/年/商（白标 ≤50 家机构，含商家看板：客户机构课消活跃度/续费信号） | 一个省级行业经销商服务 100~1000 家机构，客单价是机构的 8 倍且决策人单一（经销商老板）；对商家的账：客户机构活得越久买得越多 + 白标 = 每周品牌触达 ≫ ¥1500 | 扫街 10 家、签约 3 家 = **首笔现金 ¥4,500**，同时获得 60+ 精准机构分发面 |
| ③ 教师 KOL 社群分佣 | 按成交 20% 分佣给团长 | 依赖①②的转化率数据成熟后再开 | 不做承诺，进迭代池 |

**为什么 ② 是主攻**：机构主 CNY 付费弱（R1），但行业经销商 B2B 决策快、有明确 ROI（客户机构存活 = 采购基本盘）、且天然批量触达机构主——**供应链上游即渠道**（docs/12 §6.3）。第一桶金的本质不是规模，是"有人为价值付了第一笔真钱 + 一条可复制的收款路径"，3 家经销商试点同时验证产品价值（H5）、渠道结构（分发面）与收款能力。

## 6. 诚实条款（本项目的科学底线）

- **不碰在线收退费、不做监管报送**：课包手工录入（这是特性不是缺陷：无资金合规负担、无支付牌照问题、离线可用）。资金存管与一课一消报送以全国监管平台及属地要求为准，本工具只管机构自己的经营底账。
- **本地记录不具备司法级不可篡改性**：消课记录与对账单的证据价值在"完整、即时、双方签字"，可用于日常对账与纠纷调解的底稿，但本工具不宣称替代公证存证或监管平台数据。
- **退费试算是谈判台阶不是法律意见**：按"已消正课折算、赠课不折现"的行业通识口径计算，过期未消单列不推定——**培训合同与属地规则永远赢**，试算单页脚常驻声明。
- **60 课时红线与 5000 元提示线是政策口径的参数化**：红线依据教育部等六部门 2021 通知（3 个月或 60 课时），5000 元为部分地区家长提示口径；工具亮灯不阻止，红线执行以属地监管为准。
- **所有商业假设未验证**：付费、留存、渠道数字全部是待证伪的信念。我们不把"7 万件投诉"当作需求的必然性——纸卡也免费，记忆和 Excel 也是船。
