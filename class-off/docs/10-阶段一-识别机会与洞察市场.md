# 10 · 阶段一：识别机会与洞察市场

> 本阶段回答：世界的哪个痛点值得做？用第一性原理拆到底，用 JTBD / 船模型 / 非消费者分析还原真实场景，用 PESTEL 扫宏观，用机会缺口矩阵定位空白。

---

## 1. 第一性原理拆解

不问"市面上有什么教培 SaaS"，只保留不可再分的事实：

| # | 不可再分的事实 | 推论 |
|---|---|---|
| F1 | 预收费是教培的默认商业模式：先收钱、后上课。每卖掉一节课，机构就多背一节"尚未提供的服务"的**负债**——课时账本质是一本**负债账**，消课（核销）就是逐节还债 | 账上「还剩多少课要还」是机构的真实负债表；记不清课时 = 记不清自己欠多少，这是经营风险不是文书问题 |
| F2 | 2021 年起预收费被制度化管理：教育部等六部门《关于加强校外培训机构预收费监管工作的通知》（2021-10）明确**不得一次性收取或以充值、次卡等形式变相收取时间跨度超过 3 个月或 60 课时的费用**；全国校外教育培训监管与服务综合平台（家长端"校外培训家长端"App）按「一课一消、家长确认、银行拨付」运转，各地配套细则持续加码（收费时点、5000 元提示线等） | "收了钱不上课/说不清课"从商业问题升级为**监管问题**；60 课时红线让"卖大课包"这条老路被堵死，机构必须精细化经营课时 |
| F3 | 退费难是行业第一投诉顽疾：2024 年全国消协组织受理教育培训服务类投诉**超 7 万件**（中消协 2024 投诉分析口径），"已开课不退、有学习记录不退、违约金过高"贯穿各类纠纷——而每一单退费的计算基础都是**已消课时数** | 没有一本双方都认的消课账，退费就只能靠吵；账本是纠纷的减震器，也是机构的自证材料 |
| F4 | 小微非学科机构（舞蹈/美术/体育/音乐/编程/书法，1~2 个场地、几十到几百名学员、全职夫妻 + 兼职老师）的现状解法 = **纸卡划课 + Excel 表 + 记忆**：余额算不清要翻表、临期没人盯、过期即纠纷、家长问"还剩几节课"要等老板翻 Excel 回微信 | 现状解法的失败不在"没有工具"，在**工具的动作成本高于事情的价值**——所以永远"回头再记" |
| F5 | 家长信任决定续费率，而"主动对账"是唯一低成本的信任动作：机构从不发对账单，不是不想，是生成一张对账单的成本（Excel 拉一小时、还要挑好看格式）高于它的心理价值 | 把对账单的生成成本打到「点一下、复制、粘贴」级别，"主动对账"才会从美德变成习惯——信任与续费长在对账单上 |
| F6 | 兼职教师课时费按节计算，月底各人对课表：教师记自己的、机构记 Excel 的，两本账对不上就扯皮，旺季流动性大时更甚 | 消课记录天然是**劳资对账的底账**——同一条流水同时服务家长对账与教师结算，一份动作两份价值 |
| F7 | 机构跑路舆情让家长对预付费高度敏感，"卷款跑路"的新闻持续训练家长的警惕；合规经营的小微机构反而缺一个"我不跑路"的可信信号 | 定期主动对账 + 清晰的课时负债账 = 中小机构稀缺的**信任基建**，这是家长视角下的真实价值 |
| F8 | 学员姓名、课时、金额是敏感个人信息；机构主的经营终端就是手机微信；各地要求通过全国监管平台报送与资金存管，机构侧无力也无须自建"第二套监管系统" | 本地优先（数据不出设备）是安全与成本的双重最优解；工具**不做监管报送、不做在线收退费**，与监管平台是互补不是竞争 |

**第一性结论**：预收费机构的经营确定性 = 「课时负债账的清晰度 × 家长信任的交付频率 × 教师劳资对账的确定性」，三件事共用**同一本消课账**。谁把"记一节课、发一张对账单"的成本打到趋近于零，谁就把 60 课时红线时代的合规压力，变成小微机构的信任资产。

## 2. 痛点 - 爽点 - 痒点模型（梁宁）

| 层 | 用户心理 | 消课单对应 |
|---|---|---|
| **痛点**（恐惧/怕） | 怕家长上门要求退费时拿不出已消课时数；怕课包过期没提醒、家长闹"为什么不早说"；怕月底和兼职老师对不上课时费；怕哪天被检查说不清预收费台账 | 过期未消、临期、余额三类预警自动点名——纠纷在爆发前被看见；退费试算给双方一个都能看的数 |
| **爽点**（即时确定性） | 上完课 30 秒点名消课，谁还剩几节一眼可见；家长微信问余额，复制对账单 10 秒回复；月底教师工资表自动汇总 | 点名即落账 + 对账单三通道（微信文本/打印 HTML/直接打印）+ 教师月课时表 |
| **痒点**（虚拟自我） | "我的小机构也有大机构一样的规范台账"；"我对每个家长都明明白白" | 印着机构名称的对账单 + 双方签字栏 + 60 课时红线体检——夫妻店的"规范办学者"身份叙事 |

优先级：痛点 > 爽点 > 痒点。MVP 只做痛点与爽点，痒点靠对账单的品牌落款顺手满足，不做招生营销/家校圈/成长档案。

## 3. JTBD（待办任务）

**主任务陈述**：**当**上完一节课、家长问"还剩几节"、课包快到期、月底要给老师结课时费、家长提出退费时，**我要**立刻说得清课时账、拿得出对账凭据，**以便**续费续得顺、退费退得清、老师结得明、检查问得不慌。

三维拆解：

| 维度 | Job | 现状方案的失败点 |
|---|---|---|
| 功能性 | 消课落账（谁、哪科、哪天、扣哪包）；余额/临期/过期预警；家长对账单产出；退费金额试算；教师课时费汇总 | 纸卡不聚合、Excel 无预警、对账单成本高、退费全凭吵 |
| 情感性 | 家长来问时不心虚、不拖延；退费谈判不蒸腾成对抗 | "我回头查一下"本身就在消耗信任 |
| 社会性 | 向家长（明白消费）、向老师（公道结算）、向监管（规范办学）证明"我是认真的机构" | 没有任何体面的台账载体 |

**竞品不是别的 SaaS，而是「纸卡 + Excel + 微信口头 + 什么都不记」**——它们免费且是行业默认动作，这是我们真正的敌人（见阶段二波特五力：替代品威胁）。

## 4. 船模型

> 用户要的从来不是船，是安全过河。这里河对岸 = 课时账清、家长信、老师服、检查不慌。

| 元素 | 本场景 | 现状问题 |
|---|---|---|
| 乘客 | 1~2 个场地、几十到几百名学员的非学科小微机构主 / 单飞教师工作室 | — |
| 船 A：纸卡划课 + Excel + 记忆 | 现状默认解，零成本 | 余额靠翻表、临期靠运气、过期即纠纷、劳资对账靠吵；跑路舆情下信任赤字最大 |
| 船 B：教培 SaaS（校管家、小麦助教、校盈家等一众） | 消课、排课、招生、营销、收银全家桶 | 为"规模化机构的增长"设计：按年费收钱、重实施、要联网、数据在云；小微要的是"把课消和对账说明白"，不是一整套营销 CRM；迁移与学习成本高 |
| 船 C：全国监管平台 / 家长端 App | 一课一消、资金存管的官方通道 | 服务**监管与资金安全**，不是机构的经营账本：机构无法用它生成对家长的品牌对账单、算教师工资、做退费试算；报送义务之外的经营段是空白 |
| 船 D：微信群 + 口头 + 拍 Excel 截图 | 家长问余额的实际现状 | 截图没有结构、没有累计、没有签收；每一次查询都是一次人工服务 |
| 河 | **预收费与课消之间的负债黑箱**：欠家长多少节课、临期多少、过期多少、该付老师多少，没有一本双方都认的账 | 四条船共同的黑水区 |

**定位推论**：消课单**不造 SaaS 的船，也不造监管平台的船**，做挂在所有船上的"课时负债账 + 信任对账单"——课包从哪来（监管平台购买 / 线下合同 / 私域续费）不重要，重要的是"收了钱之后的每一节课"第一次有了双方共认的账。与 SaaS 互补（轻机构用不上 SaaS；重机构拿它当对账出口），与监管平台互补（它管资金存管与报送，消课单管机构自己的经营底账），与 Excel 正面对抗但迁移成本 ≈ 0（还是微信，只是从"拍截图"变成"发对账单"）。

## 5. 非消费者分析（Christensen）

| 非消费者类型 | 画像 | 为什么不用现有解 | 对产品的启示 |
|---|---|---|---|
| 纸卡小作坊 | <50 名学员，夫妻店，一张桌子两间教室 | "SaaS 是连锁用的"；Excel 也不会用公式 | 免费开始；50 学员内全功能；名词全部说人话（"消课"不叫"核销"） |
| 单飞教师 | 一个老师一个琴房/画室，学员 10~30 人 | 用不上排课招生；课时费和课时账是同一本 | 教师工资表 = 机构主视角的自己；一人机构全功能免费 |
| 乡镇县域机构 | 县城舞蹈室/武馆，网络不稳，家长只用微信 | 云 SaaS 断网即瘫；家长不装额外 App | PWA 离线可用；对账单走微信文本，家长零安装 |
| 反 SaaS 老板 | 被年费 SaaS 坑过（买了没人用/数据被锁） | "再交一次年费不如再买一沓卡" | 数据 100% 本地 + JSON 导出/导入；不收年费也能一直用 |

非消费者共同阻碍排序：**觉得"台账是连锁的事"（规模错觉）> 怕录课麻烦（动作成本）> 怕家长觉得对账单是催费（叙事风险）**。MVP 依次对应：单人单店免费全功能、点名 30 秒落账、对账单文案以"明白消费"而非"催费"为基调（续费提醒只出现在机构侧看板）。

## 6. PESTEL 宏观扫描

| 维度 | 要点 | 对本机会 |
|---|---|---|
| **P** 政治 | 双减（2021-07）后学科类压减、非学科类成为存续主体并分口径监管；预收费监管（3 个月/60 课时红线、专户存管、一课一消）全国推开；《校外培训行政处罚暂行办法》2023-10 施行把违规收费的罚则成文化 | 合规要求从"行业自觉"变"显性规则"，顺风；机构需要一套"合规自查"的日常工具，60 课时红线体检是顺手的价值 |
| **E** 经济 | 教培是现金流生意，小微机构对费用极度敏感；但退费纠纷、劳资扯皮、家长流失每一项都是真金白银；招生获客成本上行让"续费"的价值相对上升 | 免费增值是唯一可行定价；付费逻辑是"保住续费与少吵架"，比"营销增长"更贴近小微的账 |
| **S** 社会 | 跑路舆情持续训练家长警惕，"预付费焦虑"成为社会情绪；90 后家长对透明消费的要求高；出生率下行让存量学员的续费率比新招更重要 | 主动对账 = 信任基建，家长侧价值成立；续费率经营是小微的主战场 |
| **T** 技术 | 微信是家校沟通的绝对通道；PWA/打印是系统级能力；监管平台（家长端）承担资金与报送，机构侧经营工具留白 | 本地优先 + 微信文本双通道恰好补位；不碰报送、不碰支付就没有与平台的竞争 |
| **E** 环境 | 双减后机构数量出清、向素质类集中，单机构学员密度上升，课时账复杂度上升 | 出清后的存续机构恰恰是"认真经营的"那批，台账需求真实 |
| **L** 法律 | 退费纠纷司法实践中，已消课时的举证依赖机构的记录（培训合同 + 消课记录是常见证据组）；《民法典》合同编对服务合同解除与结算有通用规则 | 消课记录同时是机构的**举证资产**——记录的完整、即时、规范直接服务诉讼与调解 |

结论：宏观无逆风。P（预收费制度化）与 S（家长信任焦虑）双顺风；E（费用敏感）约束定价但不约束机会成立；T（监管平台存在）被"互补定位"结构性化解——做平台不做的事，不做平台做的事。

## 7. 机会缺口矩阵

以"用户重要性 × 市场现有解完整度"定位空白：

```
重要性 高 │ ①招生营销/排课管理         ③【空白】预收费课时账 + 家长对账
          │ （教培 SaaS 红海）          （消课落账/预警/对账单/退费试算，
          │                             无小微级轻产品）
重要性 低 │ ②在线直播/教务硬件          ④机构财务记账
          │ （重资产/重实施）            （通用记账 App 已泛滥）
          └─────────────────────────────
             现有解完整度 高            低
```

- ③的四段拆解交叉验证：纸卡 Excel（无预警无对账单）、教培 SaaS（重、贵、为增长设计）、监管平台（管资金不管经营）、微信截图（无结构无累计）——**每一段都有人做，合起来无人做**。
- ①是 SaaS 的主场，年费数千起且要实施；③覆盖的是沉默的大多数（几十到几百学员的夫妻店与单飞教师）。
- ②与④偏离主线，无冲突也不碰。
- 政策与产业事实给 ③ 背书：60 课时红线让"卖大包"的粗放模式终结（教育部等六部门 2021）、培训投诉 7 万件/年且退费难居首（中消协 2024）、一课一消让"消课"成为机构每天都要完成的动作——**规则已生效、痛点有量级、轻产品空白仍在**。

**阶段一结论**：消课单占位 ③——一条被预收费监管、7 万件/年投诉与家长信任焦虑共同供养、被"纸卡 + Excel + 微信截图"证明协作真实存在、却被所有重 SaaS 忽略的缺口。
