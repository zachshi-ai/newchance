## 1. 痛点（真实世界，有据可查）

预收费是教培的默认商业模式，而预收费的本质是负债：每卖掉一节课，机构就多背一节"尚未提供的服务"的欠条。双减之后（[教育部等六部门 2021 通知](14-调研来源.md#法规与政策红线口径的直接依据)），这本负债账被制度化管理：

- **60 课时红线**：不得一次性收取或以充值、次卡、加赠等形式变相收取超过 3 个月或 60 课时的费用——"卖大课包"的粗放模式被终结，机构必须逐节经营课时。
- **一课一消**：全国监管平台按"家长确认消课 → 银行按课次拨付"运转——"消课"从内部动作变成每天都要完成的合规动作。
- **退费难是第一投诉顽疾**：2024 年教育培训类投诉超 7 万件（[中消协 2024 投诉分析口径](14-调研来源.md#投诉与纠纷数据痛点量级)），每一单退费的计算基础都是已消课时数——没有账就只能吵。
- **现状解法 = 纸卡划课 + Excel + 记忆**：余额算不清要翻表、临期没人盯、过期即纠纷、家长问"还剩几节课"要等老板翻 Excel 回微信、月底和兼职老师对课时费两本账对不上。
- 第一性差距：**"预收费与课消之间的负债黑箱"没有任何小微级工具承接**——消课单把消课变点名、把对账变微信、把退费变试算。

## 2. 方案（机会 → 产品）

**消课单**：零依赖、本地优先的 PWA。

1. **学员/课程/教师建档 + 购课建包**：正课包（实付、可折算）与赠课包（不折现）分立；建包即做 60 课时红线与变相打包体检。
2. **一课一消落账**（核心计算）：上完课勾学员 → 消课落账；消耗顺序确定性——正课先于赠课、临期先消、先买先消、跨包自动接续；余额不足**整体拒绝不部分入账**；重复点名拒绝；点错一键撤销精确回滚。
3. **三类预警**：余额 ≤ 预警线（续费触点）、课包临期 30 天窗（消课或办延期）、过期未消（退费纠纷疫苗）。
4. **家长对账单三通道**（核心"信任交付"动作）：纯文本复制微信发家长（主通道）、打印版单文件 HTML（双方签字栏）、直接打印。
5. **退费试算单**：逐包折算（单节价 = 实付 ÷ 总课时）、赠课不折现、过期未消单列——给双方一个都能看的数，合同为准。
6. **教师月课时工资表 + 数据自持**：按月自动汇总劳资对账底账；100% 本地存储，JSON 导出/导入。

## 3. 诚实的现状声明（真实可落地，不空中楼阁）

- **已验证**（本仓库内可复现）：核心逻辑 35/35 单元测试通过（含账实一致守恒、整体拒绝不部分入账、撤销回滚、消耗顺序边界、红线体检、导出确定性、XSS 转义、导入导出往返）；浏览器端到端全流程（示例数据 → 看板四类预警 → 点名消课 → 撤销回滚 → 对账单导出 → 退费试算）真实运行通过；打印版 HTML 为单文件、离线可用；零 npm/CDN/API 依赖；SW 缓存版本化且更新可靠。
- **未验证**（需真实用户，见 docs/13 假设登记册）：消课动作留存（H1）、对账单真实发送（H2）、退费试算使用（H3）、付费意愿（H4）、教具商渠道（H5）——全部标注"待验证"并配有可证伪判据。
- **边界与免责**：不碰在线收退费、不做监管报送、不做排课招生；本地记录不宣称司法级存证；退费试算是谈判台阶不是法律意见，合同与属地规则永远赢；60 课时红线为政策口径参数化，工具亮灯不阻止。

## 5. 与既有项目的领域隔离（用户约束）

本方向为**非学科教育培训 · 预收费课时账与家长对账（B2B 小微机构 · 教培经营台账）**，已对照仓库根 README 领域登记表与 `newidea` 仓库 62+ 点子做领域排除：不与 `pet-handoff`（C 端宠物照护）、`food-sentry`（B2B 餐饮合规/监管科技）、`turn-sheet`（民宿短租周转与布草供应链）、`work-proof`（小微雇主劳动用工合规）重叠，也不与 `newidea`（个人/家庭账本经济学 + 开发者工具，无任何机构经营方向）重叠。付费主体（培训机构与教具/演出服经销商）、使用场景（课后点名消课与家长对账）、行业语境（预收费监管、培训服务合同、劳资课时结算）均不同域。
