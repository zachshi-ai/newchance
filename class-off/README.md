# 消课单 ClassOff 📒

> **小微教培机构的预收费课时账本：上完课点名即消课，微信发家长即对账；余额临期先知道，退费试算有台阶，教师课时费月底不扯皮。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 家长不用装 App

预收费的每一块钱都是"还没上的课"。双减之后，这本负债账被制度化管理：一次性收费不得超过 3 个月或 60 课时（教育部等六部门 2021 通知）、一课一消、家长确认后资金拨付。而小微机构的现状是纸卡划课 + Excel + 记忆——余额算不清、临期没人盯、过期即纠纷、退费全凭吵、月底和兼职老师对课时费两本账对不上。消课单把这段黑箱变成白箱：购课建包（超红线当场亮灯）→ 课后点名 30 秒消课（正课先消、临期先消、点错可回滚）→ 对账单一键微信发家长 → 退费试算给双方台阶 → 教师工资表自动汇总。

## 3 条命令跑起来

```bash
cd class-off
npm start           # 等价于 python3 -m http.server 8084 --directory app
open http://localhost:8084
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程。

## 功能

| 模块 | 说明 |
|---|---|
| 🎒 **购课建包 + 红线体检** | 正课包（实付可折算）/ 赠课包（不折现）分立；单包超 60 课时、在途+新包变相打包、超 5000 元提示线当场亮灯（教育部等六部门 2021 通知口径，工具提示不阻止） |
| ✅ **一课一消落账** | 勾学员 → 落账两步：正课先于赠课、临期先消、先买先消、跨包自动接续；到期日当天可用次日作废；同科目同日重复点名拒绝；**余额不足整体拒绝，绝不部分入账**；撤销精确回滚，账实始终一致 |
| 🔔 **三类预警** | 余额 ≤ 预警线（续费触点）/ 课包临期 30 天窗（消课或办延期）/ 过期未消（退费纠纷疫苗，主动谈别等投诉） |
| 🧾 **家长对账单三通道** | 任意学员一键生成：**纯文本复制**（微信粘贴给家长，主通道）/ 打印版**单文件 HTML**（内联样式、含双方签字栏）/ 直接打印。家长不用装任何东西 |
| 💸 **退费试算单** | 逐包折算（单节价 = 实付 ÷ 总课时，整数分运算）、赠课不折现、过期未消单列按合同处理——给双方一个都能看的数，试算单页脚常驻"以培训合同为准" |
| 🧑‍🏫 **教师月课时工资表** | 按月自动汇总：每节课 × 课时费，跨月/跨年隔离——消课流水同时是劳资对账底账 |
| ⚙️ **数据自持** | 100% 本地存储；JSON 导出/导入（换机迁移，含结构校验）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
县城机构网络差，PWA 离线可用；发对账单走微信文本，不依赖任何在线服务；学员姓名、课时、金额不出设备。**不碰在线收退费、不做监管报送**——资金存管与一课一消报送是监管平台的事，这里是机构自己的经营底账。

## 边界与免责

- **不做在线收退费、不做支付、不做监管平台报送、不做排课招生**——课包与消课手工录入（这是特性不是缺陷：无资金合规负担、离线可用）。资金存管与一课一消报送以全国监管平台及属地要求为准。
- 60 课时红线依据教育部等六部门 2021 通知整理，5000 元为部分地区家长提示口径；**属地监管要求永远赢**，工具亮灯提示不替代法定义务。
- 退费试算采用行业通识口径（已消正课折算、赠课不折现、过期按合同处理），试算单是谈判台阶不是法律意见；**培训合同永远赢**。
- 消课记录与对账单的证据效力以双方签字确认与法律规定为准，工具不宣称司法级存证。
