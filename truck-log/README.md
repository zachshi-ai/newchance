# 车轮账 TruckLog 🚚

> **小微货运部与个体货车的一车一档合规台账：四只证照钟红黄绿倒计时，车龄过线周期自动减半，技术档案随手记，动态监控报警一键闭环，迎检一页纸拿出即用。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 数据不出设备

一辆黄牌营运货车身上同时跑着四只法定时钟：道路运输证**每年审验一次**（《道路货物运输及站场管理规定》第 50 条，2026 年版）、机动车检验检测**注册不满 120 个月每 12 个月一次、满 120 个月后每 6 个月一次**（《道路运输车辆技术管理规定》第 21 条，2023 年版）、交强险每年（脱保上路扣车+保费二倍罚款，《道路交通安全法》第 98 条）、从业资格证 6 年（超 180 日未换证失效）。外加两本法定台账：**一车一档**的技术档案（维护修理/换件/里程/事故）和**报警必须记录存档**的动态监控台账（违法信息与处理情况保存 3 年，处理率低于 90% 属罚则情形）。小微货运部的现状是脑子记日期 + 遮光板夹证件 + 空白档案本 + 报警弹了就划掉——车轮账把这段黑箱变成白箱：建档上钟（周期自动判档）→ 红黄绿倒计时 → 档案 30 秒一笔 → 报警三字段闭环 → 月度小结与迎检材料一键出。

## 3 条命令跑起来

```bash
cd truck-log
npm start           # 等价于 python3 -m http.server 8095 --directory app
open http://localhost:8095
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程。

## 功能

| 模块 | 说明 |
|---|---|
| 🚚 **车辆建档 + 证照钟** | 一车一档建档（车牌/车型/注册登记日/运输证号）；四只证照钟（运输证年审/检验检测/交强险/商业险）红黄绿倒计时；**检验检测周期按注册日期自动判档**（12 个月 ↔ 6 个月，部令第 21 条口径）；续期填新日期一键办结 |
| 🧾 **技术档案随手记** | 维护/维修/换件/检验/事故五型流水 + 里程 + 费用（整数分运算）；自动汇总每车年度养车支出；**一车一档打印版**单文件 HTML（部令第 15 条档案形态，卖车/审验随车带走） |
| 📡 **动态监控台账** | 报警登记（疲劳驾驶/超速/终端离线/其他）→ 三字段处理闭环（闭环日期不得早于报警日、重复闭环拒绝）→ 未处理报警按挂账时长点名、超催办线高亮 → **月度小结**自动汇总处理率与未处理名单（自带法条口径的文本底稿） |
| 🧑‍✈️ **驾驶员台账** | 从业资格证 6 年钟（超 180 日失效提前点名）+ 诚信考核 12 个月周年提醒 |
| 📑 **迎检一页纸** | 单文件 HTML 打印版：证照钟全景 + 一车一档速览 + 动态监控台账 + 驾驶员台账 + 双签字栏——路检/审验拿出即用 |
| ⚙️ **数据自持** | 100% 本地存储；JSON 导出/导入（换机迁移，含结构校验）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
县乡停车场网络差，PWA 离线可用；月度小结走微信文本，不依赖任何在线服务；车牌、驾驶员、费用数据不出设备。**不做货源撮合、不做油路集采、不装北斗硬件、不碰公共平台对接**——监管归集是平台的事，这里是车队自己的合规总账。

## 边界与免责

- **不做货源撮合、不做油路/ETC 集采、不做北斗硬件与平台对接、不代缴任何证照与保险**——车辆与证照手工录入（这是特性不是缺陷：无资金合规负担、离线可用）。运输证审验、检验检测、保险投保以法定渠道为准。
- 法定周期（年审每年一次、检验检测 12/6 个月、从业资格证 6 年、诚信考核 12 个月）为现行部令口径的参数化呈现；**属地规则、车籍地执行口径与证件本身永远赢**，工具亮灯提示不替代法定义务，周期规则随部令修订更新。
- **总质量 4.5 吨及以下蓝牌普货车不适用**《道路运输车辆技术管理规定》（第 33 条）且普货双证已取消——本产品按黄牌营运车设计。
- 技术档案与报警处理记录的证据效力以法定台账表式与法律规定为准，工具不宣称司法级存证；属地有制式台账要求时以制式为准、本工具为底稿。
