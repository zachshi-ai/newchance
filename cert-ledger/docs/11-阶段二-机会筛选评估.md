# docs/11 · 阶段二：机会筛选评估

## 1. 候选生成与淘汰记录（RICE 前的证伪）

本轮候选筛选先淘汰了三条路（记录在案防止回头再想）：

| 被淘汰候选 | 淘汰理由 |
|---|---|
| 能力验证代办/拼团平台 | 触碰承担机构资质与监管程序，平台责任重；频次一年 1~2 次，粘性差 |
| 标准物质/耗材电商比价 | 重供应链、重资金，非小微级工具定位；与既有仓库项目供应链撞型 |
| 评审咨询/代办服务 | 非工具、不可规模化、与「不替代法定程序」的产品边界冲突 |
| 检验检测**人员**求职/证书平台 | 用户是个人而非机构，与「机构侧自证台账」主线分散 |

选定 **检验检测机构合规台账（认证认可线）**：领域与仓库既有 28 项全部互斥（对象是「检测机构」这一行业，而非其上游的餐饮/药品/特种设备/计量器具），法规三件套四年内全部换新（163 号令 2021 修改、39 号令 2021、2023 评审准则、2023 能力验证办法），义务密度高而工具空白。

## 3. TAM-SAM-SOM（宽区间，权威口径待复核）

- **TAM**：全国检验检测机构 **53,057 家**（2024 年底，国新办发布会口径），行业营收 4,875.97 亿元。
- **SAM**：小微机构（1~50 人、非规上）。规上机构近 8,000 家 → 非规上约 **4.5 万家**；按环境监测/食品/建材/轻工等通用领域占比宽估 **3 万~4 万家**（逐档官方统计缺失，标注待复核）。
- **SOM（90 天）**：渠道白标 2~4 家经销商×其下游机构 + 直客，**30~80 家付费**，客单 ¥299~699/年 → 90 天收入 ¥3,000~10,000（与仓库同类项目第一桶金口径一致）。

## 4. 波特五力（诚实评估：低壁垒赛道，防线在内容纪律）

| 力 | 评估 |
|---|---|
| 现有竞争 | LIMS 厂商向上打小机构意愿低（客单不匹配）；免费日历/Excel 是真替代——**靠「闸机+证据链」的确定性结构拉开** |
| 新进入者 | 壁垒低（诚实承认）；防线=法条级内容维护纪律（条号位移/准则换挡雷区）+ 首发渠道先手 |
| 供应商 | 评审员/协会/经销商渠道有议价力但非独家；零依赖技术栈无技术供应商锁定 |
| 买方 | 小微机构付费意愿弱（最大风险，H4/H5 证伪线管）；罚则金额（3 万/撤销）是付费叙事支点 |
| 替代品 | 纸质台账+Excel 永远免费——对策=把「做不了」的功能做进去（闸机、联动停报、证据链核对单） |

## 5. 机会-可行性四象限

|  | 可行性高 | 可行性低 |
|---|---|---|
| **机会大** | **本项目：三组时钟+三道闸（法规确定性结构+零依赖可交付）** | 监管报送接口（政策门槛不可控） |
| 机会小 | 证照到期日历（可做但替代品多、客单趋零） | 检测流程 LIMS（大厂腹地） |
