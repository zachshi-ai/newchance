## 第 1 号项目：宠托付 PetHandoff

**痛点**：每逢节假日，养宠家庭要把毛孩子托付给寄养机构、上门宠托师或亲友——但照护信息的传递还停留在微信语音和口头叮嘱。走失、喂错药、应激、断粮时有发生，纠纷对簿公堂（真实案例：送医 8200 元）；专家建议的第一道防线恰是"详细交接喂养信息与用药剂量"，却没有任何产品把它做对。

**方案**：零依赖本地优先 PWA——宠物档案 + 一键生成结构化托养交接单（HTML 文件 / 纯文本 / 打印三通道送达）+ 免疫驱虫到期预警 + 照护日志回传。

## 第 2 号项目：食安哨 FoodSentry

**痛点**：市场监管 60 号令（2022-11 施行）强制餐饮主体执行"日管控、周排查、月调度"并留痕，未建立先警告、拒不改正可罚 5 千~3 万元；而 900 万+ 家餐饮小店的现状解法是纸质台账本 + 记忆补填、检查前突击。监管要的不是"你做了"，是"你能证明你持续做了"——证明成本是整个痛点的第一性变量。

## 第 3 号项目：翻房单 TurnSheet

**痛点**：中国民宿相关企业十年增长超 20 倍、现存约 38 万~40 万家（企查查口径），38 万商家抢流量，好评 = 流量 = 生存——而卫生住在「退房 → 入住」那两三个小时的执行里。小微房东（1~10 间房）的现状解法是微信喊保洁 + 口头交代 + 无台账：接重叠订单、保洁不知道截止时间、遗留物品没人记录；布草几套在房几套在洗涤厂全凭记忆，缺套总在到客日发现。海外 Turno 已验证"翻房调度"是独立付费品类，国内 PMS 只画房态色块——**两次入住之间的执行黑箱没有任何工具承接**。

**方案**：零依赖本地优先 PWA——翻房窗口自动派生（红黄绿 + 订单重叠点名）+ 六步翻房打卡留档（遗留物品单独记录）+ 任务单三通道（微信文本 / 打印版单文件 HTML / 直接打印，保洁零安装）+ 布草四态周转账（在房→脏→在途→净，总量守恒）+ 洗涤厂 SLA 超时催厂 + 到客缺口预警 + 90 天报废重购预算。第一桶金主攻「洗涤厂联营」：上游供应商即分销商，¥1200/年/厂 白标分发其下游 10~200 家送洗民宿。

## 第 4 号项目：工据 WorkProof

**痛点**：中国 1.25 亿户个体工商户支撑近 3 亿人就业，劳动争议案件量常年高位（2022 公报 316.2 万件且连年上升）——被告端绝大多数是没有 HR 的小微主体。雇人即触发刚性法律义务（一个月内签合同、试用期三档上限、社保强制、离职出具证明），违约价格随工龄自动增长（二倍工资上限 11 个月工资、违法解除 2N），且举证责任倒置、劳动者维权零成本；而小微雇主的现状解法——不签合同"先干着"、现金发薪、签"自愿弃保承诺"——本身全是违法或无效操作。2025-09-01 司法解释（二）施行后弃保协议一律无效，规则统一时点即存量违法暴露期。

## 第 5 号项目：消课单 ClassOff

**痛点**：预收费是教培的默认商业模式，而预收费的本质是负债——每卖掉一节课，机构就多背一节"尚未提供的服务"的欠条。双减后这本负债账被制度化管理：一次性收费不得超过 3 个月或 60 课时（教育部等六部门 2021 通知）、一课一消、家长确认后银行拨付；而 2024 年教育培训类投诉超 7 万件、退费难居首（中消协口径）。小微非学科机构的现状解法是纸卡划课 + Excel + 记忆：余额算不清要翻表、临期没人盯、过期即纠纷、家长问"还剩几节课"要等老板翻表回微信、月底和兼职老师对课时费两本账对不上——**预收费与课消之间的负债黑箱没有任何小微级工具承接**。

**方案**：零依赖本地优先 PWA——购课建包 + 60 课时红线当场体检（单包超线/在途变相打包/5000 元提示线）+ 一课一消点名落账（正课先消/临期先消/FIFO/跨包接续；余额不足整体拒绝、重复点名拒绝、撤销精确回滚）+ 余额/临期/过期三类预警 + 家长对账单三通道（微信文本 / 打印版单文件 HTML / 直接打印，家长零安装）+ 退费试算单（逐包折算、赠课不折现、过期单列，合同为准）+ 教师月课时工资表（劳资对账底账）。第一桶金主攻「教具/演出服供应商联营」：上游供应商即分销商，¥1500/年/商 白标分发其下游 100~1000 家机构客户。

## 第 12 号项目：泳清单 PoolClear

**痛点**：游泳场所的水质自检与公示是每天真实发生的法定动作——《游泳场所卫生规范》（卫监督发〔2007〕205 号）要求每场开放前、开放时检测池水余氯、pH、温度并记录备查，**检测结果应公示并注明测定时间**；GB 37488-2019 把泳池水收紧到 pH 7.0~7.8、浑浊度 ≤1 NTU、游离性余氯 0.3~1.0 mg/L（浸脚池余氯 5~10 mg/L、每 4 小时更换）；《公共场所卫生管理条例实施细则》要求卫生管理档案至少保存两年，未按规定检测的责令改正、可处 2000~20000 元罚款，情节严重的停业整顿直至吊证——而抽检不合格公示一挂，家长用脚投票，损失远大于罚金。小微泳馆（1~5 池的泳培馆/健身附属/酒店/学校泳池）的现状解法是纸台账 + 记忆 + 检查前突击：测了不留、留了不晒、晒了不闭环——**"每天真实发生的水质管理"与"检查者/家长能看见的水质证明"之间没有任何小微级工具**。
