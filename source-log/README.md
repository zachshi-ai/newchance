# 来路单 SourceLog

> 废品站（再生资源回收站点）的收购实名台账与赃物风险自证台 —— 机会实验室 13 号项目
>
> **来路可查，收得安稳。**

## 痛点

废品站老板最大的风险不是收不上货，是**说不清收的货哪来的**——收了一车电缆，三天后警察上门。收购生产性废旧金属要查验出售单位证明并登记出售人证件号与物品明细（《废旧金属收购业治安管理办法》第八条），登记资料保存不少于两年；而明知赃物而收购是掩饰、隐瞒犯罪所得罪（刑法第三百一十二条，最高七年），「明显低于市场价收购」「从同一人手中多次收购」都是推定"明知"的司法口径。检察官的公开建议就是三个动作：**查来源、做记录、来路不明拒收**——但 1~2 人夫妻站的现状是烟盒记账 + 脑子 + 谁卖都收，收货那一刻"问了谁、查了什么、为什么这个价"没有任何留痕。

## 方案

零依赖、本地优先的 PWA（`app/` 目录，文档根即部署根）：

- **出售人实名底档**——建档一次点选复用，身份证号只存本机不上云
- **收购落账守门**——生产性/公用金属无证明当场拦截（改走拒收登记）、需实名品类缺证件号拒绝、**明显低价强制写原因**
- **拒收登记**——30 秒留痕（含"不明人员"）：拒收不是损失，是最硬的自证
- **销赃特征点名**——同一人 30 日内高危品类 ≥3 次自动亮红灯
- **三件套出证**——登记册（按月，含拒收与查验痕迹，两年保存口径）/ 来源自证单（出售人签字栏）/ 出货对账单（发打包站）
- **进出两本账**——出货去向留痕 + 月度经营账现算；JSON 导出/导入

## 诚实条款

技术可行性已在仓库内验证（23/23 测试 + 浏览器端到端）；不判定物品是否赃物、不替代属地备案与特种行业管理要求（属地规则永远赢）；登记册是站点自证底账、不承诺执法采信，涉案认定以公安机关为准；品类风险分级与参考价是通识口径的参数化（当日实时行情永远赢）；身份证号只存本机、最小采集；商业假设（落账留存/出证使用/拒收渗透/付费/打包站渠道）全部标注"待验证"并配有可证伪判据。
