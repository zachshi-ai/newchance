# 10 · 阶段一：识别机会与洞察市场

> 本阶段回答：世界的哪个痛点值得做？用第一性原理拆到底，用 JTBD / 船模型 / 非消费者分析还原真实场景，用 PESTEL 扫宏观，用机会缺口矩阵定位空白。

---

## 1. 第一性原理拆解

不问"市面上有什么废品站软件"，只保留不可再分的事实：

| # | 不可再分的事实 | 推论 |
|---|---|---|
| F1 | 登记是法定义务不是经营偏好：《废旧金属收购业治安管理办法》第八条要求收购**生产性废旧金属**时查验出售单位证明，并登记出售单位名称、经办人姓名、住址、**身份证号码**与物品名称、数量、规格、新旧程度（本仓库已对照国家行政法规库原文核验）；《再生资源回收管理办法》口径：登记资料**保存不少于两年** | 站点的生存问题不是"收不收得到货"，是"**能否证明收的货来路查验过**"。证明成本（把口头问一句变成拿得出手的登记记录）是整个痛点的第一性变量 |
| F2 | 刑事风险是真实概率不是吓唬：《刑法》第三百一十二条掩饰、隐瞒犯罪所得罪，明知赃物而收购处三年以下、情节严重三至七年（最高法典型案例：收购 165 万余元即达"情节严重"）；废品站老板低价收电缆获刑的判例年年出现——2024 法治网案例（16.5 元/公斤收电缆）、2025 湖北日报案例，公开报道持续刷新 | 风险与利润严重错配：一车电缆赚几十上百元，一次"收赃"判刑毁掉一个家庭生计。**收购那一刻"问了谁、查了什么、为什么这个价"的记录质量，决定站主是自证尽责还是推定明知** |
| F3 | 司法口径把"明知"的推定标准说得很白：「以明显低于市场价格收购」「从同一人手中多次收购」「交易时间场所异常」（凌晨收电缆）都是推定"明知"的依据（江苏检察网、中国警察网口径） | 推定情形全是**可以用台账对冲的**：价格原因写下来、出售人身份记下来、交易如实留痕——"我查验过"第一次有了可以拿出来的形态 |
| F4 | 检察官的公开建议恰好是三个动作：「了解物品来源**并做好记录**，来路不明应**拒绝收购**，发现犯罪所得及时报警」（湖北日报 2025 案例报道） | 产品处方不用发明：**查来源、做记录、拒收留痕**——来路单只是把司法系统已经给出的建议，做成顺手的工具 |
| F5 | 市场量级真实：2024 年再生资源回收总量 4.01 亿吨、回收价值 1.33 万亿元（中国物资再生协会）；站点端是海量个体（夫妻站、社区点、游商），行业宽口径数十万级（精确统计检索未获，诚实标注） | 沉默的大多数是 1~2 人站点：没有 ERP、没有财务软件，一部手机 + 一个本子就是全部数字资产 |
| F6 | 现状解法 = **烟盒记账 + 脑子 + 谁卖都收**：身份不查、证明不看、价格随口、纸单塞抽屉；检查前突击补一本——笔迹同一、间隔整齐，一翻就假 | 现状解法的失败不在"不懂法"，在**登记的动作成本高于登记的价值感知**——直到手铐把价值标价成七年。动作成本必须打到"顺手"级，价值叙事必须贴着"自证" |
| F7 | 身份证号是站点最敏感的数据：站主不敢把出售人信息交给任何云端——"万一泄漏了，出卖我的就是我自己" | 本地优先不是技术偏好，是**信任前提**：数据不出设备是产品承诺本身，也是与一切 SaaS 的分界线 |
| F8 | 下游打包站是站点的稳定出口：货卖给谁白纸黑字，既是链条自证（去向），也是每月对账凭据（收款） | 台账同时是**治安底账**与**经营账本**：进（谁卖给我）+ 出（我卖给谁）两头闭环，一本账两用 |

**第一性结论**：废品站的生存确定性 = 「出售人实名的登记率 × 查验动作的留痕度 × 异常情形的免疫度」，三件事共用**同一本收购台账**。谁把"问一句、记一笔、拒一单"的成本打到趋近于零，谁就把掩饰隐瞒罪的刑事尾部风险，变成站主用得起的自证资产。

## 2. 痛点 - 爽点 - 痒点模型（梁宁）

| 层 | 用户心理 | 来路单对应 |
|---|---|---|
| **痛点**（恐惧/怕） | 怕收进一车赃物戴手铐；怕警察拿着监控截图上门倒查时，翻不出"我问了来路"的任何痕迹；怕检查台账拿不出登记册被罚；怕同一人反复卖铜自己却毫无警觉 | 无证明品类当场拦截（该拒收的收不进来）；明显低价强制写原因（"白菜价"有了解释）；销赃特征自动点名（"同一人多次"看得见）；登记册两年口径随导随出 |
| **爽点**（即时确定性） | 出售人建档一次，收购点选 30 秒落账；拒收登记 30 秒留痕；被倒查时翻出自证单，出售人签字栏白纸黑字；月底对账单直接发打包站 | 实名底档 + 落账守门 + 三件套出证（登记册/自证单/对账单） |
| **痒点**（虚拟自我） | "我的站比同城同行都规范"；"公安来了我不慌，台账拿出来随便翻" | 印着站点名称与备案号的登记册——小微站主的"正规军"身份叙事 |

优先级：痛点 > 爽点 > 痒点。MVP 只做痛点与爽点，痒点靠登记册落款顺手满足；不做行情报价、不做拍卖、不做支付（见阶段三 ERRC）。

## 3. JTBD（待办任务）

**主任务陈述**：**当**有人骑着三轮车拉来一车电缆、电瓶、井盖，当警察带着监控截图上门倒查，当公安/商务来检查台账，当月底要跟打包站对账结算时，**我要**说得出"谁在什么时候卖给我什么、我查验了什么、为什么是这个价、卖给了谁"，**以便**收得安稳（不踩刑事线）、查得从容（登记册随出）、赚得明白（进出两本账）。

| 维度 | Job | 现状方案的失败点 |
|---|---|---|
| 功能性 | 出售人实名建档；收购逐笔落账；无证明拦截；拒收登记；出货去向记录；登记册/自证单/对账单产出 | 记忆不聚合、纸单无拦截、拒收没有记录形态、去向全凭脑子 |
| 情感性 | 有人拉来可疑货时不心虚（"我按规矩拒了"）；警察上门不慌（"你看台账"）；月结对账不扯皮 | "谁卖都收"本身就在积累风险；一旦倒查，烟盒上的字救不了任何人 |
| 社会性 | 向公安（规范经营）、向打包站（稳定供货商）、向同行（正规军口碑）证明"我的站来路清白" | 没有任何体面的自证载体 |

**竞品不是别的软件，而是「烟盒记账 + 脑子 + 什么都不记」**——它们免费且是行业默认动作，这是我们真正的敌人（见阶段二波特五力：替代品威胁）。

## 4. 船模型

> 用户要的从来不是船，是安全过河。这里河对岸 = 收得安稳、查得从容、赚得明白。

| 元素 | 本场景 | 现状问题 |
|---|---|---|
| 乘客 | 1~2 人的个体废品站 / 社区回收点（夫妻店占绝对多数） | — |
| 船 A：烟盒记账 + 脑子 | 现状默认解，零成本 | 身份不查、价格随口、纸单塞抽屉——倒查时一片空白 |
| 船 B：通用进销存/收银 SaaS | 小商店的全家桶 | 为"零售门店"设计：要 SKU、要联网、要会员——没有出售人实名、没有证明查验、没有风险点名，且云端存储与"身份证号不出设备"根本冲突 |
| 船 C：政务备案/报送平台 | 商务备案、部分城市的回收管理小程序 | 管的是"你备案了没有""报了数据没有"，不管你经营中的查验留痕——报送是平台的事，底账是站点的事（互补不竞争） |
| 船 D：协会纸质台账本 | 治安联防/协会发的登记本 | 事后突击补填、无守门无点名、保存两年全靠柜子不进水 |
| 河 | **收进来的货与来路说得清的货之间的证明黑箱**：查没查说不清，为什么这个价讲不明 | 四条船共同的黑水区 |

**定位推论**：来路单**不造 SaaS 的船，也不造报送平台的船**，做挂在所有船上的"收购治安底账"——货源从哪来（游商/居民/工程退料）不重要，重要的是"收货那一刻我查验了什么"第一次有了可出示的书面形态。与报送平台互补（它管备案报送，来路单管经营留痕），与进销存正面对抗但迁移成本 ≈ 0（还是手机，只是从"记个总数"变成"查证件、记来路、留痕迹"）。

## 5. 非消费者分析（Christensen）

| 非消费者类型 | 画像 | 为什么不用现有解 | 对产品的启示 |
|---|---|---|---|
| 城中村夫妻站 | 1~2 人，前店后院，一部老年机/千元机 | "记账是超市的事"；SaaS 要培训要联网 | 免费开始；名词全部说人话（"实名底档"不叫"KYC"）；离线可用 |
| 社区纸塑点 | 只收纸箱塑料的环保站 | "收赃判刑跟我没关系"——直到有人开始搭着卖铜 | 品类分级自解释（选品类时风险提示自动出现）；生活源废品不强制实名，不吓跑低频用户 |
| 大型分拣中心的下游小站 | 给固定打包站供货的站 | 打包站有自己的结算系统，但小站的来路记录是空白 | 打包站联营渠道（见 6.3）：下游小站的空白恰是打包站的链条风险 |
| 流动游商 | 三轮车走街串巷，不建档不注册 | 拒不拒收全凭心情，没有记录形态 | 拒收登记支持"不明人员"——拒收留痕不需要对方建档 |

非消费者共同阻碍排序：**觉得"登记是把自己人办进去"（敏感数据恐惧）> 觉得"记账是文书"（动作成本）> 觉得"小站没人查"（风险错觉）**。MVP 依次对应：身份证号只存本机（数据不出设备写进首页承诺）、落账 30 秒、看板用判例把尾部风险标价。

## 6. PESTEL 宏观扫描

| 维度 | 要点 | 对本机会 |
|---|---|---|
| **P** 政治 | 治安管理常态化：公安机关对"三电"（电力/电信/广播电视）设施、市政公用设施盗窃的打击专项持续进行；再生资源回收备案制度（商务+公安双备案）长期稳定 | 治安线监管对象恰是站点端：备案主体 = 登记主体，顺风 |
| **E** 经济 | 2024 回收总量 4.01 亿吨、回收价值 1.33 万亿元（中国物资再生协会）；铜铝等金属价格高位运行 | 金属价格越高，盗窃诱因越强 = 站点风险越大；回收体系规范化（商务部 9 部门 2024 通知）带来行业正规化顺风 |
| **S** 社会 | 城市治理对站点"脏乱差"整治持续，站点向规范化园区/连锁迁移；站主群体老龄化但微信普及率极高 | "正规军"身份叙事有真实溢价；微信级工具零教育成本 |
| **T** 技术 | 智能秤、电子磅单在部分园区普及；微信是站主-打包站-同行沟通的绝对通道 | 来路单不做硬件不碰秤：登记动作手机完成，磅单数字手填（参数可后接） |
| **E** 环境 | 双碳政策下再生资源体系是政策红利方向；家电以旧换新放大回收量 | 回收量越大、经手人越多，登记与自证的价值越大 |
| **L** 法律 | 掩饰隐瞒罪判例持续（最高法典型案例 + 地方判例年年有）；两高司法解释口径下"明显低价、同一人多次、时间场所异常"均为明知推定情形；属地特种行业管理规定宽严不一 | 判例潮 = 风险教育已完成；推定情形可被台账对冲 = 产品的法律立足点；属地差异用参数化 + "属地规则永远赢"消化 |

结论：宏观无逆风。P（治安专项常态化）与 L（判例潮 + 检察官建议的产品化空间）双顺风，E（金属价格高位）放大风险也放大登记价值；S（规范化迁移）让"正规军叙事"成立；站点量级宽口径数十万级支撑机会成立——**规则已生效、痛点有判例、轻产品空白仍在**。

## 7. 机会缺口矩阵

以"用户重要性 × 市场现有解完整度"定位空白：

```
重要性 高 │ ①行情查询/通用记账            ③【空白】收购治安底账
          │ （网站/小程序/进销存，成熟）    （实名底档/无证明拦截/低价留痕/
          │                                拒收登记/销赃特征点名/三件套出证，
          │                                无小微级轻产品）
重要性 低 │ ②园区智能磅/电子台账            ④拆解分拣教程内容
          │ （重硬件，园区场景）            （免费内容，弱付费）
          └─────────────────────────────
             现有解完整度 高            低
```

- ③的四段拆解交叉验证：烟盒记账（无留痕）、进销存（无实名无查验）、政务平台（管报送不管底账）、协会纸本（无守门可突击）——**每一段都有人做，合起来无人做**。
- ①是工具站的主场，不做（红海且与自证主线无关）；③覆盖的是沉默的大多数（1~2 人站点）。
- ②与④偏离主线，无冲突也不碰。
- 政策与司法事实给 ③ 背书：第八条登记义务长期有效、登记保存两年口径明确、掩饰隐瞒判例年年出现、4.01 亿吨的回收量证明协作密度——**规则已生效、判例在进行时、轻产品空白仍在**。

**阶段一结论**：来路单占位 ③——一条被登记义务、掩饰隐瞒判例潮与检察官建议共同供养、被"烟盒记账 + 谁卖都收"证明协作真实存在、却被进销存与政务平台同时忽略的缺口。
