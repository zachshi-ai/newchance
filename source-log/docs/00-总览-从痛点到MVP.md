## 1. 痛点（真实世界，有据可查）

废品站是治安管理的闸口，而闸口的风险不在收不上货，在**说不清收的货哪来的**：

- **登记是法定义务**：[《废旧金属收购业治安管理办法》第八条](14-调研来源.md#法规与登记义务红线口径的直接依据)要求收购生产性废旧金属时查验出售单位证明，登记出售方姓名、证件号与物品名称、数量、规格；《再生资源回收管理办法》口径：登记资料**保存不少于两年**。
- **收赃是刑事风险**：[《刑法》第三百一十二条](14-调研来源.md#司法裁判口径与真实判例风险量级的直接证据)掩饰、隐瞒犯罪所得罪，明知赃物而收购最高可判七年；司法通识口径下「明显低于市场价收购」「从同一人手中多次收购」「凌晨交易」都是推定"明知"的依据——废品站老板低价收电缆获刑的判例年年出现（2024 法治网、2025 湖北日报），最高法典型案例标注了"情节严重"的量级。
- **检察官的公开建议恰好是三个动作**：「了解物品来源**并做好记录**，来路不明应**拒绝收购**，发现犯罪所得及时报警」——查来源、做记录、拒收留痕，这就是产品的全部处方，不需要发明。
- **市场量级真实**：2024 年再生资源回收总量 4.01 亿吨、回收价值 1.33 万亿元（中国物资再生协会）；站点端是海量 1~2 人夫妻店，一部手机就是全部数字资产。
- **现状解法 = 烟盒记账 + 脑子 + 谁卖都收**：身份不查、证明不看、价格随口、纸单塞抽屉、检查前突击补——第一性差距：**"收进来的货"与"来路说得清的货"之间，没有任何小微级工具把它变成台账**。来路单把查验变拦截、把口头变登记、把拒收变自证。

## 2. 方案（机会 → 产品）

**来路单**：零依赖、本地优先的 PWA。

1. **出售人实名底档**：建档一次（姓名 + 证件号 + 电话备注），收购时点选复用——第八条登记义务变成顺手动作；身份证号只存本机不上云。
2. **收购落账守门**：生产性/公用设施金属（电缆/井盖/护栏/建筑金属件）**必须查验单位证明并登记，拿不出证明当场拦截**改走拒收登记；需实名品类缺证件号拒绝落账；**明显低于参考价必须写明原因**（折重/行情）——"白菜价"有了解释才是查验过的痕迹。
3. **拒收登记**：30 秒留痕（含"不明人员"）——拒收不是损失，是最硬的自证。
4. **销赃特征点名**：同一出售人 30 日内高危品类 ≥3 次自动亮红灯（"多次与同一销赃人合作"是司法推定情形）——多问一句，必要时报警。
5. **三件套出证**：登记册按月导出（收购 + 拒收 + 查验痕迹 + 两年保存口径，给检查）；单笔来源自证单（含**出售人签字确认栏**，给倒查）；出货对账单（微信文本发打包站，对账 + 去向留痕）。
6. **进出两本账 + 数据自持**：出货台账记录去向（卖给哪个打包站），月度经营账现算差额；100% 本地存储，JSON 导出/导入。

## 3. 诚实的现状声明（真实可落地，不空中楼阁）

- **已验证**（本仓库内可复现）：核心逻辑 23/23 单元测试通过（含守门拦截、低价判定边界、销赃特征窗口边界、实名缺口、跨月隔离、单据确定性、XSS 转义、导入导出往返）；浏览器端到端全流程（示例数据 → 看板点名 → 无证明拦截 → 正常落账 → 自证单生成 → 拒收登记 → 台账月报 → 设置档案）真实运行通过；单据为单文件 HTML 离线可用；零 npm/CDN/API 依赖；SW 缓存版本化。
- **未验证**（需真实用户，见 docs/13 假设登记册）：落账留存（H1）、出证使用（H2）、拒收渗透（H3）、付费意愿（H4）、打包站渠道（H5）——全部标注"待验证"并配有可证伪判据。
- **边界与免责**：不判定物品是否赃物（公安与法院的职权）、不替代属地备案与特种行业管理要求（属地规则永远赢）、不承诺登记册执法采信、参考价不是实时行情；**涉案认定以公安机关为准**。

## 5. 与既有项目的领域隔离（用户约束）

本方向为**再生资源流通 · 回收站点收购治安台账与赃物风险自证台（B2B 微体 · 1~2 人站点 · 公安治安线）**，已对照仓库根 README 领域登记表做领域排除：不与已交付的 12 个方向（宠物照护/餐饮食安/民宿周转/劳动用工/教培预收费/农资购销/二手车披露/燃气安检/口腔院感/工贸安全生产自查/养老照护/泳池水质）重叠；与同期在建方向亦不同域——汽修厂危废台账（garage-ledger，生态环境线，管危废去向）属危废物流，本方向属**再生资源流通业的收购治安登记**（收购物来路，不是废物转移也不是水质）。与 `newidea` 仓库点子亦无重叠：`repair-ledger` 是 C 端家庭"修还是换"的决策 CLI（提及"废品站"仅为修辞），本方向是 B 端站点的收购治安底账——主体、问题、行业语境均不同。付费主体（站主与打包站/分拣中心）、使用场景（收购查验登记与倒查自证）、行业语境（掩饰隐瞒判例与登记保存义务）均独立成域。**让位记录**：本仓库 2026-09-05 曾并行出现电梯维保方向草稿（lift-log），因与在建的 lift-sheet（梯保单）同域而主动废弃并转向本方向——领域互斥约束优先于沉没成本。
