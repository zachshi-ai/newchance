# 工据 WorkProof 🧾

> **小微雇主的用工合规自查台：现在踩了几条线、值多少钱、今天做什么——把每一次「没关系」变成拿得出手的凭据。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 员工信息不出设备

中国有 1.25 亿户个体工商户支撑近 3 亿人就业，劳动争议案件量常年高位——被告端绝大多数是没有 HR 的小微主体。雇一个人就自动触发一组刚性法律义务：一个月内签书面合同、试用期三档上限、社保强制、离职必须出具证明，每条都有明码标价的后果（二倍工资上限 11 个月工资、违法解除 2N）。而小微雇主的现状解法——不签合同"先干着"、现金发薪、签"自愿弃保承诺"——**本身全是违法或无效操作**；2025-09-01 司法解释（二）施行后，弃保承诺连纸面安慰都不再是。工据把红线检测、期限计时、法定单据和赔偿测算的成本打到趋近于零。

## 3 条命令跑起来

```bash
cd work-proof
npm start           # 等价于 python3 -m http.server 8082 --directory app
open http://localhost:8082
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程（五个典型画像：未签合同计时中 / 合同到期预警 / 违法试用期+弃保 / 离职未开证明 / 干净档案）。

## 功能

| 模块 | 说明 |
|---|---|
| 🚨 **红线引擎** | 书面合同（签约窗口 → 二倍工资按月计时 → 满一年视为无固定期限）、试用期（三档法定上限、不得约定情形、二次约定、80% 工资线）、社保弃保无效（解释二第十九条）、离职未开证明——逐条标注条文依据 |
| ⏳ **今日风险台** | 高危/待办计数 + 逐人风险卡（每项配「今天做什么」）+ 全员倒计时（签约截止/合同到期/试用期到期） |
| 🧾 **单据中心** | 离职证明四要素（《实施条例》第 24 条）一键生成：打印版**单文件 HTML**（可盖章）/ **纯文本复制**（微信发送）/ 直接打印；全员用工合规自查报告一键导出 |
| 🧮 **经济补偿计算器** | N / 2N / N+1：6 个月规则、社平三倍封顶 + 12 年封顶（第 47 条第二款）、2N 不叠加代通知金——整数「分」运算，赔偿金不错一分 |
| 📅 **法律口径的日期计算** | 日历月收敛（1/31 + 1 月 = 2/28），与《劳动合同法》"以上/不满"口径对齐；30 天近似会算错法律期限 |
| 🔓 **免费增值闭环** | 免费档 3 名员工全功能；第 4 名起 ¥99/年 离线授权码解锁（验证付费意愿的验证型实现，如实标注） |
| ⚙️ **数据自持** | 100% 本地存储，员工敏感信息不出设备（身份证选填 + 列表脱敏）；JSON 导出/导入（含结构校验）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
员工姓名、身份证号、工资是敏感个人信息——本地优先让"数据不出设备"成为合规卖点而不是妥协；给离职员工送证明走打印 HTML 或微信文本，不依赖任何在线服务。

## 边界与免责

- **不构成法律意见**：输出为按主流裁审口径生成的通用合规提示，逐条标注条文依据；个案请咨询执业律师或属地劳动人事争议仲裁机构。
- **只引用、不发明**：引擎只映射全国统一的成文规则；最低工资、社平三倍、仲裁时效等属地与个案参数一律不内置，由用户填写或明示不判定。
- **不判定历史责任**：新旧法衔接、劳动监察 2 年时效、仲裁时效中断均刻意不建模——工具回答"现在怎么办"，不回答"过去算不算"。
- **授权码为验证型实现**：防顺手滥用不防刻意破解；正式收费阶段应替换为后端发码。
