# 12 · 阶段三：机会转化产品方案

> 本阶段回答：机会怎么变成一个可卖的产品？用商业画布与价值主张画布定结构，用蓝海四动作定差异化，用 Kano 裁 MVP，最后把供应链想透——本项目的特殊之处在于：**唯一的内容原料是公开法律文本，"内容供应链"天然零成本且权威**。

---

## 1. 商业画布（Business Model Canvas）

| 模块 | 内容 |
|---|---|
| **客户细分** | 小微雇主（1~10 人：餐饮零售美业小店、工作室、小加工、个体工商户）；渠道客户：**法律咨询公司/劳动法律师/代理记账公司**（联营贴牌，见 §6.3） |
| **价值主张** | 对雇主：现在踩了几条线、值多少钱、今天做什么——把"没关系"变成有数字、有截止日期、有法条依据的台账；对渠道：给小微客户加一块"用工合规"服务交付物，白标即可交付 |
| **渠道** | 直达：劳动法普法短视频/图文（"弃保承诺无效了"新规内容）+ 计算器引流；渠道：法律咨询/代账联营（上游服务商即分销商）、商会/园区/集市协会 |
| **客户关系** | 免费自助 + 内容号陪跑（新规解读、红线清单内容）；渠道客户由合作方代维护 |
| **收入来源** | 免费版（3 名员工全功能）；完整版 ¥99/年（第 4 名员工起解锁，离线授权码已实现）；渠道联营年费 ¥1200/家（白标 ≤50 客户）待验证（H5） |
| **核心资源** | 法条→检查项的映射库（随立法/司法更新运营）、"工据=雇主自查"品类心智、法律咨询/代账渠道关系 |
| **关键业务** | 法规内容保鲜（新规第一时间落库：解释二 2025-09-01 即首次验证）、渠道拓展、留存运营（到期倒计时） |
| **重要伙伴** | 法律咨询公司/劳动法律师（渠道 + 口径校验源）、代账公司（渠道）、静态托管平台 |
| **成本结构** | 近零边际成本：无服务器账单、无 npm 审计、单人维护；获客内容制作为主要成本 |

## 2. 价值主张画布（Value Proposition Canvas）

**客户侧（小微雇主）**

| 客户任务 | 痛点 | 期望收益 |
|---|---|---|
| 雇人开工 | 不知道"先干着"已经违法；不知道窗口只有一个月 | 建档当天亮出高危计数与签约截止日 |
| 约定试用期 | 三档上限记不住，"再约定一次"很常见 | 输入合同类型与期限自动算法定上限，超限/二次约定直接点名 |
| 交社保 | "自愿弃保承诺"是行业惯性，2025-09-01 起全部无效 | 弃保状态一对一亮灯，引用第十九条原文 |
| 有人离职 | 证明不会开、四要素写不全，回头被追责 | 30 秒生成含四要素的离职证明（三通道送达） |
| 真被仲裁/协商解除 | N/2N/代通知金不会算，谈判心里没底 | 计算器给出月数、封顶与依据，谈判有数字 |

**产品侧**

| 功能 | 减痛 / 创益 |
|---|---|
| 风险台（高危/待办计数 + 逐人风险卡） | 减痛：恐惧第一次有数字 |
| 签约窗口/合同到期/试用期到期倒计时 | 创益：所有"自动增长的债务"都有截止日期 |
| 二倍工资按月计时（解释二第六条口径） | 减痛：每拖一个月的代价可见 |
| 经济补偿计算器（N/2N/N+1、三倍封顶 12 年） | 创益：谈判与预算有依据 |
| 离职证明三通道（打印版 HTML/文本复制/直接打印） | 创益：法定义务 30 秒履行完毕 |
| 自查报告一键导出 | 创益：向合伙人说明、整改前后对比留档 |

**契合检验**：五个客户任务 ↔ 六项功能一一对应，无"我们做了但没人要"的悬空功能。

## 3. 蓝海战略四动作框架（ERRC）

| 动作 | 内容 | 效果 |
|---|---|---|
| **剔除 Eliminate** | 考勤/薪酬/排班（HR SaaS 主场）、电子签（资质与巨头）、仲裁代办与律师撮合交易（责任风险）、云存储与账号体系（隐私风险 + 成本） | 与所有相邻巨头的战场全部放弃；合规责任边界一并划清 |
| **减少 Reduce** | 建档字段（一屏 17 项全含）、学习成本（零培训：一个页面看懂全部风险）、报告格式（一种文本模板） | 把"合规系统"降为微信级别的动作 |
| **增加 Increase** | 弃保协议无效预警（解释二第十九条，2025-09-01 当天即可用）、二倍工资按月计时、试用期三档上限 + 二次约定检测、80% 工资线、三倍封顶 12 年、离职证明四要素内置 | 把"行业默认的违法操作"逐条点亮——每一项都是 2025 年新规或成文法条的直接映射 |
| **创造 Create** | **小微雇主的"第一本用工风险账"**：违法后果从抽象恐惧变成具体数字（高危计数、敞口金额、截止日期）；免费档 3 人恰好覆盖最小盘 | 非消费者（"劳动法是大公司的事"型、人情替代合同型）第一次被服务 |

## 4. USP（独特销售主张）

> **唯一为小微雇主设计的用工合规自查台：未签合同二倍工资按月计时、试用期红线、弃保协议无效预警、离职证明 30 秒生成——不用装、不用学、数据不出本机，3 人以下免费。**

- 对比"什么都不记"：同样的零成本，但把"没关系"翻译成了"6.6 万敞口 + 今天做什么"；
- 对比 HR SaaS：不要按人头交年费、不要实施培训、不管考勤发薪，只管 HR SaaS 不管的那件事——"你现在违法了吗"；
- 对比律师：不替代打官司，只做争议前的日常自查；风险导流给律师而不是抢律师的活；
- 三句话之外的克制：**不说"保证不被告"，不判定历史责任与属地口径，不构成法律意见**——边界见诚实条款（docs/13 §5）。

## 6. 供应链分析（重点：三条链，第一条链决定内容可信度）

### 6.1 内容供应链（法律口径的"供货"——本项目的独特优势）

合规工具的本质是内容生意，原料质量决定生死。本项目的原料是**公开、免费、权威的法律文本**：

| 环节 | 内容 | 风险与对策 |
|---|---|---|
| 上游原料 | 全国人大（法律）、最高法（司法解释）、人社部（部门规章与公报）、地方裁审口径 | 原料免费且权威——**供应链零成本是本项目的结构性红利** |
| 加工 | 法条 → 检查项映射（如第 19 条三档上限 → `probationCapMonths` 纯函数；解释二第六条 → 按月计时） | 加工错误的代价极高 → 对策：只映射成文规则（日期类判定全国统一），赔偿基数等属地参数一律让用户填写；每条输出回引原文 |
| 保鲜 | 新规第一时间落库（解释二 2025-09-01 施行 = 首次保鲜实战） | 法条修订滞后是全行业通病 → 对策：版本化（STATE_VERSION）+ 更新日志；属地口径永远赢的原则写进产品 |
| 检验 | 免责边界：通用提示不构成法律意见 | 责任风险（R2）→ 对策：常驻免责 + 只引用不发明 + 不判定历史责任 |

### 6.2 产品自身供应链（MVP 的技术依赖链，逐项消除单点故障）

与 pet-handoff / food-sentry / turn-sheet 同一架构纪律：**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**本项目的特殊加成：**员工身份证号与工资是敏感个人信息，数据不出设备本身就是合规卖点**（《个人信息保护法》语境下，小微雇主用云 HR 存员工信息反而是新增风险）。

| 依赖 | 决策 | 单点故障消除 |
|---|---|---|
| 后端/数据库 | 无（localStorage 本地优先） | 无云账单、无停服；员工敏感信息不进任何服务器 |
| 第三方库 | 无（core.js 纯函数，日历月计算/状态判定/导出自实现） | 无供应链投毒面；`node --test` 零依赖可测 |
| 分发 | 任意静态服务器（`python3 -m http.server` 3 条命令） | 文档根即部署根，可迁移任意托管 |
| 单据送达 | 打印版单文件 HTML（内联样式）+ 纯文本复制 + 系统打印 | 不依赖任何在线消息服务，离职证明当场交付 |
| 金额计算 | 整数「分」运算（`parseMoneyToCents`/`fmtCents`，测试钉死） | 杜绝 0.1+0.2 浮点误差——赔偿金数字错一分都是事故 |
| 期限计算 | 日历月收敛（1/31 + 1 月 = 2/28） | 与《劳动合同法》"以上/不满"口径对齐，30 天近似会算错法律期限 |

### 6.3 分发供应链（获客链路——上游服务商即分销商的结构性优势）

```
内容制作（劳动法普法短视频/图文："2025 年 9 月起，弃保承诺一文不值"
          + N/2N 计算器作为引流工具）
      ↓ 免费工具承接（零摩擦，扫码即用）
直达用户（小微店主；免费档 3 人恰好覆盖最小盘）
      ↓ 规模化放大（本项目独有的渠道结构）
渠道分层：① 法律咨询公司/劳动法律师联营（B2B2C）：把工据白标进其小微法律顾问服务
         → 律所动机：顾问年费里多一块"日常台账"交付物、日常自查降低其案源处理成本、
           高危风险项天然导流新案源（透明披露）
         → 工据动机：一家法律咨询公司服务 50~300 家小微，获客成本≈0
         ② 代理记账公司：记账报税已是小微外包的合规动作，用工台账是天然加购品
         ③ 商会/园区/集市协会：批量成员单位的普惠合规工具
```

每层渠道都已有真实存在的服务商（法律咨询公司、代账公司、商会）——不需要发明新的中间商，只需给他们一个更好送的商品。**法律咨询/代账是全链路里"上游服务商反过来是分销商"的角色——供应链即渠道**，与翻房单的洗涤厂联营同构但分属不同行业（法律服务/财税 vs 布草洗涤），领域互斥。

---

**阶段三结论**：商业结构成立的关键在"近零成本 + 免费增值 + 法律咨询/代账渠道复用"；产品差异化在"把小微雇主默认的违法操作逐条点亮，并顺手交付了法定单据"。所有付费与渠道假设进入阶段四的假设登记册逐一证伪。
