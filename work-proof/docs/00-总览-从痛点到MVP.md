## 1. 痛点（真实世界，有据可查）

中国有 1.25 亿户个体工商户、支撑近 3 亿人就业（市场监管总局 2024 底口径），劳动争议案件量常年高位（人社部 2022 公报 316.2 万件且连年上升）——争议的被告端绝大多数是没有 HR 的小微主体。落到一个雇着 1~10 个人的店主身上，它具体成了一组每天在"自动计息"的债务：

- **雇人即触发刚性义务**：一个月内签书面合同（第 10 条）、试用期三档上限且只能约定一次（第 19 条）、试用期工资 ≥ 转正 80%（第 20 条）、社保强制、离职必须出具证明（第 50 条）——每条都有明码标价的后果（二倍工资上限 11 个月工资、试用期赔偿金、2N）。
- **举证责任倒置 + 仲裁免费**：工资表、考勤、合同由用人单位掌握，不提供承担不利后果（调解仲裁法第六条）；劳动者维权零成本——**证明成本是雇主风险的第一性变量**。
- **现状解法本身全是违法/无效操作**：不签合同"先干着"、现金/微信发薪无记录、签"自愿弃保承诺"、口头约定试用期再"续"一次——每一条都在放大敞口。
- **2025-09-01 司法解释（二）施行**（法释〔2025〕12 号）：弃保协议一律无效 + 员工可解除并索经济补偿 + 补缴后可追回补贴；二倍工资按月计算、满一年封顶、续签一个月窗口全部成文——**规则统一时点 = 存量违法暴露期 = 普法窗口**。
- 第一性差距：**"雇 1~10 个人、没有 HR、没人告诉他你已经违法了"——这个日常自查段没有任何产品承接**。HR SaaS 管流程不管风险，律师管争议后不管日常，模板站有模板没计算。

## 2. 方案（机会 → 产品）

**工据 WorkProof**：零依赖、本地优先的 PWA。

1. **员工建档**：一屏 17 项全含（入职/合同/试用期/工资/社保/离职善后），敏感信息选填且脱敏显示、不出设备。
2. **红线引擎**（核心计算）：书面合同（签约窗口倒计时 → 二倍工资按月计时 → 满一年视为无固定期限）、试用期（三档法定上限、不得约定情形、二次约定、80% 工资线、超限履行起算日）、社保（弃保无效一对一亮灯）、离职善后（未开证明高危）。逐条标注条文依据。
3. **今日风险台**：高危/待办计数 + 逐人风险卡（每项配"今天做什么"）+ 全员倒计时（签约截止/合同到期/试用期到期）。
4. **单据中心**：离职证明四要素（实施条例第 24 条）一键生成——打印版单文件 HTML / 纯文本复制 / 直接打印三通道；全员用工合规自查报告一键导出。
5. **经济补偿计算器**：N / 2N / N+1，含 6 个月规则、社平三倍封顶 + 12 年封顶（第 47 条第二款）、2N 不叠加代通知金。
6. **数据自持与免费增值**：100% 本地存储，JSON 导出/导入；免费档 3 名员工全功能，第 4 名起 ¥99/年 离线授权码解锁（验证付费意愿）。

## 3. 诚实的现状声明（真实可落地，不空中楼阁）

- **已验证**（本仓库内可复现）：核心逻辑 40/40 单元测试通过；浏览器端到端全流程（示例数据 → 风险台命中 4 高危 2 待办 → 自查报告逐人列依据 → 离职证明四要素 → 计算器 N=21,000 → 授权码激活 → 闸门解除）真实运行通过；打印版 HTML 为单文件、离线可用；零 npm/CDN/API 依赖。
- **未验证**（需真实用户，见 docs/13 假设登记册）：建档留存（H1）、整改闭环（H2）、证明时效（H3）、付费意愿（H4）、渠道联营（H5）——全部标注"待验证"并配有可证伪判据。
- **边界与免责**：输出为通用合规提示不构成法律意见；只引用成文规则、属地参数一律不内置；不判定历史责任与时效；不做仲裁代办；授权码为验证型实现。细则见 [docs/13 诚实条款](13-阶段四-产品落地验证闭环.md)。

## 5. 与既有项目的领域隔离（用户约束）

本方向为**劳动用工合规 · 小微雇主侧自查与法定单据（B2B · 1~10 人小微 · 人社监管线）**，已对照仓库根 README 领域登记表与 `newidea` 仓库 62 个点子做领域排除：

- 与 `pet-handoff`（C 端宠物照护）、`turn-sheet`（民宿住宿运营）无任何交集；
- 与 `food-sentry` 的关键区隔：食安哨是**市场监管线 · 对外的食品安全合规证明**（市监 60 号令、迎检留痕），工据是**人社线 · 对内的用工关系风险台账**（劳动合同法体系、民事赔偿敞口）——法规体系、监管机关、付费逻辑（罚款规避 vs 二倍工资/2N 赔偿金规避）均不同域；
- 与 `newidea` 的区隔：`shadow-base` 是**雇员侧**社保基数审计（个人查公司），工据是**雇主侧**自查（公司管风险）；newidea 62 点子均为个人/开发者视角，无任何雇主侧用工合规方向。
