# 10 · 阶段一：识别机会与洞察市场

> 本阶段回答：世界的哪个痛点值得做？用第一性原理拆到底，用 JTBD / 船模型 / 非消费者分析还原真实场景，用 PESTEL 扫宏观，用机会缺口矩阵定位空白。

---

## 1. 第一性原理拆解

不问"市面上有什么 HR 软件"，只保留不可再分的事实：

| # | 不可再分的事实 | 推论 |
|---|---|---|
| F1 | 雇一个人就自动产生一组**刚性法律义务**：一个月内签书面合同（《劳动合同法》第 10 条）、试用期三档上限且只能约定一次（第 19 条）、试用期工资 ≥ 转正 80%（第 20 条）、社保强制缴纳（《社会保险法》）、离职时必须出具证明（第 50 条）——每一条都有明码标价的违法后果（第 82/83/87 条：二倍工资、试用期赔偿金、2N） | 用工合规不是"要不要做"的选择题，是"雇人即触发"的默认债务；违约价格 = 月工资的倍数，随时间自动增长 |
| F2 | 二倍工资、违法试用期赔偿、2N 赔偿金全部是**可以精确计算的天文数字级民事敞口**：未签合同上限 11 个月工资（司法实践通称，成文确认见解释二第九条），违法解除 = 2N | 一个 6000 元月薪的员工，未签合同拖满一年 = 最高 6.6 万元的敞口——对 3 人小店是真金白银 |
| F3 | **举证责任倒置**：与争议有关的工资表、考勤记录、劳动合同由用人单位掌握管理，不提供承担不利后果（《劳动争议调解仲裁法》第六条）；劳动仲裁对劳动者**不收费** | 劳动者的维权成本趋近于零，雇主的抗辩成本完全取决于"手里有没有留痕"——**证明成本是雇主风险的第一性变量** |
| F4 | 中国有 1.25 亿户个体工商户、支撑近 3 亿人就业（市场监管总局 2024 底口径）；劳动争议案件量常年高位（人社部 2022 公报 316.2 万件且连年上升）——争议的被告端绝大多数是没有 HR 的小微主体 | 小微是劳动争议的"沉默被告群"，但没有任何产品为他们服务 |
| F5 | 小微雇主的现状解法 = 不签合同"先干着" + 现金/微信发工资 + 签一纸"自愿弃保承诺" + 口头约定试用期——**每一条现状解法本身都是违法或无效行为** | 小微不是"不愿合规"，是把违法操作当成了合规常识；2025-09-01 司法解释二第十九条把"弃保承诺"这最后一块遮羞布明确判为无效 |
| F6 | 2025-08-01 最高法发布《劳动争议司法解释（二）》（法释〔2025〕12 号，2025-09-01 施行）：弃保协议一律无效 + 劳动者可解除并索经济补偿 + 补缴后可追回社保补贴；二倍工资按月计算、满一年停止累计、续签一个月窗口全部成文化 | **规则刚刚统一、存量违法存量巨大、普法窗口正在打开**——这是雇主侧合规工具的历史性时机 |
| F7 | 律师服务与小微付费力之间存在鸿沟：法律顾问年费数千至数万元、单案代理费数千元，而小微需要的不是打官司，是"每天别踩红线" | 法律服务供给集中在"争议后"，"争议前"的日常自查段无人覆盖 |
| F8 | 员工姓名 + 身份证号 + 工资是高度敏感个人信息 | 任何云方案都在给小微增加新的泄露风险——本地优先不是妥协，是卖点 |

**第一性结论**：小微雇主的用工风险 = "违约价格自动增长的债务 × 举证责任倒置 × 零成本维权的对手方"，而他们的现状解法全部在放大这三项。谁把"你现在踩了几条线、每条线值多少钱、今天做什么"的成本打到趋近于零，谁就接住 2025-09-01 这个规则统一时点释放出的存量需求。

## 2. 痛点 - 爽点 - 痒点模型（梁宁）

| 层 | 用户心理 | 工据对应 |
|---|---|---|
| **痛点**（恐惧/怕） | 怕员工去仲裁（二倍工资 11 个月、2N、补缴+经济补偿三连）；怕"自愿弃保承诺"在 2025-09-01 后一夜变废纸；怕检查时拿不出台账；怕离职员工回头告 | 风险台高危计数 + 每项风险配法条依据与赔偿敞口——恐惧第一次有了数字和截止日期 |
| **爽点**（即时确定性） | 打开就知道"现在几条高危"；每项配"今天做什么"；离职证明 30 秒生成；补签一天止损一个月工资 | 今日倒计时（签约窗口/合同到期/试用期到期）+ 四步动作卡片 |
| **痒点**（虚拟自我） | "我的 3 人小店也有大企业级的合规台账"；"我对每个员工都依法办事" | 逐人档案 + 风险卡 + 自查报告——夫妻店的"规范经营者"身份叙事 |

优先级：痛点 > 爽点 > 痒点。MVP 只做痛点与爽点，痒点靠自查报告顺手满足，不做课程/社区/测评。

## 3. JTBD（待办任务）

**主任务陈述**：**当**我雇了新员工、试用期要转正、合同快到期、有人要离职时，**我要**立刻知道有没有踩法律红线、该给的单据有没有给，**以便**不把辛苦钱赔进二倍工资和赔偿金，出了争议手里有凭据。

三维拆解：

| 维度 | Job | 现状方案的失败点 |
|---|---|---|
| 功能性 | 红线检测（合同/试用期/社保/离职善后）；期限计算（一个月窗口、三档试用期上限、满一年线）；单据产出（离职证明四要素）；赔偿测算（N/2N/N+1） | 律师太贵、HR SaaS 不管风险判定、模板没有日期计算 |
| 情感性 | 不用再想"万一他告我怎么办"；遇到纠纷不心虚 | 弃保承诺给的是假安心——2025-09-01 起连纸面安慰都没有了 |
| 社会性 | "我对员工够意思也够规矩"；向合伙人/家人证明小店经营规范 | 没有任何体面的留痕载体 |

**竞品不是别的 App，而是「不签合同先干着 + 微信转账 + 一纸弃保承诺」**——它们免费且是行业默认动作，这是我们真正的敌人（见阶段二波特五力：替代品威胁）。

## 4. 船模型

> 用户要的从来不是船，是安全过河。这里河对岸 = 雇几个人不赔大钱、出了争议有凭据。

| 元素 | 本场景 | 现状问题 |
|---|---|---|
| 乘客 | 1~10 人的小微雇主（餐饮零售美业小店、工作室、小加工、个体工商户） | — |
| 船 A：不签合同 + 微信转账 + 弃保承诺书 | 现状默认解，零成本 | 每一条都是违法/无效行为；风险随工龄自动增长且不可逆 |
| 船 B：HR SaaS（钉钉智能人事、2号人事部、北森等） | 考勤、薪酬、排班、电子签 | 为"有 HR 的公司"设计：管流程不管风险，没有任何"你现在违法了吗"的判定；按人头年费 + 实施成本对 3 人店过重 |
| 船 C：律师 / 法律顾问 / 按次咨询 | 专业、权威 | 年费数千至数万元，单次数百元；服务"争议后"而非"日常"；小微请不起也想不到请 |
| 船 D：劳动法公众号 / Word 模板下载站 | 普法内容丰富、模板免费 | 静态内容没有日期计算、没有预警、没有台账——看得懂、记不住、用不上 |
| 河 | **雇 1~10 个人、没有 HR、没人告诉他"你已经违法了"的黑水区** | 四条船共同的黑水区 |

**定位推论**：工据**不造 HR SaaS 的船，也不抢律师的活**——做挂在所有船之间的**"合规黑匣子"**：不考勤、不发薪、不电子签、不代办仲裁，只回答三个问题：*现在踩了几条线？值多少钱？今天做什么？*与 HR SaaS 互补（它管流程、工据管风险），与律师上下游协同（风险导流而非替代），与弃保承诺书正面对抗（产品存在的第一理由就是宣判它无效）。

## 5. 非消费者分析（Christensen）

| 非消费者类型 | 画像 | 为什么不用现有解 | 对产品的启示 |
|---|---|---|---|
| "劳动法是大公司的事"型 | 夫妻店、3 人以下 | 从没想过雇人需要合规；HR SaaS/律师都"不是我这个段位的" | 免费档 3 人全功能——恰好覆盖"雇 1~3 个人"的最小盘，首次让合规工具出现在他们的段位里 |
| 人情替代合同型 | 用亲戚/老乡，"自己人不用签" | 觉得签合同伤感情 | 风险台把"自己人"同样按 11 个月敞口计价——人情不是合同，账本才是 |
| 现金/微信发薪型 | 无工资表、无考勤 | 不知道举证责任倒置意味着什么 | 自查报告逐人留痕，第一次给出"该留什么证据"的清单 |
| 模板收藏家型 | 下载过劳动合同模板但从未填完 | 模板是静态的：没有日期计算、没有到期预警、没有风险判定 | 模板 ≠ 台账；工据把模板升级成"会自己算日子的账" |

非消费者共同阻碍排序：**意识缺失（不知道自己已违法）> 段位错配（觉得合规是大企业的奢侈品）> 学习成本**。MVP 依次对应：首页高危计数 + 司法解释二热点内容获客、3 人免费档、零培训单页操作。

## 6. PESTEL 宏观扫描

| 维度 | 要点 | 对本机会 |
|---|---|---|
| **P** 政治 | 最高法《劳动争议司法解释（二）》2025-08-01 发布、2025-09-01 施行：弃保协议一律无效、二倍工资规则成文化；人社部欠薪与违法用工治理常态化 | **历史性顺风**：规则统一时点 = 普法窗口 = 存量违法暴露期，工具顺势成为"新规自查"入口 |
| **E** 经济 | 个体工商户 1.25 亿户、支撑近 3 亿人就业（2024 底）；劳动争议案件量高位（2022 公报 316.2 万件，连年上升）；法律服务价格与小微付费力的鸿沟 | 需求基数巨大且被动增长；付费逻辑是"省下 N 倍月薪的赔偿"而非"合规罚款"——比罚款类合规工具更强的省钱叙事；但小微付费力弱 → 免费增值是唯一可行定价 |
| **S** 社会 | 新生代劳动者权利意识上升，劳动法普法短视频爆发——**员工端维权知识增速远超雇主端**；"00 后整顿职场"舆情常态化 | 雇主与员工之间的法律信息差在快速拉平，雇主侧的知识赤字就是产品空间；普法内容同时是天然获客渠道 |
| **T** 技术 | 普法内容分发成本趋零（短视频）；PWA/本地存储/打印为系统级能力；电子签已普及但只解决"签"，不解决"合不合规" | 本地优先 PWA 零成本交付 + 打印/文本三通道送达；电子签越普及，"签完之后的风险自查"空白越明显 |
| **E** 环境 | 无纸化、电子存证政务趋势 | 打印版单文件 HTML + 文本通道兼容"线上留一份、纸质存一份"的小微习惯 |
| **L** 法律 | 举证责任倒置（调解仲裁法第六条）；劳动仲裁不收费、时效一年；二倍工资/2N/试用期赔偿全部可计算；劳动监察 2 年查处时效 | 维权零成本 + 举证责任在雇主 = **"留痕"本身就是法律上的护身符**，产品的每一项输出都直接服务举证地位；监察时效是本产品刻意不碰的边界（不误报"历史追责"） |

结论：宏观是本项目所见三个方向里**顺风最锐利的一次**——P（新规施行时点）与 S（维权信息差拉平）双强顺风，L（举证倒置 + 仲裁免费）直接定义产品价值，E（付费力弱）约束商业模式但不约束机会成立。

## 7. 机会缺口矩阵

以"用户重要性 × 市场现有解完整度"定位空白：

```
重要性 高 │ ①考勤/薪酬/排班          ③【空白】雇主侧日常合规自查
          │ （HR SaaS 红海，为有 HR    （红线判定+期限计时+法定单据，
          │   的公司设计）              无小微级产品）
重要性 低 │ ②电子签                  ④劳动法内容付费
          │ （牌照+巨头盘踞）          （同质化泛滥）
          └─────────────────────────────
             现有解完整度 高            低
```

- ③的四段拆解交叉验证：什么都不记（默认解无风险意识）、HR SaaS（管流程不管风险）、律师（争议后服务）、模板站（静态无计算）——**每一段都有人做，合起来无人做**。
- ①是钉钉们的主场，按人头收费、要实施要培训，3 人店用不起；③覆盖的是沉默的大多数。
- ②有电子签名法与 CA 资质壁垒，巨头（e签宝/法大大/腾讯电子签）盘踞，不碰；④内容同质化、无付费闭环。
- 时机背书：解释二 2025-09-01 施行给 ③ 一个明确的"现在"——存量弃保承诺一夜失效、二倍工资规则刚刚统一，**需求是刚性的、时点是新的、品类是空的**。

**阶段一结论**：工据占位 ③——一条被 1.25 亿小微主体、举证责任倒置与 2025 新规共同供养、被"不签合同先干着"证明需求真实存在、却被所有软件产品忽略的缺口。
