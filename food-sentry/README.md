# 食安哨 FoodSentry 🛡️

> **小店 30 秒食安台账：每天打卡留痕，检查前一天一键打印 —— "做了"变成"能证明做了"。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 不替代法定报送

「日管控、周排查、月调度」是市场监管 60 号令的硬要求：未建立先警告，拒不改正可罚 5 千~3 万元（《食品安全法》第 126 条）。而小店的现状是纸质台账本 + 记忆补填，检查前突击。食安哨把每天的合规动作变成 30 秒打卡：漏检自动点名、异常强制留整改说明、周报月报自动汇总、迎检台账一键打印。

## 3 条命令跑起来

```bash
cd food-sentry
npm start          # 等价于 python3 -m http.server 8081 --directory app
open http://localhost:8081
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程。

## 功能

| 模块 | 说明 |
|---|---|
| ✅ **日管控打卡** | 晨检 / 进货查验（索证索票）/ 环境卫生·虫害 / 餐用具消毒 / 设备设施 / 餐厨废弃物，每项一句话法规依据 + 操作提示；异常必须留整改说明才计入 |
| 📋 **周排查 · 月调度** | 由打卡记录确定性生成《每周食品安全排查治理报告》《每月食品安全调度会议纪要》小店简化版：完成率、异常整改、漏检日自动点名 |
| 🧾 **台账导出（迎检）** | 任意日期区间一键生成**打印版单文件 HTML**（内联样式、无外部资源、含签字栏，微信可直接发送）+ 纯文本粘贴双通道 |
| 👥 **健康证预警** | 员工健康证到期前 30 天进首页待办，过期置顶点名 |
| 🏪 **门店档案** | 业态决定检查项模板（食堂/集体用餐自动加"食品留样 ≥125g·48h"）；支持自定义检查项 |
| ⚙️ **数据自持** | 100% 本地存储；JSON 导出/导入（换机迁移，含结构校验）；本地事件流可导出（验证用埋点） |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md#6-供应链分析重点三条链)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
后厨网络差也能打卡（PWA 离线）；打印走系统级能力 + 单文件 HTML，不依赖任何在线服务。数据不出设备。

## 边界与免责

- 本地打印台账用于**自查与检查备查**，不替代属地监管要求的法定报送系统（如省级追溯平台）；本地时间戳不宣称司法级不可篡改效力。
- 60 号令"日周月"对企业主体强制、对个体户为地方参照执行；进货查验等台账记录义务（《食品安全法》第 53 条）全量适用。文案不虚张处罚适用的普适性。
- 检查项模板为通识口径并标注法规依据，具体以属地监管要求为准；异常处置遵循属地监管与专业机构意见。
