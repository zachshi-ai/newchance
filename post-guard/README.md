# 岗卫账 PostGuard 🦺

> **小微企业接害岗位的职业健康监护台账：上岗前闸钟、在岗到期钟、离岗闸钟三钟齐转，检测·申报·培训·防护四件套同页管理，GBZ 188—2025 新规自动定档，迎检自证包一键导出。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 数据不出设备

一个存在噪声、粉尘、铅苯、高温岗位的小微企业，身上同时跑着三层法定时钟：**员工层**的上岗前/在岗期间/离岗时三次职业健康检查（在岗周期按「岗位 × 接害因素 × 作业分级」定档——**GBZ 188—2025 已于 2026-08-01 施行代替 2014 版，粉尘与化学物改为按作业分级定档且总体缩短，未分级的从严按 1 年 1 次执行**）；**机构层**的职业病危害因素定期检测（危害严重类每年 1 次+每 3 年现状评价，危害一般类每 3 年 1 次）、危害项目申报变更（竣工验收 30 日内/其他变更 15 日内）、职业卫生培训、防护用品发放；**红线层**是三根高压线：安排未经上岗前检查者接害（罚款 5 万~30 万）、在岗检查/建档/告知缺失（5 万~10 万）、未检离岗解除劳动合同（法定禁止）。小微企业的现状是纸质体检报告袋 + 老板脑子记日期 + 检查员来了现凑材料——岗卫账把这段黑箱变成白箱：建档自动定档上钟 → 红黄绿倒计时 → 检查 30 秒登记 → 异常结论强制生成处置待办 → 迎检自证包一键导出。

## 3 条命令跑起来

```bash
cd post-guard
npm start           # 等价于 python3 -m http.server 8099 --directory app
open http://localhost:8099
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入请到「设置」点「**载入示例数据**」，30 秒体验完整流程（一座机械加工厂：电焊/打磨/喷涂三岗位、5 名员工、含两条红线演示）。

## 功能

| 模块 | 说明 |
|---|---|
| 🏗️ **岗位建档 + GBZ 188—2025 定档引擎** | 岗位登记接害因素（噪声/矽尘/煤尘/电焊烟尘/木粉尘/铅/苯/高温）+ 作业分级 + 噪声 8h 等效声级；**周期自动判档**：噪声 ≥85 dB(A) 1 年、80~85 2 年、<80 免监护；粉尘/化学物按 GBZ/T 229 分级 Ⅰ 级 2 年、Ⅱ 级及以上 1 年、**未分级从严 1 年**；多因素取最短 |
| 👷 **员工三钟（一人一档）** | **上岗前闸钟**：无检查记录红牌禁止接害（第 75 条(七)）；**在岗到期钟**：最近检查+岗位周期红黄绿倒计时；**离岗闸钟**：拟离职自动开 30 日检查窗，90 日内在岗检查依法视同离岗检查（49 号令第 15 条），已离岗未检亮「不得解除/终止合同」红牌 |
| 🩺 **检查登记与处置待办** | 检查结论四分类（正常/职业禁忌/健康损害相关/疑似职业病），异常结论**强制生成处置待办**（调离/妥善安置/医学观察或诊断，49 号令第 17 条）并追踪闭环；费用随手记，自动汇总「健康投入账」 |
| 📋 **合规四件套** | ① 定期检测/现状评价钟（5 号令第 20 条按危害等级分档）② 申报变更钟（48 号令第 8 条四种情形 30/15 日）③ 培训钟（负责人+劳动者复训，第 34 条）④ 防护用品发放钟（按岗位周期） |
| 🧾 **离岗档案复印件** | 一键生成员工个人监护档案单文件 HTML（职业史/接触史/历次检查/费用/签章栏）——第 36 条法定义务「离职时如实、无偿提供并签章」从半天翻箱倒柜变成 10 秒 |
| 📑 **迎检自证包** | 单文件 HTML：员工监护钟况一览（含定档依据）+ 检测评价 + 申报变更 + 培训，逐项标注法条口径，可打印签收 |
| ⚙️ **数据自持** | 100% 本地存储；JSON 导出/导入（含结构校验）；周期/预警窗全部可在设置中按属地口径覆盖 |

## 为什么没有后端 / 没有依赖

设计而非偷懒（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用；无第三方 API → 无停服风险。**
车间与乡镇小厂网络差，PWA 离线可用；员工姓名+健康检查数据是高敏个人信息，**数据不出设备**是最小合规方案；自证包是单文件 HTML，微信发文件即达。**不做体检机构、不做检测机构撮合平台、不代申报、不做职业病诊断**——这里是企业自己的监护总账。

## 边界与免责

- **不做体检机构/检测机构撮合、不代申报代缴、不做职业病诊断与鉴定**——检查结果与检测报告手工录入（特性而非缺陷：无资金合规负担、离线可用、高敏数据不出设备）。职业健康检查以备案机构出具的报告为准。
- 周期口径（GBZ 188—2025 三分档、检测 12/36 个月、申报 30/15 日）为现行标准与部门规章的参数化呈现；**属地卫生健康部门要求、检查机构个体建议与员工复查安排永远赢**，工具亮灯提示不替代法定义务，标准修订后随版本更新。
- 内置 8 类接害因素覆盖小微常见场景（噪声/四类粉尘/铅/苯/高温），未覆盖因素可用「分级+固定周期」口径兜底；GBZ 188—2025 监护范围较 2014 版显著扩容（新增腕管综合征、创伤后应激障碍等，配合《职业病分类和目录》12 大类 135 种），特殊行业请按标准全文核对。
- 监护档案的证据效力以法定台账表式与档案管理规定为准（保存期限不少于 15 年），工具不宣称司法级存证；属地有制式档案要求时以制式为准、本工具为底稿与索引。
