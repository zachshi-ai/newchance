# 12 · 阶段三：机会转化产品方案

> 本阶段使用的框架：商业画布、价值主张画布、蓝海四动作（ERRC）、USP、Kano、供应链三层分析。
> 结论先行的三句话：**免费工具获客、服务与转介变现；USP 是「新规定档引擎+三钟+一键交付」的组合；零依赖本地优先是供应链分析的结论，不是技术偏好。**

## 1. 商业画布（Business Model Canvas）

| 模块 | 内容 |
|---|---|
| **客户细分** | ① 10~50 人、存在噪声/粉尘/化学/高温岗位的小微加工/建材/家具/五金/印刷厂（主）② 个体工商户级小作坊（次，免费池）③ 乡镇街道/园区统一「职业健康管家」采购（B2G2B 探索） |
| **价值主张** | 把 GBZ 188—2025 换挡期的「重新定档+三只法定钟+迎检出示」从半天翻箱倒柜变成 10 分钟建档+5 分钟出示；红线（5 万~30 万）看得见 |
| **渠道** | 乡镇职业卫生宣讲会、职业健康检查机构合作转介、行业协会/园区物业、短视频（「新规换了你知道吗」选题）、GitHub 开源本身 |
| **客户关系** | 工具免费自助 + 付费建档服务 + 体检季提醒（微信文本/文件流转） |
| **收入流** | ① 建档服务（远程帮建岗位定档+导入员工+解读机构报告）¥399~899/厂一次性 ② 年度服务费 ¥199/年（预警推送+新规口径更新+自证包定制抬头）③ 体检机构转介分成 5%~10%（通过工具预约产生）④ B2G2B 网格化采购定制 |
| **关键资源** | 经原文核验的法规口径知识库（docs/14）+ 定档引擎规则表 + 项目家族复用的零依赖 PWA 骨架 |
| **关键活动** | 法规口径维护（换挡响应）、渠道地推验证、假设验证循环（docs/13） |
| **重要伙伴** | 职业健康检查机构（转介）、乡镇职业卫生管理员（渠道）、行业协会（背书） |
| **成本结构** | 近零边际成本（无服务器无依赖）；主要成本=创始人时间（法规跟踪+渠道验证） |

## 2. 价值主张画布

**客户任务**：让每个接害员工在正确时点被检查、结果被处置、随时能出示证明。
**痛点**：看不懂 GBZ 188 定档规则；记不住三只钟；迎检凑材料半天；离职档案交付翻箱倒柜；红线罚则悬在头上。
**收益期待**：检查花出去的钱能看见（投入账）；检查员来了不慌；员工索赔时有完整监护链。

**产品侧（缓解痛点/创造收益）**：
- 痛点↔功能一一映射：定档断点→定档引擎；闸门断点→上岗前闸钟；离岗断点→离岗闸钟+档案复印件；出示断点→迎检自证包。
- 收益↔功能：健康投入账（费用汇总）；红线名单（风险可视化）；定档依据展示（白盒规则）。

**适配性检验**：MVP 六视图（看板/岗位/员工/合规四件套/自证包/设置）与上述映射逐条对应，无「画布里有、产品里没有」的悬空项。

## 3. 蓝海四动作（ERRC）

| 动作 | 内容 |
|---|---|
| **Eliminate 消除** | ① 服务器与账号体系（本地优先，消除注册流失与数据焦虑）② 术语门槛（「上岗前闸钟」替代职业卫生行话）③ 纸质台账的唯一性 |
| **Reduce 减少** | ① 迎检准备时间：半天→5 分钟 ② 建档动作：一字段登录册→岗位×因素选择式 ③ 新规学习成本：定档依据直接展示，不用通读标准 |
| **Raise 提升** | ① 档案交付体验：离岗复印件从「找不到」到 10 秒带签章导出 ② 红线风险可视化（此前只存在于法条文本里）③ 检查费用从流水变「健康投入账」 |
| **Create 创造** | ① GBZ 188—2025 定档引擎（未分级从严、多因素取最短）——新规换挡期独有 ② 异常结论→法定处置待办闭环（49 号令第 17 条五项措施的执行追踪）③ 90 日视同离岗检查的自动判定 |

## 4. USP（独特销售主张）

> **「2026 新规定档引擎+三只法定钟：岗卫账让小微企业 10 分钟重建职业健康监护台账，检查员上门 5 分钟出示自证包。」**

支撑点三条：① 定档引擎内置 GBZ 188—2025 全部判档规则并展示口径原文（竞品纸质/Excel/SaaS 均无）；② 罚则红线（5 万~30 万）在产品里被翻译成红牌与红线名单，风险可感；③ 数据不出设备——对高敏健康数据是合规优势，对产品是零服务器成本。

## 5. Kano 模型

| 层级 | 功能 | MVP 处理 |
|---|---|---|
| **基本型**（没有就流失） | 三钟红黄绿、岗位建档、检查登记、数据本地保存、备份导出 | ✅ 全部实现并有测试覆盖 |
| **期望型**（越多越满意） | 定档引擎口径展示、四件套钟、红线名单、健康投入账、示例数据 | ✅ 全部实现 |
| **兴奋型**（没想到会有） | 离岗档案复印件一键导出（第 36 条义务的优雅解法）、自证包逐项标注法条口径、90 日视同离岗自动判定 | ✅ 实现前两项；第三项内置于离岗闸钟 |
| **无差异/反向**（不做） | 社交分享、排行榜、AI 健康建议（涉医疗风险）、云端同步 | 明确不做，写进边界 |

## 6. 供应链分析（三层）

**① 产品侧供应链（卖什么、成本在哪）**：
纯数字产品，无实体物料、无库存、无物流。唯一「原料」是法规文本（公开、免费、gov.cn 原文）与标准口径（GBZ 188—2025 发布通告公开）。供应链风险=口径过期风险，缓释=周期参数化+docs/14 版本记录+30 天修订响应承诺。

**② 产品自身供应链（用什么造的）**：
零 npm 依赖、零第三方 API、零 CDN——不存在的供应链就是最稳的供应链：无投毒攻击面、无断供风险、无账单。技术栈=浏览器标准能力（ES Module/localStorage/Service Worker/Blob 下载），单人可维护十年。**这个选择由供应链分析倒逼产生，而非技术洁癖。**

**③ 分发供应链（怎么到用户手里）**：
GitHub Pages/静态托管 → 微信转发文件 → 乡镇宣讲现场扫码。整条链路无中间商、无渠道库存；付费服务的交付物（建档配置、自证包定制）同样是数字文件。分发瓶颈不在物流在信任，所以渠道选择以「已有信任的节点」为准：体检机构、乡镇职业卫生管理员、行业协会。

## 7. 阶段结论

商业模式闭环成立：工具零成本获客 → 建档服务+年度服务费+转介分成三线变现 → 法规知识库是唯一需要持续投入的关键资源。进入阶段四定义验证闭环（docs/13）。
