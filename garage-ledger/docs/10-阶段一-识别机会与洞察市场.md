# 10 · 阶段一：识别机会与洞察市场

> 本阶段回答：世界的哪个痛点值得做？用第一性原理拆到底，用 JTBD / 船模型 / 非消费者分析还原真实场景，用 PESTEL 扫宏观，用机会缺口矩阵定位空白。

## 1. 第一性原理拆解

不问"市面上有什么危废软件"，只保留不可再分的事实：

| # | 不可再分的事实 | 推论 |
|---|---|---|
| F1 | 修车必然产废：换油产生废机油、钣喷产生漆渣与废溶剂、换电瓶产生废铅蓄电池、换机滤产生沾染废物——这些在《国家危险废物名录》（2021 年版，部令第 15 号，2021-01-01 施行）里被明确列为**危险废物**（废润滑油 900-214-08、废铅蓄电池 900-052-31、沾染的包装物/容器/滤芯 900-041-49、喷漆废物 900-252-12 等） | 危废不是"边角垃圾"，从产生那一刻起它就是企业的**法定处置义务**——修理厂账上多了一笔看不见的负债。危废账首先是**负债账**，其次才是库存账 |
| F2 | 《固体废物污染环境防治法》（2020 修订）给产废单位定了四件硬义务：**管理计划备案 + 管理台账如实记录**（第 78 条）、**贮存不得超过一年**（第 81 条）、**禁止将危废提供或委托给无许可证的单位**（第 80 条）、转移运行**联单**——而"能不能证明"由产废方举证：你要能说清每一滴废机油的去向 | 合规的关键变量是**可追溯性**：不是"你交了"，是"你能证明你交给了有资质的人、且没有存放超过一年"。证明成本就是痛点的第一性变量 |
| F3 | 罚则与刑事线都够到小微的生存线：未建台账 → **10 万~100 万**（第 112 条第 13 项）；联单未按规定填写运行 → **10 万~100 万**（第 112 条第 5 项）；交给无证单位 → **所需处置费用 3~5 倍，不足 20 万按 20 万计**（第 112 条第 4 项）；而两高环境污染刑事司法解释将"非法排放、倾倒、处置危险废物**三吨以上**"列为刑法第 338 条污染环境罪的入罪情形——一家中型修理厂一年的废机油产量恰在 1~5 吨量级，**刑事门槛就在日常经营半径之内** | 对小微企业这不是"合规成本"问题，是**生存风险**问题；风险与收入的错配越大，把证明成本打到越低的产品价值越大 |
| F4 | 路边修理厂（三类及以下业户占绝大多数）的现状解法 = **不记账 + 塑料桶堆墙角 + 卖油收现金 + "单据回收商给我开"**：检查来了翻不出两年前的转移记录，联单号在回收商手机里，台账本上一片空白 | 现状解法的失败不在"不懂法"，在**记账成本高于记账收益**——废油一个月卖几百块，谁会为它建一套台账？除非记账同时产生别的收益 |
| F5 | 同一批废机油同时是**资产**：有资质的收集/利用单位上门收购，废矿物油按吨计价（行情随油价波动）、废铅蓄电池以旧换新折价——一次合规转移 = 一次收款 | 合规与变现是**同一个动作**：出库台账记完，钱账也记完了。把"负债账"与"收益账"合成一本，记账收益第一次大于记账成本——这是本产品与纯合规工具的分水岭 |
| F6 | 执法检查的实物形态是"四件套"：**台账本 + 转移联单 + 贮存区标识标签 + 接收方资质合同**；修理厂主的经营终端是手机微信 + 一张桌子 | 迎检材料的生成成本必须打到"点一下"，且输出形态要能打印、能微信发、能装订进档案盒 |
| F7 | 上游收集商有对称的焦虑：从不建台账的产废方收油，自己就站在"非法转移链条"的下游——**帮下游把账建齐 = 锁定合规货源 + 切断自身连带风险** | 渠道激励天然对齐（详见阶段三分发链）：上游收集商反过来是产品的天然分销商，这不是发明，是既有利益结构的顺水推舟 |
| F8 | 执法台账与卖油收入都是高敏数据；联单报送走国家危险废物信息管理系统，是监管方的既定通道 | 本地优先（数据不出设备）是安全与成本双重最优；工具**不做联单报送、不碰在线支付**，与国家系统互补不竞争 |

**第一性结论**：修理厂的危险废物经营确定性 = 「每一滴危废的可追溯度 × 贮存期限的先见度 × 迎检材料的生成速度」；而让记账可持续的燃料是**同一本账上的收益面**。谁把"记一笔转移、出一份迎检包"的成本打到趋近于零，谁就把 10 万起步的罚款风险变成小店用得起的日常习惯。

## 2. 痛点 - 爽点 - 痒点模型（梁宁）

| 层 | 用户心理 | 危废账对应 |
|---|---|---|
| **痛点**（恐惧/怕） | 怕检查时翻不出台账、说不清废油去向；怕贮存超一年没人在意；怕卖给上门收油的"游击队"被认定委托无证单位；怕哪天桶漏了、油渗了，从小罚款变刑事 | 贮存超期红黄灯按批次倒计时；接收方资质登记 + 到期预警；出库强制填接收方与联单号（可补录但亮灯）；红线自查台每天点名 |
| **爽点**（即时确定性） | 记一笔 30 秒：谁来的、收走多少、给了多少钱、联单号多少；存量几桶几公斤一眼可见；年底废油卖了多少钱自动汇总 | 出入库即记账 + 存量守恒 + 收益账月度汇总——合规动作当场兑现成钱账 |
| **痒点**（虚拟自我） | "我的小店也有大厂一样的规范台账"；"检查来了我主动把迎检包递过去" | 印着厂名的迎检包（台账明细 + 存量汇总 + 资质核验记录 + 自查结论 + 签字栏）——夫妻店的"规范经营者"身份叙事 |

优先级：痛点 > 爽点 > 痒点。MVP 只做痛点与爽点，痒点靠迎检包的落款顺手满足，不做环境监测、不做审批代办。

## 3. JTBD（待办任务）

**主任务陈述**：**当**换完一桶油、回收商上门拉货、电瓶以旧换新、检查所进门要台账、年底盘点废油收入时，**我要**立刻说得清"收了多少、存了多少、给了谁、有没有超期、卖了多少"，**以便**检查不慌、货款不糊、货源合规、风险有人盯。

| 维度 | Job | 现状方案的失败点 |
|---|---|---|
| 功能性 | 出入库落账；按批次算贮存期限；接收方与联单闭环；迎检材料产出；卖油收益汇总 | 没有账；期限靠运气；联单号在别人手机里；检查前突击补 |
| 情感性 | 检查来了不心虚；收现金不担心说不清；深夜看见墙角的桶不焦虑 | "回头再记"本身就在积累风险 |
| 社会性 | 向监管（规范经营）、向回收商（我是合格货源）、向社区（不污染邻里）证明"我是认真的修理厂" | 没有任何体面的台账载体 |

**竞品不是某款危废 SaaS，而是「不记账 + 塑料桶 + 现金 + 口头承诺」**——它零成本且是行业默认动作，这是我们真正的敌人（见阶段二波特五力：替代品威胁）。

## 4. 船模型

> 用户要的从来不是船，是安全过河。这里河对岸 = 台账齐、期限清、去向明、检查不慌。

| 元素 | 本场景 | 现状问题 |
|---|---|---|
| 乘客 | 1~10 个工位的快修店、轮胎店、综修厂、钣喷店厂主（夫妻店为主，会计与 EHS 岗位均为零） | — |
| 船 A：不记账 + 纸台账本 + 记忆 | 现状默认解，零成本 | 检查前突击补、联单号找不到、超期无预警、卖油款说不清；一旦被罚就是 10 万起步 |
| 船 B：面向大企业的危废管理 SaaS / EHS 系统 | 服务大型产废企业与处置单位 | 按年费数千至数万收钱、要实施培训、要联网填报、字段为环评口径设计——路边店被排除在市场外；小微要的是"把台账和迎检说明白"，不是一套 EHS 体系 |
| 船 C：国家危险废物信息管理系统（电子联单） | 监管方的报送通道（转移管理办法体系下联单电子化运行） | 服务**监管追溯**，不是产废单位的经营账本：不能生成迎检自查、不能算收益、不能预警贮存超期；报送义务之外的经营段是空白 |
| 船 D：回收商口头承诺"单据我给你开" | 卖油时的实际现状 | 信任但不可控：回收商换人/换公司，历史单据就断链；价格不透明，台账在别人手里等于账在自己手里是空的 |
| 河 | **产生与转移之间的追溯黑箱**：存了多少、存了多久、给了谁、凭据在哪，没有一本自己掌握的账 | 五条船共同的黑水区 |

**定位推论**：危废账**不造 EHS 的船，也不造监管系统的船**，做挂在所有船上的"产废单位自己的追溯账 + 迎检包"——废油交给谁（持证收集商 / 再生油厂 / 以旧换新渠道）不重要，重要的是"产生之后的每一公斤"第一次有了产废方自己掌握的账。与大企业 SaaS 互补（小店用不上；大店拿它当车间级台账出口），与国家系统互补（它管联单与追溯，危废账管产废方自己的台账、预警与收益），与纸台账本正面对抗但迁移成本 ≈ 0（手机上 30 秒记一笔，检查时一键打印装订）。

## 5. 非消费者分析（Christensen）

| 非消费者类型 | 画像 | 为什么不用现有解 | 对产品的启示 |
|---|---|---|---|
| 路边三类修理厂 | 1~3 工位，夫妻店，主营快保换油 | "危废系统是大厂的事"；台账本都懒得买 | 免费开始；名词全部说人话（"废机油"不叫"HW08"）；建店即送汽修常见品目模板 |
| 乡镇/县域修理店 | 网络不稳，回收商上门现金收购 | 云 SaaS 断网即瘫；店主的账都在微信和脑子里 | PWA 离线可用；迎检包可打印装订；收益账顺手把现金账记了 |
| 连锁快修单店 | 总部有 EHS，单店长只管干活 | 总部系统填报滞后，单店自己没账；检查先查单店 | 单店级台账 = 对上报送的底稿；导出 JSON 可向上汇总 |
| 反 SaaS 老板 | 被年费软件坑过（买了没人用/数据在云上拿不回） | "再交一次年费不如再买两个桶" | 数据 100% 本地 + JSON 导出/导入；不付费也能一直用 |

非消费者共同阻碍排序：**觉得"台账是大厂的事"（规模错觉）> 怕记油麻烦（动作成本）> 怕记了反而暴露问题（叙事风险）**。MVP 依次对应：单人单店免费全功能 + 品目模板预填、出入库 30 秒落账、自查台的基调是"先补齐、不评判"（红绿灯给的是行动指引，不是罚单预告）。

## 6. PESTEL 宏观扫描

| 维度 | 要点 | 对本机会 |
|---|---|---|
| **P** 政治 | 新固废法 2020-09-01 施行全面加码产废单位义务；危险废物转移管理办法体系下联单电子化运行；生态环境部门对汽修行业的危废专项执法常态化（废机油是基层执法最常见案由之一） | 合规要求从"软约束"变"硬罚则"，顺风；小店需要一套"证明自己合规"的日常工具，自查台是顺手的价值 |
| **E** 经济 | 修理厂毛利被价格战压薄，对费用极度敏感；但一次罚款（10 万起步）≈ 小店 1~2 年净利润；废油/旧电瓶年变现几百到几千元是真实小额收入 | 免费增值是唯一可行定价；付费逻辑是"避免一次罚款"，比"经营增长"更贴近小店的账；收益账把软件从成本变成"顺便记了笔钱账" |
| **S** 社会 | 废机油偷倒污染土壤河道的社会情绪强烈，"散乱污"治理深入人心；社区投诉是执法线索的主要来源之一 | 合规经营的修理厂需要"我不是偷倒的那家"的可信信号；迎检包 = 对社区与监管的沟通资产 |
| **T** 技术 | 电子联单已全国联网运行，转移链条数字化基建成熟；但产废端小微数字化近乎空白；微信是修理厂主一切信息往来的默认通道 | 国家系统管"链上追溯"，产废端"自己的账"留白；本地优先 + 微信文本 + 打印恰好补位，不碰报送就没有与平台的竞争 |
| **E** 环境 | 新能源车渗透率上升改变危废结构（废机油增量趋缓，动力电池回收成为新命题），但存量燃油车保有量巨大，未来 10 年换油业务仍是基本盘 | 品目模板可编辑的产品设计天然适应危废结构迁移；不把产品押在单一品目上 |
| **L** 法律 | 产废方对危废去向承担**自证责任**；两高司法解释"三吨入刑"把偷倒从行政问题升格为刑事问题；台账、联单、合同是执法与诉讼中的常见证据组 | 台账记录同时是**举证资产**——记录的完整、即时、规范直接服务执法应对与纠纷自保；本地记录不宣称司法级存证（诚实条款） |

结论：宏观无逆风。P（硬罚则 + 专项执法）与 L（自证责任 + 三吨入刑）双顺风；E（费用敏感）约束定价但不约束机会成立；T（联单系统已建成）被"互补定位"结构性化解——做监管系统不做的事，不做监管系统做的事。

## 7. 机会缺口矩阵

以"用户重要性 × 市场现有解完整度"定位空白：

```
重要性 高 │ ①大型产废企业危废SaaS/EHS    ③【空白】小微修理厂危废追溯账
          │ （红海，为环评口径设计）      （台账/超期预警/资质核验/迎检包/收益账，
          │                               无小微级轻产品）
重要性 低 │ ②在线环境监测硬件/代办申报    ④通用进销存软件
          │ （重资产/灰域代办）            （无危废品目与法条语境）
          └─────────────────────────────
             现有解完整度 高            低
```

- ③的四段拆解交叉验证：不记账/纸台账本（无预警无迎检）、大企业危废 SaaS（重、贵、为环评口径设计）、国家联单系统（管报送不管经营）、回收商口头承诺（账在别人手里）——**每一段都有人做，合起来无人做**。
- ①是危废 SaaS 的主场，年费数千至数万且要实施；③覆盖的是沉默的大多数（几十万量级的修理业户，详见阶段二 TAM 的宽区间诚实标注）。
- ②偏离主线且涉灰域，不碰；④偏离危废法条语境，无冲突也不碰。
- 法条与执法事实给 ③ 背书：台账缺失 10 万起步（固废法第 112 条第 13 项）、贮存超一年违法（第 81 条）、三吨入刑（两高司法解释）、废机油是基层环保执法高频案由——**规则已生效、痛点有量级、轻产品空白仍在**。

**阶段一结论**：危废账占位 ③——一条被硬罚则、三吨刑事线与专项执法共同供养、被"不记账 + 塑料桶 + 口头承诺"证明协作真实存在、却被所有危废 SaaS 忽略的缺口。
