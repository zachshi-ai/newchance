## 1. 痛点（真实世界，有据可查）

修车必然产废：废机油、废铅蓄电池、漆渣、沾染的滤芯油桶，都在《国家危险废物名录》（2021 年版）里被明确列为危险废物——从产生那一刻起，修理厂就背上了法定处置义务。而新《固体废物污染环境防治法》（2020 修订）把这本账变成了硬约束：

- **台账是法定义务**：产废单位必须制定管理计划并备案、建立管理台账如实记录（第 78 条）；未建台账罚款 **10 万~100 万**（第 112 条第 13 项）。
- **贮存不得超过一年**（第 81 条），桶堆墙角超过一年就是违法状态持续。
- **禁止交给无证单位**（第 80 条）：把废油卖给上门的"游击队"，按所需处置费用 **3~5 倍**罚款、不足 20 万按 20 万计（第 112 条第 4 项）。
- **联单是证明**：未按规定填写运行转移联单罚 **10 万~100 万**（第 112 条第 5 项）——而联单号今天躺在回收商的手机里。
- **刑事线在三吨**：两高环境污染刑事司法解释将"非法排放、倾倒、处置危险废物三吨以上"列为污染环境罪入罪情形——一家中型修理厂一年废机油产量恰在 1~5 吨量级，**刑事门槛就在日常经营半径之内**。
- **现状解法 = 不记账 + 塑料桶 + 现金 + "单据回收商给我开"**：检查来了翻不出两年前的转移记录；同一批废油其实是资产（有资质收集商上门按吨收钱、旧电瓶以旧换新折价），但没人把这笔钱账记下来。
- 第一性差距：**"产生与转移之间的追溯黑箱"没有任何小微级工具承接**——大企业危废 SaaS 年费数千起步、为环评口径设计；国家联单系统管监管追溯不管经营；路边店被整个市场排除在外。

## 2. 方案（机会 → 产品）

**危废账**：零依赖、本地优先的 PWA。

1. **厂店/品目/接收方建档**：汽修常见危废品目模板预填（代码可编辑，标注"以最新名录与属地要求为准"）；接收方登记经营许可证号与有效期。
2. **出入库台账**（核心计算）：入库 = 产废进桶、出库 = 转移给接收方；出库不得超存量（**整体拒绝不部分入账**）；数量最小单位 0.1kg/件，整数运算无浮点漂移；撤销 = **红字冲销留痕**（不可静默删除，部分转移的入库拒绝冲销）——台账具备审计自洽性。
3. **贮存期限预警**：按批次倒计时，一年红线（口径参数化）+ 30 天预警窗；FIFO 先出建议——最早批次先转移。
4. **红线自查台**：台账断更 / 联单待补 / 资质缺失或到期 / 贮存超期 / 管理计划备案 / 容量预警，逐条亮灯并标注法条依据，给"今天做什么"。
5. **收益账**（爽点）：出库款额按月/品目/接收方自动汇总（整数分）——合规与变现是同一个动作。
6. **迎检包三通道 + 数据自持**：微信文本 / 打印版单文件 HTML（台账明细 + 存量汇总 + 资质核验 + 自查结论 + 签字栏）/ 直接打印；JSON 导出/导入，100% 本地存储。

## 3. 诚实的现状声明（真实可落地，不空中楼阁）

- **已验证**（本仓库内可复现）：核心逻辑单元测试全绿（守恒校验、整体拒绝不部分入账、红字冲销回滚、部分冲销拒绝、FIFO 批次消耗、超期分级、资质到期预警、联单待补清单、收益汇总整数分、迎检包文本/HTML 确定性输出、XSS 转义、导入导出往返）；浏览器端到端全流程（示例数据 → 记账 → 冲销 → 预警 → 自查台 → 迎检包导出）真实运行通过；打印版 HTML 为单文件、离线可用；零 npm/CDN/API 依赖；SW 缓存版本化且更新可靠。
- **未验证**（需真实用户，见 docs/13 假设登记册）：台账留存（H1）、迎检真实使用（H2）、预警闭环（H3）、付费意愿（H4）、收集商渠道（H5）——全部标注"待验证"并配有可证伪判据。
- **边界与免责**：不碰联单报送、不做监测对接、不做审批代办、不做在线支付；本地记录不宣称司法级存证；品目代码、罚则口径、贮存要求参数化，**以最新《国家危险废物名录》、现行《固体废物污染环境防治法》及属地生态环境部门要求为准**——属地规则永远赢；自查结果是整改指引，不是"包过检查"。

## 5. 与既有项目的领域隔离（用户约束）

本方向为**机动车维修 · 危险废物合规台账与边角料收益账（B2B 小微修理厂 · 生态环境监管线）**，已对照仓库根 README 领域登记表与 `newidea` 仓库 64+ 点子做领域排除：不与 1~13 号已登记项目重叠——`pet-handoff`（C 端宠物照护）、`food-sentry`（餐饮食安/市监线）、`turn-sheet`(民宿周转与布草)、`work-proof`（劳动用工/人社线）、`class-off`（教培预收费课时账）、购销单（农资购销/农业农村线）、车况单（二手车披露）、瓶安单（燃气安检）、灭菌单（口腔院感）、安巡单（安全生产/应急线）、护安单（养老机构安全/民政线）、泳清单（泳池水质/卫健线）、来路单（废品站收购实名/公安线）——也不与 `newidea` 各点子重叠：特别排查了 `lowball`（装修增项，消费侧）、`repair-ledger`（家电修换决策，消费侧）、`expiry-cliff`（个人证照到期）、`shadow-base`（社保基数，雇员侧）等邻域点子。危废账与来路单虽同属"台账自证"形态，但方向相反（来路单管收购**进向**溯源，危废账管产废**去向**追溯）、行业与监管线完全不同（再生资源/公安 vs 汽修危废/生态环境）。付费主体（修理厂与危废收集商）、使用场景（产废/转移记账与环保迎检）、行业语境（固废法罚则、贮存期限、转移联单、废油行情）均不同域。
