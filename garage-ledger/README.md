# 危废账 GarageLedger

> 小微修理厂的危险废物台账：**废机油从进桶那一刻起就是法定负债，卖出去那一刻又是现金资产——危废账把"负债 + 收益"合成一本账。**
> 机会实验室 15 号项目 · 领域方向：机动车维修 · 危险废物合规台账与边角料收益账（B2B 小微修理厂 · 生态环境监管线）

## 痛点

- 修车必然产废：废机油（900-214-08）、废铅蓄电池（900-052-31）、漆渣、沾染滤芯，全是《国家危险废物名录》里的危险废物——产生即负债。
- 《固体废物污染环境防治法》（2020 修订）：管理计划备案 + 台账如实记录（第 78 条）、贮存不得超过一年（第 81 条）、禁止交给无证单位（第 80 条）。
- 罚则到小店生存线：**未建台账 10 万~100 万、联单缺失 10 万~100 万、委托无证单位按处置费 3~5 倍（不足 20 万按 20 万）**；非法倾倒危废 **≥3 吨入污染环境罪**——一家中型修理厂年废油量恰在 1~5 吨量级。
- 现状解法 = 不记账 + 塑料桶 + 现金 + "单据回收商给我开"；而大企业危废 SaaS 年费数千起步，路边店被整个市场排除。
- 同一批废油其实是资产：持证收集商上门按吨收钱、旧电瓶以旧换新折价——没人把这笔钱账记下来。

## 方案

零依赖、本地优先 PWA：**出入库 30 秒记账（超存量整体拒绝、撤销=红字冲销留痕）→ 贮存超期按批次倒计时（一年红线 + FIFO 先出）→ 接收方资质与联单闭环核验 → 红线自查台（逐条带法条依据 + 今天做什么）→ 收益账（出库款额按月自动汇总）→ 迎检包三通道（微信文本 / 打印版单文件 HTML / 直接打印）**。数据 100% 本地，JSON 导出归档自持。

## 快速开始

```bash
cd garage-ledger && npm start   # → http://localhost:8094
npm test                        # 31/31 单元测试
```

首次使用点「设置 · 用汽修常见模板一键添加」品目，再点「载入示例数据」即可体验临期预警、待补联单、资质缺失等演示场景。

## 第一桶金

主攻「**危废收集商联营**」：上游供应商即分销商（实验室已多次验证的分发模式，本项目里激励三方对齐）——收集商把危废账白标赠给下游 10~200 家产废修理厂：下游台账齐 = 货源合规可溯 = 收集商自身不站"非法转移链条"下游（固废法第 80 条连带走），白标迎检包落款 = 业务员巡收路线上的品牌触达。¥1200/年/商；修理厂侧 ¥99/年 Pro 为辅（假门验证）。

## 诚实条款

技术可行性已在仓库内验证（31/31 测试 + 浏览器端到端）；本工具是产废单位自查台账与整改指引，**不构成法律意见、不替代法定申报与转移联单报送、不宣称司法级存证**；品目代码与法条口径参数化，以最新《国家危险废物名录》、现行《固体废物污染环境防治法》及属地生态环境部门要求为准（属地规则永远赢）；行业数量为宽区间诚实标注；商业假设（记账留存/迎检使用/预警闭环/付费/收集商渠道）全部标注"待验证"并配有可证伪判据（docs/13 H1-H8）。
