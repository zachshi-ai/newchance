# 12 · 阶段三：机会转化产品方案

## 1. 商业画布（九格）

| 格 | 内容 |
|---|---|
| 价值主张 | 「证在期、人配齐、自查签——五道闸全过，这个航次才开」：每日 3 分钟把法定义务做完留痕，海事登轮 10 秒自证，扣船风险前置清零 |
| 客户细分 | 1~5 船内河个体船东（主）；小微水运公司挂靠船队（次）；船舶经纪/燃油供应点/船员换证代办（渠道） |
| 渠道 | 上游即渠道联营（船舶经纪手握买卖与年检关系、燃油供应点手握每航次充值触点）；长江/运河沿线码头地推；船东社群（抖音航运号/微信群） |

| 收入流 | ①船所直接订阅 ¥300/船/年（早鸟）②渠道白标 ¥150/船/年×10~50 船/点 ③迎检辅导包 ¥99/次 ④船员换证/保险经纪导流佣金（待验证） |

| 成本结构 | 开发（系列复用后边际≈0）；获客（地推人力为主）；法规维护（每季度一次口径复核） |

## 2. 价值主张画布

**客户任务**：合规任务（四证换发/船员证书/开航前自查/进出港报告）、运营任务（配员排班/维护保养）、资产任务（船舶买卖/租赁时的账面证明）。
**痛点**：证书到期遗忘、配员凑不齐硬开、65 周岁红线跨线、自查清单补签丢失、海事检查前夜凑材料、扣船停航损失。
**收益期待**：不被扣船、不被罚 1 万~10 万、省时间、卖船时有干净账面。

**产品映射**：痛点 relief——四证钟+换发窗口（遗忘→红黄绿）、配员引擎+开航闸（硬开→当场拦）、65 周岁提示（跨线→提前换证）、自查同日唯一（补签→不可补）、迎检自证包（凑材料→10 秒出）。收益 creator——当次开航单贴驾驶台（体面+速查）、当次快照回放（纠纷时自证清白）、月度小结（船队/家人群的存在感）。

## 3. 蓝海战略四动作（ERRC）

| 动作 | 内容 |
|---|---|
| 剔除 Eliminate | 云端账号体系、航次调度/货源匹配（红海）、货物/运单管理、培训成本 |
| 减少 Reduce | 每日录入到 ≤3 分钟（五组打勾为主）；证书录入到「照证件抄一个日期」；配员核对到「多选点名」一键 |
| 提升 Raise | 拦截的法条解释力（每条拒绝理由精确到条号与罚额）；自查清单的法定格式感（船长签字+2 年留档口径） |
| 创造 Create | **开航五道闸**（行业没有「开航前门禁」心智）；当次开航单贴驾驶台；快照回放；合规雷达（27 号令修正/检验规则 2024 显式跟踪） |

## 4. USP

> 唯一一款「法条内嵌、离泊过闸、登轮自证」的内河船舶台账：拦截理由精确到条号与罚额，开航单随船可查，数据不出手机。

## 5. Kano 模型

- **必备（M）**：四证/证书到期提醒、开航前自查留痕、配员核对、数据备份导出——没有即一票否决。
- **期望（O）**：五道闸拦截+法条理由、月度小结、迎检自证包——越准越好。
- **魅力（A）**：当次快照回放、65 周岁红线提示、换发窗口自动黄、合规雷达——传播点。
- **无差异（I，明确不做）**：货源匹配、运单/结算、天气导航、船用配件商城。

## 6. 供应链分析

**产品侧供应链**（做这个产品需要什么）：零依赖开源栈（HTML/JS/Node test/playwright）→ 供给无限、成本 0；法条数据源=国家行政法规库（moj.gov.cn PDF）/交通部 xxgk/CCS 转载（一手核验，见 docs/14）→ 免费、可持续；无硬件、无第三方 API → 无断供风险。

**产品自身供应链**（产品在船东侧的运行链）：手机浏览器（船上一部旧安卓机即可）→ localStorage（本机）→ 出证物（单文件 HTML/打印/文本）→ 纸/微信。全程无服务器、无账号、无支付通道依赖；内河航线常有信号盲区——本地优先 PWA 离线可用恰好是刚需而非卖点。

**分发供应链**（怎么到船东手里）：三级——①**上游即渠道**：船舶经纪（手握买卖+年检代办关系，一台手机带 10~50 船）、燃油供应点（每个航次都有充值触点，白标 ¥150/船/年）、船员换证代办（换证场景天然接触证书痛点）；②水系沿线地推：码头/锚地扫船+30 秒示例演示；③线上：船东社群内容（「检验证书过期被暂扣怎么办」）。第一桶金主打 ①：一个燃油供应点/经纪点 10~30 船的年框即可验证付费假设（H5/H6）。

## 7. MVP 边界

**做**：船舶建档四证钟（含换发窗口）、船员名册三钟（适任/健康/65 周岁）、配员核对引擎、每日开航前自查卡（五组+异常转缺陷）、开航五道闸+当次快照、缺陷闭环状态机、变更登记台账、周期义务账（6 类）、十项体检、月度小结、海事迎检自证包、当次开航单、导入导出、合规雷达。
**不做（MVP 外）**：进出港报告直连（政府系统承接）、AIS/GPS 集成、多船船队看板、航次调度、油污水接收联单、船员考证报名。
