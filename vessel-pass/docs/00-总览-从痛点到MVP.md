# 00 · 总览：从痛点到 MVP —— 船安单 VesselPass

> 一句话：把内河船舶「每次开航前必须核对、海事登轮必须查证、船东夜里睡不着」的合规动作，装进一部手机的五道闸与两张纸里——**证在期、人配齐、自查签，五道闸全过，这个航次才开。**

## 一、痛点（第一性原理切到底）

- 事实 1：一条内河货船随身携带七八本证——检验证书、国籍证书（5 年）、最低安全配员证书、责任保险文书、船员适任证书（值班船员 ≤5 年且有效期截止不超过 65 周岁）、健康证明……到期日各不相同，全靠船东脑子记。
- 事实 2：内河条例的罚则是「扣船级」的：无证擅自航行→责令停航→拒不停止**暂扣船舶**→情节严重没收（第 64 条）；未按规定配员航行→船东罚 **1 万~10 万**、逾期不改责令停航（第 65 条）；无保险文书→停航+1 万~10 万（第 67 条）。停一天船的损失就超过一年工具钱。
- 事实 3：海事登轮检查要看《船舶开航前安全自查清单》（船长签字、在船保存 ≥2 年）——纸本清单补签、丢失是常态。
- 推论：把「四证钟 + 船员证书钟 + 配员核对 + 开航前自查 + 五道闸 + 一页自证」装进船东手机，防的是扣船，省的是心。

## 二、方案（零依赖本地优先 PWA）

船舶建档（四证钟，照证书录入、国籍/配员证书届满前 1 年换发窗口自动黄）→ 船员名册（适任证书钟+65 周岁红线+健康证明钟，离船停用不删除）→ **每日开航前自查卡**（五组条目：船体水密/主机机电/救生消防/航行设备/货物装载，异常必写处置并自动转缺陷）→ **开航五道闸**（证书在期→保险在期→配员达标且船长在船→自查已签→缺陷闭环，当场拦截带法条理由，放行存当次快照）→ 缺陷闭环 + 变更登记 + 周期义务账（演习/维护/报告核查/图籍/换发窗口/保险）→ 一键出**海事迎检自证包 / 当次开航单**。

## 三、为什么现在

- **运力出清**：水上运输船舶 11.02 万艘（2024 公报，一年减 0.81 万艘）——老旧船退出、单船合规成本权重上升，账做实才能跑得久；
- **口径刚换挡**：《船舶安全监督规则》现行版=交通运输部令 2022 年第 27 号二次修正版（开航前自查=第 42 条，网上大量引 2017 原版文号即露馅）；《内河船舶检验规则（2024）》已发布；
- **船员队伍老龄化**：65 周岁红线（适任证书有效期截止日）正批量撞上一线船长——换证窗口管理是刚需。

## 五、诚实条款

技术可行性已在仓库内验证（**23/23 单元测试 + 27/27 浏览器端到端**）；商业假设（付费/留存/渠道）全部标注「待验证」并配有可证伪判据。本工具是船东/船长自查与海事检查备查的底账，**不替代船舶登记、检验、进出港报告、船员考证等法定程序**；渔船/体育运动船艇/非营业游艇不适用配员规则；属地海事机构要求永远赢。
