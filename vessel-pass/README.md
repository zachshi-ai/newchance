# 船安单 VesselPass · 内河船舶合规台账（机会实验室 #32）

> 「证在期、人配齐、自查签——五道闸全过，这个航次才开。」
> 面向 1~5 船内河个体船东与小微水运公司的零依赖本地优先 PWA：把海事「每次开航必须核对、登轮检查必须出示」的合规动作装进一部手机，当场拦截不合规开航，出证物随船可查。

## 痛点

全国水上运输船舶 11.02 万艘（2024 交通运输统计公报，一年减 0.81 万艘——运力出清、单船合规成本权重上升）。一条内河货船随身七八本证：检验证书、国籍证书（5 年、届满前 1 年换发）、最低安全配员证书（截止前 1 年换发）、责任保险文书、船员适任证书（值班船员 ≤5 年、有效期截止不超过 65 周岁生日）、健康证明——到期日各不相同，全靠船东脑子记。而内河条例的罚则是「扣船级」的：无证擅自航行→**暂扣船舶**、情节严重没收（第 64 条）；未按规定配员航行→船东罚 **1 万~10 万**、逾期不改停航（第 65 条）；无保险文书→停航+1 万~10 万（第 67 条）。海事登轮还要查《船舶开航前安全自查清单》（船长签字、在船保存 ≥2 年）。现状解法是驾驶台抽屉一摞证+脑子记+微信催——**「证在期、人配齐、自查签」与「能向海事证明」之间，没有任何船东级工具。**

## 方案

- **船舶建档四证钟**：检验证书（照证书簿载明的下次检验日录入，不自行推算周期）/国籍证书（5 年+届满前 1 年换发窗口自动黄）/最低安全配员证书（截止前 1 年窗口）/责任保险文书（第 67 条口径），红黄绿+换发窗口三态。
- **船员名册三钟**：适任证书钟（≤5 年+65 周岁红线提示+临期提醒）+健康证明钟（默认 2 年参数化）；普通船员无强制适任证不误拦，登记了就照判；离船停用不删除。
- **配员核对引擎**：照《最低安全配员证书》录入核定人数，开航点名实时核对「人数达标+船长在船+全员证书在期」。
- **每日开航前自查卡**：五组条目（船体水密/主机机电/救生消防/航行设备/货物装载），同日唯一、异常必写处置并自动转缺陷；固定航线单航次 ≤2 小时口径标注（第 42 条）。
- **开航五道闸**：检验/国籍/配员证书在期 → 保险在期 → 配员达标 → 自查已签 → 缺陷闭环——当场拦截带法条理由+埋点，放行存当次快照。
- **缺陷闭环状态机**：自查异常自动转入/海事监督检查/公司自查，登记→整改→复查销案，跳级拒绝。
- **变更登记台账 + 周期义务账**：演习/维护保养/进出港报告核查/航行资料更新/换发窗口核查/保险确认，6 类打勾滚动。
- **两通道出证**：海事迎检自证包（八段单文件 HTML 含签字栏）/当次开航单（打印随船，五道闸核对+在船船员证书快照）。
- **合规雷达**：《船舶安全监督规则》2022 年第 27 号修正口径、《内河船舶检验规则（2024）》动态显式跟踪。

## 快速开始

```bash
cd vessel-pass
npm start          # → http://localhost:8110
npm test           # 23/23 单元测试
python3 tests/e2e.py   # 27/27 端到端（需 npm start 运行中；playwright+系统 Chrome）
```

## 诚实条款

技术可行性已在仓库内验证（23/23 单测 + 27/27 E2E）；商业假设全部标注「待验证」并配可证伪判据（docs/13 H1-H8）。本工具是船东/船长自查与海事检查备查底账，**不替代船舶登记、检验、进出港报告、船员考证等法定程序**；渔船/体育运动船艇/非营业游艇不适用配员规则；属地海事机构要求永远赢。数据 100% 本机存储（内河信号盲区离线可用），出证物脱敏可控，埋点不含个人信息。
