# 场记单 SceneLog 🎬

> **小微剧本娱乐场所（剧本杀·密室）的合规台账：剧本报备钟 30 日三色、未成年人时段红线（2026 官方假日表内置，调休补班的周六日照判工作日）、消防指南「每局一巡查」、月检/半年演练/年培训/灭火器四钟——检查来了 30 秒出证。**
> 零依赖 · 本地优先 · 免注册 · 可离线 · 数据不出设备

2022 年起，剧本杀与密室逃脱作为「剧本娱乐经营场所」被五部门纳入全国统一监管（文旅市场发〔2022〕70号）：场所与剧本经「全国文化市场技术监管与服务平台」**告知性备案**（营业起/使用起 **30 个自然日**，新增与实质变更重报）、剧本要**适龄提示**、**除国家法定节假日、休息日及寒暑假期外不得向未成年人提供**；《剧本娱乐经营场所消防安全指南（试行）》（国家消防救援局、文旅部 2023-04-06）更把留痕颗粒度定到行业罕见的**「每局剧本娱乐活动结束后必须进行一次防火巡查」**，外加每月全面检查、每半年演练（白天+夜间各一）、每年培训；文旅专项整治清单（办综执发〔2023〕37号线）的十大检查点条条要台账。而全国近 5 万家门店（2023 青浦区政府文件口径）的现状解法是纸本巡查表月底补签、备案日期靠记忆、调休补班日接待未成年人全靠前台自觉——**监管要的不是「你做了」，是「你能证明你持续做了」。**

场记单把这段黑箱变成白箱：建档上钟 → 开本落账 10 秒（工作日/补班日接待未成年人当场红线警告）→ 局后一键巡查打卡 → 四钟自动滚 → 八灯体检 → 一键出「迎检自证包」（十大检查点逐项对表 + 签字栏）/ 当日巡查卡（打印上墙）/ 微信月度小结。

## 3 条命令跑起来

```bash
cd scene-log
npm start           # 等价于 python3 -m http.server 8100 --directory app
open http://localhost:8100
```

没有 npm 也可以：任意静态服务器指向 `app/` 目录即可（它就是这个产品的全部）。
首次进入点「**先看示例数据**」，30 秒体验完整流程（示例故意埋了红线场次与逾期灭火器）。

| 模块 | 说明 |

| 🚦 **未成年人时段红线** | 内置 2026 官方假日表（国办发明电〔2025〕7号，**含 6 个调休补班日**）+ 寒暑假窗口（属地校历可改）；未来 14 天闸门图；工作日/补班日接待未成年人当场拦截，18+/场景禁入剧本永禁 |

| 🩺 **八灯体检** | 报备/时段红线/每局巡查/月检/演练/培训/灭火器/选址设施，确定性扣分（红-15 黄-8），迎检前先自查 |

## 为什么没有后端 / 没有依赖

这不是偷懒，是设计（详见 [docs/12 供应链分析](docs/12-阶段三-机会转化产品方案.md)）：
**无服务器 → 无账单；无 npm → 无投毒攻击面；无 CDN → 断网可用（门店常在商场地下层）；无第三方 API → 无停服风险。**
台账 100% 本机，玩家信息只记数量与核验标记（本地优先即《个人信息保护法》最小披露的实现方式）；年度假日安排更新=改一个种子文件+跑测试。

**不做**：备案平台直连与报送（无资质）、内容合规判定（只留自审记录）、收银/会员/拼场（经营系统的事，互补不冲突）、云端同步、玩家社交。
