## 2. 价值主张画布（Customer Profile ↔ Value Map）

**Customer Jobs**：①合规过检（功能性）；②不被罚款/不被吊证（风险性）；③家人店员交接有章法（社会性）；④「我是规范店主」的身份认同（情感性）。

**Pains**：单据散失、核验凭眼力、手续记不住（5 年期+30 日窗口+停业 1 年上限三套时钟）、检查前凑材料、电子烟新规看不懂。

**Gains sought**：10 秒出证、拦截时给法条理由、台账与实物一致。

**Products & Services**：售烟四闸 + 进货台账（红旗隔离）+ 三只钟（证/延续/停业）+ 开柜检查卡 + 合规事件闭环 + 三通道出证。

**Pain Relievers**：未成年人三态拦截（未保法第 59 条理由随拦截给出）；来源错配当场拒（卷烟→平台/电子烟→批发商的错选直接拒绝）；红旗批次自动隔离+闭环解除。

**Gain Creators**：出证物自带快照（销售落账时许可证状态+售后库存当场封存）；月度小结把「这个月没被罚」量化成拦截计数。

**Fit**：四闸与三钟逐条对应 Pains 1~3（均挂现行条文锚，docs/14）——这是「制度生产的痛点」，不是想象出来的需求。

## 3. 蓝海战略四动作框架（ERRC）

| 动作 | 内容 |
|---|---|
| **Eliminate 剔除** | 营销/会员/外卖等门店数字化功能——与合规无关，全是竞争红海；云端账号体系（本地优先即最小披露，证件号订单号不出设备） |
| **Reduce 减少** | 录入字段（进货 5 字段/售烟 6 字段）；学习成本（引导页 30 秒看懂+示例数据一键体验）；价格到「一条烟的零头」 |
| **Raise 提升** | 专卖口径的条文精度（四修条例/2022 电子烟办法/未保法罚则升格的现行口径，甩开网上旧文一个身位）；检查现场的证据组织度（快照+签字栏+法条尾注） |
| **Create 创造** | 「拦截计数=没被罚的证据」的新账本叙事；红旗批次隔离-闭环-解除的品规级风控；核验留痕作为未成年人保护义务的执行证据（行业首创落账） |

## 4. USP（一句话定位）

**「全国 550 万持证烟店里，第一本能证明『每笔烟都卖得干净』的合规台账——检查进门 10 秒出证。」**
支撑三支柱：①专卖口径现行条文逐条锚定；②售烟四闸当场拦截带法条理由；③本地优先零成本可永久免费。

## 6. MVP 边界（本仓库交付物）

**做**：店铺建档与许可证钟（含延续/停业）、品规一物一档（调味电子烟建档即拦）、进货台账（来源-品类错配拒、红旗隔离）、售烟四闸（拦截带法条理由+快照）、每日开柜检查卡（异常转合规事件）、事件闭环（红旗解除联动）、变更手续账、周期义务账（含执照年报跨线提醒）、十项体检、三通道出证、导入导出、SW 离线。

**不做（明确出界）**：执法对接/监管报送；进销存的营销功能；多端实时同步；烟草公司订货链路集成； iOS 上架（PWA 即可）。

## 7. 供应链分析

- **产品侧**（帮店主管的「供应链」）：卷烟供应链极简且强管制——工厂→中烟/省公司→县级批发企业→持证零售户，**零售户唯一合法上游=当地批发企业**（电子烟=统一交易平台→当地电子烟批发企业）。本产品的「进货台账+渠道回看窗+红旗隔离」正是这条受管制供应链在店主侧的合规镜像；不存在多头供应商的复杂度。
- **产品自身**：零依赖 PWA（无服务器、无数据库、无第三方 SDK），供应链风险=浏览器 API 演进（localStorage/Service Worker 已是稳定面十年）；单文件出证保证「检查现场不依赖网络」——合规工具断网即死是设计禁忌，本地优先是硬约束。
- **分发供应链**：批发配送商的送货车与客户经理是触达百万夫妻店的唯一高频物理通道（每周访销）；白标授权让渠道商用自己的品牌交付（借其信任存量），本方沉淀条文库与产线——渠道第 12 次复用（延续 #6/#8/#17/#18/#19 等项目的同一获客经济学）。
