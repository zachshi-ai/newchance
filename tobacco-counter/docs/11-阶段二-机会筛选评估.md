# 11 · 阶段二：机会筛选评估

## 1. 波特五力（诚实评估：低壁垒是事实，靠定位与速度活）

| 力量 | 强度 | 评估 |
|---|---|---|
| 现有竞争 | 低 | 专卖口径合规台账是空白；通用进销存（客如云/银豹等）不覆盖专卖义务口径，且以营销获客为主叙事 |
| 新进入者威胁 | **高** | 技术壁垒低（本仓库 3 天可交付同构 MVP）——护城河只能是：①专卖口径的条文精度（本仓库的一手核验流程是可复用资产）；②白标渠道卡位（批发配送商）；③速度 |
| 替代品 | 中 | 纸质台账的惯性=最大替代品；烟草公司订货 App 覆盖部分渠道证明，但无核验留痕与自查台账 |
| 买方议价力 | **高** | 百万户级、单店付费能力弱——定价锚定「一条软中华的零头」（¥99~150/年），且必须借渠道白标摊薄获客成本 |
| 供方议价力 | 低 | 零依赖技术栈、无云成本、无独家依赖 |

**结论**：五力结构差（低壁垒+弱买方）， BUT 空白缺口真实、客群基数百万级。策略：**不追求防守型护城河，追求「条文精度+渠道卡位」的先发窗口**——这与本仓库「机会实验室」逐领域快速验证的方法论一致。

## 3. TAM-SAM-SOM（宽区间，诚实标注待复核）

- **TAM**：全国烟草专卖零售许可证持证户约 **550 万户**（业内常引量级，官方精确数待复核；docs/14）。
- **SAM**：其中城镇持证、店主用智能手机、有店员交接或检查压力的「规范敏感型」门店，按 30%~50% 估 **165 万~275 万户**。
- **SOM（3 年）**：经批发配送商与协会白标渠道触达 1%~3% → **2 万~8 万店**；按 ¥99~150/年白标价与渠道 5:5 分成，年营收区间 **¥100 万~600 万**。客单价×渠道分成的保守口径下，第一桶金目标（首年 3000 付费店 ≈ ¥30 万~45 万流水中方）不依赖任何融资假设。

## 4. 机会-可行性四象限

```
        市场机会（大）
             │
   跨境电商合规 │ ★ 烟柜账
   （多法域，超射程）│ （机会大+单机技术即达）
             │
小 ──────────┼────────── 大 技术可行性
   校园周边零售 │ 美团式全渠道数字化
   细分（机会小）│ （需供应链与地推，超射程）
             │
        市场机会（小）
```

烟柜账落在「机会大 + 现有技术即可达」象限：全部功能已被本 MVP 验证（32 单测 + 30 E2E），无未验证的技术假设。

## 5. 风险矩阵（概率 × 影响 × 缓解）

| 风险 | 概率 | 影响 | 缓解 | 残余敞口 |
|---|---|---|---|---|
| 店主不愿录入（惰性） | 高 | 高 | 录入压到 5 字段；渠道价值前置（红旗隔离当场见效）；白标预装 | 中——H1/H2 假设验证（docs/13） |
| 烟草系统对第三方工具的观感 | 中 | 高 | 产品定位「店主自查台账」，不对接执法、不代法定程序；出证物均标注「不替代」 | 低-中——法律边界已在文案层闭合 |
| 电子烟户萎缩（口味禁令后市场收缩） | 中 | 中 | 主力客群是全品类持证户（550 万量级），电子烟仅是新规滩头 | 低 |
| 免费替代（烟草公司 App 加台账功能） | 低-中 | 高 | 该系统属行业内部订货链路，加「自查台账+核验留痕+出证」概率低；保持条文精度代差 | 中——季度复盘 |
| 付费意愿不达 | 高 | 中 | 首年不依赖直接付费验证生存：以白标授权+协会团购为主通道；免费层永久可用（本地优先无边际成本） | 中 |
| 法条口径过时（修订） | 中 | 中 | 本仓库口径核验流程化（docs/14）；所有周期参数化，属地要求永远赢 | 低 |

**总体判断**：低壁垒+弱付费是真实的，但「零边际成本 + 百万户级 + 法定痛点」的组合使小额白标商业模式成立；最大不确定性是行为假设（录入习惯），全部转入 HDD 假设登记册（docs/13）用 90 天验证。
