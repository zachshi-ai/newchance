# 烟柜账 CounterBook · 烟草专卖零售合规台账（机会实验室 #33）

> 证在期、货来正、不卖未成年——每笔售烟过四闸，落账即自证。

**痛点**：全国约 550 万户持证烟草零售户（业内常引口径）受三重法定义务夹击：①必须在当地烟草专卖批发企业进货（电子烟必须走全国统一交易平台），未在当地批发进货没收违法所得+罚进货总额 5%~10%（《实施条例》2023 第四次修订第 23/56 条）；②禁止向未成年人售烟、难以判明应当核验证件、显著位置张贴标志（未保法第 59 条），违者最高停业整顿/吊销执照/吊证+罚 5 万~50 万（第 123 条）；③许可证 5 年期/届满 30 日延续/停业不超 1 年三套时钟全靠脑子记（实施细则第 22/23/48 条）。检查高频且清单化（仅电子烟 2024 年以来检查 19.1 万户次、处罚 1941 户次），条例第 46 条明文授权执法者查阅复制「账册、单据、记录」——**「卖得合法」与「能证明合法」之间的证明成本，是整个痛点的第一性变量**。现状解法是纸+脑+抽屉，没有任何专卖口径的自证工具。

**方案**：零依赖本地优先 PWA——店铺建档（许可证钟：5 年上限/届满 30 日延续窗口/停业 1 年上限）→ 品规一物一档（**调味电子烟建档即拦**，电子烟办法第 26 条）→ 进货台账（来源-品类错配当场拒：「其他来源」自动红旗隔离品规、闭环解除）→ **售烟四道闸**（证在期→渠道合法→未成年人核验三态→电子烟专闸，当场拦截带法条理由、核验留痕、落账快照）→ 每日开柜检查卡（张贴/无自助售卖/无网络售烟 + 电子烟追加两项，异常必写处置自动转合规事件）→ 合规事件闭环（处置→复查销案）→ 变更手续与周期义务账（含营业执照年报跨线提醒）→ 十项体检 → 三通道出证（**迎检自证包**九段含签字栏 / **当日柜台核对单**贴烟柜 / 月度小结微信文本）。

```bash
cd tobacco-counter && npm start   # → http://localhost:8111
npm test                          # 32/32 单元测试
python3 tests/e2e.py              # 30/30 浏览器端到端（需本机 Chrome + 8111 服务）
```
